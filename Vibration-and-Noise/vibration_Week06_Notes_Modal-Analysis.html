Modal analysis of two-degree-of-freedom systems

Transforming coupled equations of motion into uncoupled modal equations with the symmetric eigenvalue problem, mass-normalised mode shapes, and the free response through modal coordinates.

01Why modal analysis

The 2DOF system of week 5 has the matrix equation \(M\ddot{\mathbf x} + K\mathbf x = \mathbf 0\). Its stiffness matrix has off-diagonal terms, so each equation contains both coordinates: the system is elastically coupled. In general, expect coupling between the degrees of freedom of any MDOF system.

Week 5 solved the generalised eigenvalue problem, \((K - \omega^2M)\mathbf u = \mathbf 0\), or \(K\mathbf u = \omega^2M\mathbf u\). It is the easiest to do by hand, but it has drawbacks once systems grow:

  • It is not computationally efficient in numerical schemes.
  • Its eigenvalues and eigenvectors are not guaranteed to be real, and the eigenvectors are not orthogonal in the ordinary sense.

The robust alternative transforms the problem into a symmetric eigenvalue problem in modal coordinates. This:

  • de-couples the equations of motion;
  • gives a symmetric transformed stiffness matrix;
  • gives real eigenvalues and eigenvectors;
  • gives an orthonormal set of eigenvectors (mode shapes) that can be used directly;
  • is less computationally intensive to solve.
Key idea

In modal coordinates each equation is a single-degree-of-freedom oscillator, \(\ddot r_i + \omega_i^2r_i = 0\), which you already know how to solve. Modal analysis is a change of coordinates that turns one coupled MDOF problem into several uncoupled SDOF problems.

02Modal analysis in eight steps

Figure 2.1: Mass-weighting (\(M^{{1/2}}\)) turns the mass matrix into the identity. Rotating with the orthonormal eigenvector matrix \(P\) then makes the stiffness matrix diagonal. The combined matrix \(S = M^{{-1/2}}P\) goes straight from modal back to physical coordinates.

Steps 1 and 2: mass-normalise

For a diagonal mass matrix, \(M^{-1/2}\) just takes \(1/\sqrt{m_i}\) on the diagonal. (If \(M\) is not diagonal, Cholesky factorisation \(M = LL^T\) does the same job.) Substitute \(\mathbf x = M^{-1/2}\mathbf q\) and pre-multiply by \(M^{-1/2}\):

Mass-normalised stiffness\[ M^{-1/2}MM^{-1/2}\ddot{\mathbf q} + M^{-1/2}KM^{-1/2}\mathbf q = \mathbf 0 \;\Rightarrow\; I\ddot{\mathbf q} + \tilde K\mathbf q = \mathbf 0, \qquad \tilde K = M^{-1/2}KM^{-1/2} \]
\(M^{-1/2}\)
Diagonal matrix of \(1/\sqrt{m_i}\) (kg⁻¹ᐟ²).
\(\mathbf q\)
Mass-weighted coordinates, \(\mathbf q = M^{1/2}\mathbf x\) (kg¹ᐟ² m).
\(\tilde K\)
Mass-normalised stiffness matrix (s⁻²); symmetric.

Step 3: the symmetric eigenvalue problem

Try \(\mathbf q = \mathbf ve^{j\omega t}\): \((\tilde K - \omega^2I)\mathbf v = \mathbf 0\). A non-trivial solution needs

Symmetric eigenvalue problem\[ \det(\tilde K - \lambda I) = 0, \qquad \lambda_i = \omega_i^2, \qquad (\tilde K - \lambda_iI)\mathbf v_i = \mathbf 0 \]
\(\lambda_i\)
Eigenvalue: the square of a natural frequency (rad²/s²).
\(\mathbf v_i\)
Eigenvector of \(\tilde K\) (not yet the physical mode shape).

The natural frequencies are exactly the same as from \(\det(K - \omega^2M) = 0\): only the eigenvectors change.

Step 4: normalise and build P

Normalised eigenvectors\[ \hat{\mathbf v}_i = \frac{\mathbf v_i}{\sqrt{\mathbf v_i^T\mathbf v_i}}, \qquad P = [\hat{\mathbf v}_1\;\hat{\mathbf v}_2], \qquad P^TP = I, \qquad P^T\tilde KP = \Lambda = \begin{bmatrix} \omega_1^2 & 0 \\ 0 & \omega_2^2 \end{bmatrix} \]
\(\hat{\mathbf v}_i\)
Unit-length eigenvector.
\(P\)
Orthonormal matrix of eigenvectors: \(\hat{\mathbf v}_i^T\hat{\mathbf v}_i = 1\), \(\hat{\mathbf v}_i^T\hat{\mathbf v}_j = 0\).
\(\Lambda\)
Spectral matrix: diagonal, with the squared natural frequencies.

Substitute \(\mathbf q = P\mathbf r\) and pre-multiply by \(P^T\): \(I\ddot{\mathbf r} + \Lambda\mathbf r = \mathbf 0\). Both matrices are diagonal, so the equations are uncoupled:

Modal equations\[ \ddot r_i(t) + \omega_i^2r_i(t) = 0, \qquad i = 1, 2 \]
\(r_i\)
Modal coordinate \(i\): the amount of mode \(i\) in the motion.
\(\omega_i\)
Natural frequency of mode \(i\) (rad/s).

Steps 5 to 8: initial conditions and back again

Transformations\[ S = M^{-1/2}P, \qquad S^{-1} = P^TM^{1/2}, \qquad \mathbf r(0) = S^{-1}\mathbf x(0), \qquad \dot{\mathbf r}(0) = S^{-1}\dot{\mathbf x}(0) \]
\(S\)
Matrix whose columns are the mass-normalised mode shapes (kg⁻¹ᐟ²).
\(S^{-1}\)
Inverse, found without inverting: \(P^TM^{1/2}\).
\(\mathbf r(0), \dot{\mathbf r}(0)\)
Modal initial conditions.
Modal solution and return to physical coordinates\[ r_i(t) = \frac{\sqrt{\omega_i^2r_{i0}^2 + \dot r_{i0}^2}}{\omega_i}\sin\!\left(\omega_it + \tan^{-1}\frac{\omega_ir_{i0}}{\dot r_{i0}}\right), \qquad \mathbf x(t) = S\mathbf r(t) \]
\(r_{i0}, \dot r_{i0}\)
Modal initial displacement and velocity.
\(\mathbf x(t)\)
Physical response (m).
Watch out

The phase uses the same \(\tan^{-1}\) as week 1, so the same quadrant rule applies: if \(\dot r_{i0} \lt 0\), add \(\pi\); if \(\dot r_{i0} = 0\), the phase is \(\pm\pi/2\) by the sign of \(r_{i0}\) (a cosine). The signs of the eigenvectors are arbitrary; choose them, then keep them consistent through \(P\), \(S\) and \(S^{-1}\).

Intuition

The columns of \(S\) are the physical mode shapes of week 5, scaled so that \(S^TMS = I\) and \(S^TKS = \Lambda\). Such mass-normalised mode shapes are what modal testing software reports.

Worked example 2.1 Lecture system by modal analysis (Inman example 4.3.1)

\(m_1 = 9\) kg, \(m_2 = 1\) kg, \(k_1 = 24\) N/m, \(k_2 = 3\) N/m; \(\mathbf x_0 = (1, 0)\) mm, \(\dot{\mathbf x}_0 = \mathbf 0\).

1
Step 1: \(M^{-1/2} = \mathrm{diag}(1/3, 1)\).
2
Step 2: \(\tilde K = \begin{bmatrix} 1/3 & 0 \\ 0 & 1 \end{bmatrix}\begin{bmatrix} 27 & -3 \\ -3 & 3 \end{bmatrix}\begin{bmatrix} 1/3 & 0 \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 3 & -1 \\ -1 & 3 \end{bmatrix}\) s⁻².
3
Step 3: \(\det = (3 - \lambda)^2 - 1 = 0\), so \(\lambda_1 = 2\), \(\lambda_2 = 4\): \(\omega_1 = \sqrt2\), \(\omega_2 = 2\) rad/s. Eigenvectors \(\mathbf v_1 = (1, 1)\), \(\mathbf v_2 = (1, -1)\).
4
Step 4: \(P = \frac{1}{\sqrt2}\begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix}\). Check: \(P^T\tilde KP = \mathrm{diag}(2, 4)\).
5
Step 5: \(S = M^{-1/2}P = \begin{bmatrix} 0.2357 & 0.2357 \\ 0.7071 & -0.7071 \end{bmatrix}\), \(S^{-1} = P^TM^{1/2} = \begin{bmatrix} 2.1213 & 0.7071 \\ 2.1213 & -0.7071 \end{bmatrix}\).
6
Step 6: \(\mathbf r(0) = S^{-1}(1, 0) = (2.1213, 2.1213)\); \(\dot{\mathbf r}(0) = \mathbf 0\).
7
Step 7: \(r_1 = 2.1213\cos\sqrt2t\), \(r_2 = 2.1213\cos 2t\).
8
Step 8: \(\mathbf x = S\mathbf r\): \(x_1 = 0.2357(2.1213)(\cos\sqrt2t + \cos 2t)\), \(x_2 = 0.7071(2.1213)(\cos\sqrt2t - \cos 2t)\).
\(x_1 = 0.5\cos\sqrt2t + 0.5\cos 2t\) mm and \(x_2 = 1.5\cos\sqrt2t - 1.5\cos 2t\) mm: the same as week 5. The columns of \(S\) are proportional to the week 5 mode shapes (1, 3) and (1, −3).

Worked example 2.2 A second system

Use modal analysis for \(m_1 = 2\) kg, \(m_2 = 1\) kg, \(k_1 = k_2 = 100\) N/m, \(\mathbf x_0 = (10, 0)\) mm, \(\dot{\mathbf x}_0 = \mathbf 0\). Find \(\mathbf x(0.5\text{ s})\).

1
\(M^{-1/2} = \mathrm{diag}(0.7071, 1)\); \(\tilde K = \begin{bmatrix} 100 & -70.7107 \\ -70.7107 & 100 \end{bmatrix}\) s⁻².
2
\(\det(\tilde K - \lambda I) = \lambda^2 - 200\lambda + 5000 = 0\): \(\lambda = 29.289, 170.711\); \(\omega = 5.4120, 13.0656\) rad/s.
3
\(P = \begin{bmatrix} 0.7071 & 0.7071 \\ 0.7071 & -0.7071 \end{bmatrix}\), \(S = \begin{bmatrix} 0.5 & 0.5 \\ 0.7071 & -0.7071 \end{bmatrix}\), \(S^{-1} = \begin{bmatrix} 1 & 0.7071 \\ 1 & -0.7071 \end{bmatrix}\).
4
\(\mathbf r(0) = S^{-1}(0.01, 0) = (0.01, 0.01)\); zero velocities, so \(r_i = 0.01\cos\omega_it\).
5
At 0.5 s: \(r_1 = 0.01\cos 2.706 = -0.00907\), \(r_2 = 0.01\cos 6.533 = 0.00969\).
\(\mathbf x(0.5) = S\mathbf r = (0.312, -13.26)\) mm. Mass 1 is almost back at zero while mass 2 is at −13.3 mm.

03Additional 2DOF problem

A rigid bar of mass \(m\) carries a point mass \(M\) at its right end and rests on springs \(k_1\) (left end) and \(k_2\). Use the translation \(x\) of the bar's mass centre and its rotation \(\theta\), small rotations, \(m = 27\) kg, \(M = 9\) kg, \(k_1 = 240\) N/m, \(k_2 = 160\) N/m, \(L = 1\) m.

Figure 3.1: From the left end: \(k_1\), then 3L to the bar centre (where \(x\) and \(\theta\) are measured), then L to \(k_2\), then 2L to the point mass. The bar is 6L long.

Worked example AP Equations of motion and natural frequencies

Take \(x\) downward at the bar centre and \(\theta\) so that a point a distance \(d\) to the right of the centre moves \(x + d\theta\).

1
Displacements: \(k_1\) at \(d = -3L\): \(x - 3L\theta\); \(k_2\) at \(d = L\): \(x + L\theta\); \(M\) at \(d = 3L\): \(x + 3L\theta\).
2
Kinetic energy: \(T = \tfrac12 m\dot x^2 + \tfrac12 J\dot\theta^2 + \tfrac12 M(\dot x + 3L\dot\theta)^2\), with \(J = m(6L)^2/12 = 3mL^2\).
3
Potential energy: \(U = \tfrac12 k_1(x - 3L\theta)^2 + \tfrac12 k_2(x + L\theta)^2\) (gravity drops out about static equilibrium).
4
\(M_{mat} = \begin{bmatrix} m + M & 3ML \\ 3ML & 3mL^2 + 9ML^2 \end{bmatrix} = \begin{bmatrix} 36 & 27 \\ 27 & 162 \end{bmatrix}\), \(K = \begin{bmatrix} k_1 + k_2 & -3k_1L + k_2L \\ -3k_1L + k_2L & 9k_1L^2 + k_2L^2 \end{bmatrix} = \begin{bmatrix} 400 & -560 \\ -560 & 2320 \end{bmatrix}\).
5
\(\det(K - \omega^2M_{mat}) = 5103\omega^4 - 178560\omega^2 + 614400 = 0\).
6
\(\omega_1 = 1.967\) rad/s (0.313 Hz), \(\omega_2 = 5.579\) rad/s (0.888 Hz). Modes \((x, \theta)\): \((1, 0.392\text{ rad/m})\) and \((1, -0.514\text{ rad/m})\).
The system is coupled both elastically (\(K_{12} \neq 0\)) and inertially (\(M_{12} = 3ML \neq 0\), because the point mass is off the bar centre). \(\omega_1 = 1.97\) rad/s, \(\omega_2 = 5.58\) rad/s.
Watch out

The 2022 partial solution does not agree with this derivation, and has an arithmetic slip of its own:

  • Its mass matrix is diagonal, \(\mathrm{diag}(36, 4.25)\). With \(x\) and \(\theta\) at the bar centre, the end mass couples them (\(M_{12} = 3ML = 27\)), and the bar inertia about its centre is \(m(6L)^2/12 = 81\) kg m², not \(mL^2/12\).
  • Even with its own matrices, the constant term of its characteristic equation should be \(\det K = 400(2320) - 560^2 = 614\,400\), not 313 600 (which is just \(560^2\)). With 313 600 it gets 1.92 and 23.52 rad/s; with 614 400 its matrices give 2.70 and 23.45 rad/s.

Its stiffness matrix agrees with the one above (the sign of the off-diagonal term depends only on which way \(\theta\) is taken as positive). Check the mass matrix with your tutor before relying on either set of numbers.

04Practice problems

Problem 4.1. Show that \(\tilde K\) is symmetric whenever \(K\) is.

\(\tilde K^T = (M^{-1/2}KM^{-1/2})^T = (M^{-1/2})^TK^T(M^{-1/2})^T = M^{-1/2}KM^{-1/2} = \tilde K\), because \(M^{-1/2}\) is diagonal (or symmetric) and \(K^T = K\).

Problem 4.2. For example 2.1, verify that \(S^TMS = I\).

\(S = \begin{bmatrix} 0.2357 & 0.2357 \\ 0.7071 & -0.7071 \end{bmatrix}\). \(S^TMS\): diagonal terms \(9(0.2357)^2 + 1(0.7071)^2 = 0.5 + 0.5 = 1\); off-diagonal \(9(0.2357)^2 - (0.7071)^2 = 0.5 - 0.5 = 0\). ✓

Problem 4.3. In example 2.1, which initial displacement gives \(\mathbf r(0) = (1, 0)\), and what does the motion look like?

\(\mathbf x(0) = S\mathbf r(0) = (0.2357, 0.7071)\) mm, proportional to mode 1. The system then vibrates only at \(\sqrt2\) rad/s with \(x_2 = 3x_1\) at all times.

Problem 4.4. For example 2.2, the masses start at rest at \(\mathbf x_0 = \mathbf 0\) and mass 2 is struck to give \(\dot x_2(0) = 0.1\) m/s. Find the modal initial velocities and \(r_1(t)\), \(r_2(t)\).

\(\dot{\mathbf r}(0) = S^{-1}(0, 0.1) = (0.07071, -0.07071)\). With \(\mathbf r(0) = \mathbf 0\): \(r_1 = (0.07071/5.4120)\sin 5.4120t = 0.01307\sin 5.412t\), \(r_2 = -0.00541\sin 13.066t\).

Problem 4.5. Why are the natural frequencies from \(\det(\tilde K - \lambda I) = 0\) the same as from \(\det(K - \omega^2M) = 0\)?

\(\tilde K - \lambda I = M^{-1/2}(K - \lambda M)M^{-1/2}\), so \(\det(\tilde K - \lambda I) = \det(K - \lambda M)/\det M\). Both vanish at the same \(\lambda\).

Steps 1 to 4

\(M^{-1/2} = \mathrm{diag}(1/\sqrt{m_i})\)

\(\tilde K = M^{-1/2}KM^{-1/2}\)

\(\det(\tilde K - \lambda I) = 0\), \(\lambda_i = \omega_i^2\)

\(\hat{\mathbf v}_i = \mathbf v_i/\sqrt{\mathbf v_i^T\mathbf v_i}\), \(P = [\hat{\mathbf v}_1\;\hat{\mathbf v}_2]\)

Steps 5 to 8

\(S = M^{-1/2}P\), \(S^{-1} = P^TM^{1/2}\)

\(\mathbf r(0) = S^{-1}\mathbf x_0\), \(\dot{\mathbf r}(0) = S^{-1}\dot{\mathbf x}_0\)

\(r_i = \frac{\sqrt{\omega_i^2r_{i0}^2 + \dot r_{i0}^2}}{\omega_i}\sin(\omega_it + \tan^{-1}\frac{\omega_ir_{i0}}{\dot r_{i0}})\)

\(\mathbf x = S\mathbf r\)

Checks

\(P^TP = I\), \(P^T\tilde KP = \Lambda\)

\(S^TMS = I\), \(S^TKS = \Lambda\)

Coordinates: \(\mathbf x = M^{-1/2}\mathbf q\), \(\mathbf q = P\mathbf r\)
