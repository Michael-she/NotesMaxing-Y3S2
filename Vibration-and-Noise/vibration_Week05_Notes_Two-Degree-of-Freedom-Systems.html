Undamped two-degree-of-freedom systems

Coupled equations of motion in matrix form, natural frequencies from the characteristic determinant, mode shapes, the free response as a sum of modes, a summary of the term 1 revision lecture, and Tutorial 2.

01Undamped two-degree-of-freedom systems

So far every system needed one coordinate. A multi-degree-of-freedom (MDOF) system needs several. The course uses two-degree-of-freedom (2DOF) systems to build the theory, which carries over to any number of degrees of freedom.

  • The number of degrees of freedom is the number of independent coordinates needed to describe the motion.
  • There is one natural frequency per degree of freedom: two for a 2DOF system.
  • Each natural frequency has a mode shape: a vector giving the relative displacements of the coordinates when the system vibrates at that frequency alone.

The recipe: draw free-body diagrams, write the equations of motion, guess a solution, substitute it to find the natural frequencies and mode shapes, then apply the initial conditions to get the free response.

Equations of motion in matrix form

Figure 1.1: The spring between the masses stretches by \(x_2 - x_1\), so it pulls \(m_1\) with \(k_2(x_2 - x_1)\) and \(m_2\) with \(k_2(x_1 - x_2)\). The force from a connecting spring on one mass is \(k\) times (own displacement minus the other's), directed against it.

Newton's law for each mass gives two equations that each contain both coordinates: they are coupled, ordinary, second-order differential equations with constant coefficients.

\[ m_1\ddot x_1 + (k_1 + k_2)x_1 - k_2x_2 = 0, \qquad m_2\ddot x_2 - k_2x_1 + k_2x_2 = 0. \]
Matrix form\[ \begin{bmatrix} m_1 & 0 \\ 0 & m_2 \end{bmatrix}\begin{Bmatrix} \ddot x_1 \\ \ddot x_2 \end{Bmatrix} + \begin{bmatrix} k_1 + k_2 & -k_2 \\ -k_2 & k_2 \end{bmatrix}\begin{Bmatrix} x_1 \\ x_2 \end{Bmatrix} = \mathbf 0 \quad\Leftrightarrow\quad M\ddot{\mathbf x} + K\mathbf x = \mathbf 0 \]
\(M\)
Mass matrix (kg): diagonal for these coordinates.
\(K\)
Stiffness matrix (N/m): symmetric; off-diagonal terms couple the coordinates.
\(\mathbf x\)
Displacement vector \((x_1, x_2)\) (m).
Intuition

Read \(K\) by columns: column \(j\) holds the forces needed on each mass to hold \(x_j = 1\) with all other coordinates at zero. Pushing \(m_1\) by 1 compresses \(k_1\) and stretches \(k_2\) (force \(k_1 + k_2\) on \(m_1\)) and pulls \(m_2\) back (\(-k_2\)).

Natural frequencies

Guess synchronous harmonic motion, \(\mathbf x(t) = \mathbf ue^{j\omega t}\), with \(\mathbf u\) a constant vector. Then \(\ddot{\mathbf x} = -\omega^2\mathbf ue^{j\omega t}\) and

\[ (-\omega^2M + K)\mathbf ue^{j\omega t} = \mathbf 0. \]

If \((-\omega^2M + K)\) had an inverse, multiplying by it would give \(\mathbf u = \mathbf 0\): no motion. So for a non-trivial solution the matrix must be singular, and a singular matrix has a zero determinant:

Characteristic equation\[ \det(K - \omega^2M) = 0 \;\Rightarrow\; m_1m_2\omega^4 - (m_1k_2 + m_2k_1 + m_2k_2)\omega^2 + k_1k_2 = 0 \]
\(\omega\)
Natural frequency (rad/s); the equation is quadratic in \(\omega^2\).
\(m_1, m_2\)
Masses (kg).
\(k_1, k_2\)
Stiffnesses (N/m).

It is a quadratic in \(\omega^2\), giving \(\omega_1^2\) and \(\omega_2^2\). Each gives \(\omega = \pm\sqrt{\omega_i^2}\): four roots, because of the complex exponential guess. The positive values are the natural frequencies.

Definition

A root \(\omega = 0\) is rigid body motion: the masses move together, in phase with equal amplitude, and no spring is deformed. It happens when the system is not tied to ground.

Mode shapes

Put each \(\omega_i^2\) back into \((K - \omega_i^2M)\mathbf u_i = \mathbf 0\). The matrix is singular, so both rows give the same information: only the ratio \(u_{i2}/u_{i1}\) is fixed. Choose \(u_{i1} = 1\) (any scaling is allowed) and read off \(u_{i2}\) from either row:

Mode shape ratio from row 1\[ \frac{u_{i2}}{u_{i1}} = \frac{k_1 + k_2 - m_1\omega_i^2}{k_2} \]
\(u_{i1}, u_{i2}\)
Relative amplitudes of \(x_1\) and \(x_2\) in mode \(i\).
\(\omega_i\)
Natural frequency of mode \(i\) (rad/s).
Worked example 1.1 Lecture example: frequencies and modes

\(m_1 = 9\) kg, \(m_2 = 1\) kg, \(k_1 = 24\) N/m, \(k_2 = 3\) N/m.

1
\(K - \omega^2M = \begin{bmatrix} 27 - 9\omega^2 & -3 \\ -3 & 3 - \omega^2 \end{bmatrix}\); determinant \((27 - 9\omega^2)(3 - \omega^2) - 9 = 0\).
2
Expand: \(9\omega^4 - 54\omega^2 + 72 = 0\), so \((\omega^2 - 2)(\omega^2 - 4) = 0\).
3
\(\omega_1 = \sqrt2 = 1.414\) rad/s and \(\omega_2 = 2\) rad/s.
4
Mode 1 (\(\omega^2 = 2\)): \((27 - 18)u_{11} = 3u_{12}\), so \(\mathbf u_1 = (1, 3)\).
5
Mode 2 (\(\omega^2 = 4\)): \((27 - 36)u_{21} = 3u_{22}\), so \(\mathbf u_2 = (1, -3)\).
In mode 1 the masses move in phase, \(m_2\) three times as far as \(m_1\). In mode 2 they move out of phase, again with \(m_2\) three times as far.

Figure 1.2: Top: mode 1, both masses swing the same way. Middle: mode 2, they swing against each other, at the higher frequency. Bottom: the free response from \(x_{10} = 1\) mm, \(x_{20} = 0\), which is half of each mode added together.

Free response from initial conditions

The general solution adds both modes, each with its own amplitude and phase (four constants for four initial conditions):

Free response of a 2DOF system\[ \mathbf x(t) = A_1\sin(\omega_1t + \phi_1)\mathbf u_1 + A_2\sin(\omega_2t + \phi_2)\mathbf u_2 \]
\(A_1, A_2\)
Amplitudes of the two modes (m).
\(\phi_1, \phi_2\)
Phases of the two modes (rad).
\(\mathbf u_1, \mathbf u_2\)
Mode shapes.
\(\omega_1, \omega_2\)
Natural frequencies (rad/s).

At \(t = 0\): \(\mathbf x_0 = A_1\sin\phi_1\mathbf u_1 + A_2\sin\phi_2\mathbf u_2\) and \(\mathbf v_0 = A_1\omega_1\cos\phi_1\mathbf u_1 + A_2\omega_2\cos\phi_2\mathbf u_2\). With \(U = [\mathbf u_1\;\mathbf u_2]\), these are two 2×2 systems: solve \(U\mathbf s = \mathbf x_0\) for \(s_i = A_i\sin\phi_i\), and \(U\mathbf q = \mathbf v_0\) for \(q_i = A_i\omega_i\cos\phi_i\). Then \(A_i = \sqrt{s_i^2 + (q_i/\omega_i)^2}\) and \(\phi_i = \operatorname{atan2}(s_i, q_i/\omega_i)\).

Worked example 1.2 Lecture example: free response

Find \(\mathbf x(t)\) for \(x_{10} = 1\) mm, \(x_{20} = 0\) and zero initial velocities.

1
Velocities: \(0 = \sqrt2A_1\cos\phi_1 + 2A_2\cos\phi_2\) and \(0 = 3\sqrt2A_1\cos\phi_1 - 6A_2\cos\phi_2\). Adding 3 × the first to the second: \(6\sqrt2A_1\cos\phi_1 = 0\), so \(\phi_1 = \pi/2\) (since \(A_1 \neq 0\)), and then \(\phi_2 = \pi/2\).
2
Displacements: \(1 = A_1 + A_2\) and \(0 = 3A_1 - 3A_2\), so \(A_1 = A_2 = \tfrac12\) mm.
\(x_1(t) = \tfrac12\cos\sqrt2t + \tfrac12\cos 2t\) mm and \(x_2(t) = \tfrac32\cos\sqrt2t - \tfrac32\cos 2t\) mm.

Figure 1.3: It starts at the lecture case of worked example 1.2. Neither coordinate is periodic at one frequency: because √2 and 2 rad/s are close, the modes drift in and out of step and energy moves from mass 1 to mass 2 and back (the envelope of x₁ first dips at about π/(2 − √2) = 5.4 s). Set x₂₀ = 3 mm (with x₁₀ = 1 mm) to start exactly in mode 1: both masses then move in phase at √2 rad/s for ever, with no beating. Set x₂₀ = −3 mm for pure mode 2. Any other start excites both modes.

Key idea

If the initial displacement is proportional to a mode shape (and the masses start from rest), only that mode is excited and the system vibrates at that single natural frequency. This is how modes are measured: excite one, and watch the shape.

Watch out

The lecture notes write "at the natural frequency \(\omega_{n2} = 2\) rad/s the masses move out of phase" and earlier list "\(\omega_1 = \pm\sqrt{\omega_1^2}\)": these are consistent with the example (\(\omega_1 = \sqrt2\), \(\omega_2 = 2\) rad/s). Keep the modes in order of increasing frequency.

02Term 1 revision

This week's revision video summarises the single-degree-of-freedom work of weeks 1 to 4 ahead of Assessment 1. The points it stresses:

Viscous dampingCoulomb damping
Frequency of oscillation\(\omega_d = \omega_n\sqrt{1-\zeta^2}\)\(\omega_n\) exactly
Decay of the peaksExponential, \(e^{-\zeta\omega_nt}\)Linear, slope \(-2\mu N\omega_n/(\pi k)\)
End of motionTends to zero, never exactlyStops in finite time inside \(\pm\mu_sN/k\)
SolutionOne expression for all time (linear)Piecewise, one stroke at a time (nonlinear)
Measured withLogarithmic decrement \(\to\zeta\)Slope of the envelope \(\to\mu\)
  • Resonance: undamped forcing at \(\omega_n\) grows linearly with slope \(f_0/(2\omega_n)\), so a measured growth rate gives an estimate of the force.
  • Beating (\(\omega\) near \(\omega_n\)) has period \(2\pi/|\omega - \omega_n|\). It is recognised in a time trace by the phase reversal of the fast oscillation where the envelope passes through zero; plain amplitude modulation has no such reversal.
  • Frequency response: with \(s = j\omega\), \(X(j\omega)/F(j\omega) = 1/(k - m\omega^2 + jc\omega)\), whose magnitude gives \(kX/F_0 = 1/\sqrt{(1-r^2)^2 + (2\zeta r)^2}\). This ratio is also the force (or acceleration) transmissibility for a force-driven system.
  • Suspension character: a soft, lightly damped luxury-car suspension isolates well above \(r = \sqrt2\) but moves a lot near resonance; a stiffly damped sports-car suspension moves less at resonance and gives more road feel, at the cost of isolation. Picture the \(X/Y\) curves of week 4.
  • Modelling first: an aircraft wing carrying an engine can be reduced to a cantilever (spring \(3EI/l^3\)) with a tip mass, forced harmonically by the propeller; the propeller shaft to a torsional spring \(GJ_p/l\) carrying a rotational inertia. Choosing the model comes before the mathematics.
Watch out

The revision video says that for Coulomb damping the velocity and acceleration are discontinuous. The acceleration does jump (by \(2\mu N/m\)) when the friction reverses, but the velocity is continuous: it is zero on both sides of every switch. Viscous damping gives continuous displacement, velocity and acceleration.

2

Additional problem 2: overhead crane

A girder (\(EI = 17\times10^9\) N m², span \(L = 10\) m) carries a 2000 kg trolley, which lifts a 50 kg load on a steel rope (\(l = 7\) m, area 710 mm²). Model it as \(m_1\) (trolley) on the girder stiffness \(k_g\), with \(m_2\) (load) hanging from \(m_1\) on the rope stiffness \(k\).

Worked example AP2 Crane natural frequencies

Find the equations of motion, the natural frequencies and the mode shapes.

1
Girder as a simply supported beam with the trolley at mid-span: \(k_g = 48EI/L^3 = 48(17\times10^9)/10^3 = 816\) MN/m.
2
Rope in tension: \(k = EA/l = 207\times10^9(710\times10^{-6})/7 = 21.00\) MN/m (assuming \(E = 207\) GPa for steel).
3
\(\begin{bmatrix} m_1 & 0 \\ 0 & m_2 \end{bmatrix}\ddot{\mathbf x} + \begin{bmatrix} k_g + k & -k \\ -k & k \end{bmatrix}\mathbf x = \begin{Bmatrix} F_0\cos\omega t \\ 0 \end{Bmatrix}\).
4
\(\omega_1 = 594.0\) rad/s (94.5 Hz), \(\omega_2 = 696.9\) rad/s (110.9 Hz).
5
\(\mathbf u_1 = (1, 6.26)\), \(\mathbf u_2 = (1, -6.39)\).
Mode 1: trolley and load move together, the load 6.3 times as far. Mode 2: they move in opposite directions. The two frequencies are close because the girder alone (\(\sqrt{k_g/m_1} = 639\) rad/s) and the rope-load alone (\(\sqrt{k/m_2} = 648\) rad/s) are almost tuned to each other.
Watch out

The tutorial does not give Young's modulus for the rope or say where the trolley sits on the girder. Mid-span and \(E = 207\) GPa are assumptions; state yours in a test. With \(E = 200\) GPa the rope stiffness is 20.3 MN/m and both frequencies shift slightly.

04Practice problems

Problem 3.1. Find the natural frequencies and modes of \(m_1 = 2\) kg, \(m_2 = 1\) kg, \(k_1 = k_2 = 100\) N/m (the layout of Figure 1.1).

\(\det\begin{bmatrix} 200 - 2\omega^2 & -100 \\ -100 & 100 - \omega^2 \end{bmatrix} = 2\omega^4 - 400\omega^2 + 10000 = 0\), so \(\omega^2 = 100 \mp 70.71\): \(\omega_1 = 5.412\) rad/s, \(\omega_2 = 13.07\) rad/s. \(u_2/u_1 = (200 - 2\omega^2)/100\): \(\mathbf u_1 = (1, 1.414)\), \(\mathbf u_2 = (1, -1.414)\).

Problem 3.2. For problem 3.1, what initial displacement excites only mode 2?

Any start proportional to \(\mathbf u_2\), from rest: for example \(x_{10} = 10\) mm, \(x_{20} = -14.14\) mm. The masses then vibrate in antiphase at 13.07 rad/s only.

Problem 3.3. Two equal masses \(m\) on a frictionless track are joined by one spring \(k\) and nothing else. Find the natural frequencies.

\(K = \begin{bmatrix} k & -k \\ -k & k \end{bmatrix}\), so \(\det = (k - m\omega^2)^2 - k^2 = m\omega^2(m\omega^2 - 2k) = 0\). \(\omega_1 = 0\) (rigid body motion, mode (1, 1)) and \(\omega_2 = \sqrt{2k/m}\) (mode (1, −1)).

Problem 3.4. Why is the stiffness matrix symmetric?

The force on mass 1 due to a unit displacement of mass 2 equals the force on mass 2 due to a unit displacement of mass 1: both come from the same connecting spring, \(-k_2\). (Maxwell's reciprocity.)

Problem 3.5. Check the lecture response \(x_2(t) = \tfrac32\cos\sqrt2t - \tfrac32\cos 2t\) against the second equation of motion, \(\ddot x_2 - 3x_1 + 3x_2 = 0\).

\(\ddot x_2 = -3\cos\sqrt2t + 6\cos 2t\); \(-3x_1 = -\tfrac32\cos\sqrt2t - \tfrac32\cos 2t\); \(3x_2 = \tfrac92\cos\sqrt2t - \tfrac92\cos 2t\). Sum: \((-3 - 1.5 + 4.5)\cos\sqrt2t + (6 - 1.5 - 4.5)\cos 2t = 0\) ✓.

Equations of motion

\(M\ddot{\mathbf x} + C\dot{\mathbf x} + K\mathbf x = \mathbf F(t)\)

Chain: \(K = \begin{bmatrix} k_1 + k_2 & -k_2 \\ -k_2 & k_2 + k_3 \end{bmatrix}\)

Frequencies and modes

\(\mathbf x = \mathbf ue^{j\omega t}\Rightarrow(K - \omega^2M)\mathbf u = \mathbf 0\)

\(\det(K - \omega^2M) = 0\)

\(u_{i2}/u_{i1} = (K_{11} - m_1\omega_i^2)/(-K_{12})\)

\(\omega = 0\): rigid body motion

Free response

\(\mathbf x = \sum_i A_i\sin(\omega_it + \phi_i)\mathbf u_i\)

\(U\mathbf s = \mathbf x_0\), \(s_i = A_i\sin\phi_i\)

\(U\mathbf q = \mathbf v_0\), \(q_i = A_i\omega_i\cos\phi_i\)

Simply supported beam, mid-span load: \(48EI/L^3\)
