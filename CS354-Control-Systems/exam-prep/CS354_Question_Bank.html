    S1Second-order response and a zero[12]

    A closed loop has \(T(s) = \dfrac{16}{s^2 + 4s + 16}\).

    (a)

    Find \(\omega_n\), \(\zeta\) and the poles.

    [3]
    (b)

    Estimate \(t_r\), \(t_p\), \(M_p\) and the 2 % \(t_s\).

    [5]
    (c)

    A zero is added, keeping the DC gain: \(T_z(s) = \dfrac{8(s+2)}{s^2 + 4s + 16}\). Predict how the step response changes and explain why. A simulation gives \(M_p = 70\) %; is that plausible?

    [4]
    Memo

    (a)[3]

    \(\omega_n^2 = 16\): \(\omega_n = 4\) rad/s. \(2\zeta\omega_n = 4\): \(\zeta = 0.5\). \(\sigma = 2\), \(\omega_d = 4\sqrt{0.75} = 3.46\) rad/s: poles \(-2 \pm 3.46j\).

    (b)[5]

    \(t_r \approx 1.8/4 = 0.45\) s; \(t_p = \pi/3.46 = 0.907\) s; \(M_p = e^{-\pi(0.5)/0.866} = 16.3\) %; \(t_s = 4/2 = 2.0\) s. (Simulation: 0.41 s, 0.907 s, 16.3 %, 2.02 s.)

    (c)[4]

    \(T_z = \tfrac12(s+2)T\), so \(y_z = y + \tfrac12\dot y\): the zero adds a multiple of the derivative of the original response. The zero sits at \(-2 = -\sigma\), right beside the poles (α = 1 in the FPE plot), so the derivative term is large: much more overshoot and a much faster rise. 70 % is plausible (simulation: 69.9 %, \(t_r = 0.12\) s). The settling time hardly changes, because the poles have not moved.

    S2Steady-state error and PI control[14]

    \(G(s) = \dfrac{10}{(s+2)(s+5)}\) is in a unity feedback loop.

    (a)

    With \(D = k_P\), find \(k_P\) for a 5 % steady-state error to a unit step.

    [3]
    (b)

    Find \(\zeta\) and \(M_p\) with that gain. Is the design acceptable?

    [4]
    (c)

    Use \(D(s) = k_P\dfrac{s+2}{s}\) instead. Explain why the step error is now zero, choose \(k_P\) for \(\zeta = 0.707\), and give \(k_I\), \(M_p\) and \(t_s\).

    [7]
    Memo

    (a)[3]

    Type 0: \(K_p = k_PG(0) = k_P\) and \(e_{ss} = 1/(1 + K_p)\) derive. \(1/(1+k_P) = 0.05\): \(k_P = 19\).

    (b)[4]

    \(s^2 + 7s + 10 + 190 = s^2 + 7s + 200\): \(\omega_n = 14.1\) rad/s, \(\zeta = 7/(2 \times 14.1) = 0.247\), \(M_p = 44.8\) %. Too oscillatory: high proportional gain buys accuracy with damping.

    (c)[7]

    The integrator makes the loop Type 1, so \(K_p = \infty\) and \(e_{ss} = 0\) for a step. The zero cancels the pole at −2: \(DG = \dfrac{10k_P}{s(s+5)}\), \(T = \dfrac{10k_P}{s^2 + 5s + 10k_P}\). \(2\zeta\omega_n = 5\) with \(\zeta = 0.707\): \(\omega_n = 3.54\), so \(10k_P = 12.5\).

    \(k_P = 1.25\), \(k_I = 2k_P = 2.5\) s⁻¹. \(M_p = 4.3\) %, \(t_s = 4/2.5 = 1.6\) s (simulation 1.69 s).

    S3Ziegler-Nichols tuning[10]

    \(G(s) = \dfrac{1}{(s+1)^3}\) is in a unity feedback loop with \(D = K\).

    (a)

    Find the ultimate gain \(K_u\) and period \(P_u\) by substituting \(s = j\omega\).

    [4]
    (b)

    Give the Ziegler-Nichols PI settings as \(k_P\), \(T_I\) and \(k_I\).

    [3]
    (c)

    The tuned loop has a phase margin of 15° and 56 % overshoot. Explain why, and what you would do next.

    [3]
    Memo

    (a)[4]

    \(s^3 + 3s^2 + 3s + 1 + K = 0\) at \(s = j\omega\). Imaginary: \(-\omega^3 + 3\omega = 0\), \(\omega = \sqrt3 = 1.73\) rad/s. Real: \(-3\omega^2 + 1 + K = 0\), \(K_u = 8\). \(P_u = 2\pi/\sqrt3 = 3.63\) s.

    (b)[3]

    Table 4.3 (not on the formula sheet): \(k_P = 0.45K_u = 3.6\), \(T_I = P_u/1.2 = 3.02\) s, \(k_I = k_P/T_I = 1.19\) s⁻¹.

    (c)[3]

    Ziegler-Nichols aims for a quarter decay ratio, roughly \(\zeta \approx 0.2\): fast but poorly damped by design. Treat the settings as a starting point and reduce \(k_P\) (or lengthen \(T_I\)) until the margin and overshoot meet the specification.

    S4Margins and bandwidth[14]

    A unity feedback loop has \(KG(s) = \dfrac{40}{s(s+2)(s+10)}\).

    (a)

    Find the phase crossover frequency and the gain margin. By how much could the gain rise before instability?

    [5]
    (b)

    Find the gain crossover frequency and the phase margin.

    [5]
    (c)

    Estimate \(\zeta\), \(M_p\) and the closed-loop bandwidth. A simulation gives \(M_p = 25\) % and \(\omega_{BW} = 2.66\) rad/s; comment.

    [4]
    Memo

    (a)[5]

    \(\angle KG = -90^\circ - \tan^{-1}(\omega/2) - \tan^{-1}(\omega/10) = -180^\circ\) when \((\omega/2)(\omega/10) = 1\): \(\omega = \sqrt{20} = 4.47\) rad/s. \(|KG| = \dfrac{40}{\sqrt{20}\sqrt{24}\sqrt{120}} = \dfrac{40}{240} = \dfrac16\), so GM \(= 6\) (15.6 dB): the gain could rise to 240.

    (b)[5]

    Solve \(\omega\sqrt{\omega^2+4}\sqrt{\omega^2+100} = 40\) (by trial, or from the asymptotes and a correction): \(\omega_c = 1.56\) rad/s. \(\angle KG = -90^\circ - 37.9^\circ - 8.9^\circ = -136.8^\circ\): PM \(= 43.2^\circ\).

    (c)[4]

    \(\zeta \approx \mathrm{PM}/100 = 0.43\) derive gives \(M_p \approx 22\) %. Bandwidth between \(\omega_c\) and \(2\omega_c\): 1.6 to 3.1 rad/s. The simulation agrees: the third pole is far enough away for the dominant-pair estimates to hold.

    S5Lead design for a Type 1 plant[16]

    \(G(s) = \dfrac{1}{s(s+1)}\) is in unity feedback with \(D(s) = K\dfrac{Ts+1}{\alpha Ts+1}\), \(\alpha \lt 1\). Requirements: \(K_v \ge 10\) and PM \(\ge 50^\circ\).

    (a)

    Find \(K\).

    [2]
    (b)

    Find the crossover frequency and phase margin of \(KG\).

    [4]
    (c)

    Design the lead with a 10° allowance: give \(\alpha\), the new crossover, \(T\) and \(D(s)\).

    [8]
    (d)

    Check the achieved phase margin.

    [2]
    Memo

    (a)[2]

    \(K_v = \lim_{s\to0} sKG = K\) derive: \(K = 10\).

    (b)[4]

    \(\omega\sqrt{\omega^2 + 1} = 10\): \(\omega^4 + \omega^2 - 100 = 0\), \(\omega^2 = 9.51\), \(\omega_c = 3.08\) rad/s. PM \(= 90^\circ - \tan^{-1}3.08 = 18.0^\circ\).

    (c)[8]

    \(\phi_{max} = 50 - 18 + 10 = 42^\circ\); \(\alpha = \dfrac{1-\sin42^\circ}{1+\sin42^\circ} = 0.198\) derive (\(1/\alpha = 5.05\)). New crossover where \(|KG| = \sqrt\alpha = 0.445\): \(\omega\sqrt{\omega^2+1} = 22.5\), \(\omega_c = 4.69\) rad/s. \(T = 1/(\omega_c\sqrt\alpha) = 0.479\) s, \(\alpha T = 0.0949\) s.

    \(D(s) = 10\,\dfrac{0.479s + 1}{0.0949s + 1}\)

    (d)[2]

    At 4.69 rad/s: \(\angle KG = -90^\circ - 78.0^\circ = -168.0^\circ\), plus \(42.0^\circ\) of lead: PM \(= 54.1^\circ\). Met. (Simulated overshoot 18 %.)

    S6Lag design for steady-state accuracy[16]

    \(G(s) = \dfrac{1}{(s+1)(0.1s+1)}\) is in unity feedback with the unity DC gain lag \(D(s) = K\dfrac{Ts+1}{\alpha Ts+1}\), \(\alpha \gt 1\). Requirements: at most 2 % step error and PM \(\ge 50^\circ\).

    (a)

    Find \(K\).

    [3]
    (b)

    Find the phase margin of \(KG\).

    [4]
    (c)

    Design the lag with a 5° allowance and the zero a decade below crossover.

    [7]
    (d)

    State the achieved margin and the cost of the lag.

    [2]
    Memo

    (a)[3]

    Type 0, \(K_p = K\): \(1/(1+K) \le 0.02\) derive gives \(K = 49\).

    (b)[4]

    \((1+\omega^2)(1+0.01\omega^2) = 49^2\): \(\omega_c = 21.0\) rad/s. \(\angle KG = -\tan^{-1}21.0 - \tan^{-1}2.10 = -151.8^\circ\): PM \(= 28.2^\circ\).

    (c)[7]

    New crossover where \(\angle G = -180 + 50 + 5 = -125^\circ\): \(\tan^{-1}\omega + \tan^{-1}0.1\omega = 125^\circ\) gives \(\omega_c = 8.83\) rad/s. \(\alpha = |KG(j8.83)| = 4.13\). \(1/T = \omega_c/10\): \(T = 1.13\) s, \(\alpha T = 4.68\) s.

    \(D(s) = 49\,\dfrac{1.13s + 1}{4.68s + 1}\)

    (d)[2]

    PM \(= 50.6^\circ\), step error 2 %. The crossover falls from 21 to 8.8 rad/s, so the loop is slower than the uncompensated one.

    S7Root locus with complex poles[14]

    Sketch the root locus of \(1 + KL(s) = 0\), \(L(s) = \dfrac{1}{s(s^2 + 4s + 8)}\), for \(K \gt 0\).

    (a)

    Give the real-axis segment and the asymptotes.

    [3]
    (b)

    Find the departure angle from the pole at \(-2 + 2j\).

    [4]
    (c)

    Is there a break-away point?

    [3]
    (d)

    Find the gain and frequency at the imaginary-axis crossing.

    [4]
    Memo

    (a)[3]

    Poles 0 and \(-2 \pm 2j\), no zeros. Real axis: \((-\infty, 0]\). Centroid \((0 - 2 - 2)/3 = -1.33\); angles 60°, 180°, 300°.

    (b)[4]

    At \(-2 + 2j\): angle from the pole at 0 is 135°, from \(-2 - 2j\) is 90°. \(-\phi_{dep} - 135^\circ - 90^\circ = 180^\circ\) gives \(\phi_{dep} = -405^\circ \equiv -45^\circ\): the branch leaves heading down and to the right.

    (c)[3]

    \(\dfrac{d}{ds}(s^3 + 4s^2 + 8s) = 3s^2 + 8s + 8 = 0\) has complex roots \(-1.33 \pm 0.94j\), so there is no break-away: the branch from 0 runs straight left along the real axis.

    (d)[4]

    \(s^3 + 4s^2 + 8s + K = 0\) at \(s = j\omega\): \(\omega^2 = 8\) (imaginary part), \(K = 4\omega^2 = 32\) (real part). Crossing at \(\pm 2.83j\), \(K = 32\).

    S8Canonical forms and a hidden mode[14]

    \(G(s) = \dfrac{2s + 6}{s^3 + 6s^2 + 11s + 6}\).

    (a)

    Write the control canonical form.

    [4]
    (b)

    Test controllability and observability of that realisation.

    [5]
    (c)

    Explain the result by factorising \(G\).

    [3]
    (d)

    Give a second-order realisation that is both controllable and observable.

    [2]
    Memo

    (a)[4]

    \(\mathbf{A}_c = \begin{bmatrix} -6 & -11 & -6 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}\), \(\mathbf{B}_c = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}\), \(\mathbf{C}_c = [0 \;\; 2 \;\; 6]\), \(D = 0\).

    (b)[5]

    Control form is always controllable (\(\det\mathcal{C} = 1\)). \(\mathcal{O} = \begin{bmatrix} \mathbf{C} \\ \mathbf{C}\mathbf{A} \\ \mathbf{C}\mathbf{A}^2 \end{bmatrix} = \begin{bmatrix} 0 & 2 & 6 \\ 2 & 6 & 0 \\ -6 & -22 & -12 \end{bmatrix}\), \(\det\mathcal{O} = 0\): not observable.

    (c)[3]

    \(G = \dfrac{2(s+3)}{(s+1)(s+2)(s+3)}\): the zero cancels the pole at −3, so that mode never reaches the output.

    (d)[2]

    \(G = \dfrac{2}{s^2 + 3s + 2}\): \(\mathbf{A} = \begin{bmatrix} -3 & -2 \\ 1 & 0 \end{bmatrix}\), \(\mathbf{B} = [1 \;\; 0]^T\), \(\mathbf{C} = [0 \;\; 2]\).

    S9Pole placement with Ackermann's formula[12]

    \(\mathbf{A} = \begin{bmatrix} -1 & 1 \\ 0 & -2 \end{bmatrix}\), \(\mathbf{B} = \begin{bmatrix} 0 \\ 1 \end{bmatrix}\), \(\mathbf{C} = [1 \;\; 0]\).

    (a)

    Show the system is controllable.

    [2]
    (b)

    Use Ackermann's formula to place the poles at \(-3 \pm 3j\).

    [7]
    (c)

    Find \(\bar N\) for zero step error.

    [3]
    Memo

    (a)[2]

    \(\mathcal{C} = [\mathbf{B} \;\; \mathbf{A}\mathbf{B}] = \begin{bmatrix} 0 & 1 \\ 1 & -2 \end{bmatrix}\), \(\det = -1\): controllable.

    (b)[7]

    \(\alpha_c(s) = s^2 + 6s + 18\). \(\alpha_c(\mathbf{A}) = \mathbf{A}^2 + 6\mathbf{A} + 18\mathbf{I} = \begin{bmatrix} 1 & -3 \\ 0 & 4 \end{bmatrix} + \begin{bmatrix} -6 & 6 \\ 0 & -12 \end{bmatrix} + \begin{bmatrix} 18 & 0 \\ 0 & 18 \end{bmatrix} = \begin{bmatrix} 13 & 3 \\ 0 & 10 \end{bmatrix}\).

    \(\mathbf{K} = [0 \;\; 1]\,\mathcal{C}^{-1}\alpha_c(\mathbf{A})\) derive. \(\mathcal{C}^{-1} = \begin{bmatrix} 2 & 1 \\ 1 & 0 \end{bmatrix}\), so \([0 \;\; 1]\mathcal{C}^{-1} = [1 \;\; 0]\).

    \(\mathbf{K} = [13 \;\; 3]\). Check: \(\mathrm{tr}(\mathbf{A} - \mathbf{B}\mathbf{K}) = -1 - 5 = -6\) ✓, \(\det = 5 + 13 = 18\) ✓.

    (c)[3]

    \(G = \dfrac{1}{(s+1)(s+2)}\), \(b(0) = 1\): \(\bar N = \alpha_c(0)/b(0) = 18\) derive.

    S10Full-order estimator[10]

    \(\mathbf{A} = \begin{bmatrix} 0 & 1 \\ -2 & -3 \end{bmatrix}\), \(\mathbf{C} = [1 \;\; 0]\).

    (a)

    Show the system is observable.

    [2]
    (b)

    Find \(\mathbf{L}\) for both estimator poles at −10.

    [5]
    (c)

    Why are estimator poles usually 2 to 6 times faster than the controller's, and what stops you making them much faster?

    [3]
    Memo

    (a)[2]

    \(\mathcal{O} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\), \(\det = 1\): observable.

    (b)[5]

    \(\mathbf{A} - \mathbf{L}\mathbf{C} = \begin{bmatrix} -L_1 & 1 \\ -2 - L_2 & -3 \end{bmatrix}\): \(\det[s\mathbf{I} - \mathbf{A} + \mathbf{L}\mathbf{C}] = s^2 + (3 + L_1)s + 2 + 3L_1 + L_2 = s^2 + 20s + 100\).

    \(L_1 = 17\), \(L_2 = 47\): \(\mathbf{L} = [17 \;\; 47]^T\).

    (c)[3]

    The estimate must converge before it is needed, so the estimator error dies out well inside the controller's response and the controller's poles dominate. Very fast poles need large \(\mathbf{L}\), which amplifies sensor noise into the estimate (and so into \(u\)).

    S11Compensator for a double integrator[16]

    A satellite attitude model is \(\ddot y = u\): \(\mathbf{A} = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}\), \(\mathbf{B} = \begin{bmatrix} 0 \\ 1 \end{bmatrix}\), \(\mathbf{C} = [1 \;\; 0]\).

    (a)

    Find \(\mathbf{K}\) for poles at \(-1 \pm j\).

    [4]
    (b)

    Find \(\mathbf{L}\) for estimator poles at −4 (twice).

    [4]
    (c)

    Find \(D_c(s) = \mathbf{K}(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C})^{-1}\mathbf{L}\) (with \(U = -D_cY\)).

    [6]
    (d)

    Is it a lead or a lag, and why must it be for this plant?

    [2]
    Memo

    (a)[4]

    \(\det[s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K}] = s^2 + K_2s + K_1 = s^2 + 2s + 2\): \(\mathbf{K} = [2 \;\; 2]\).

    (b)[4]

    \(\det[s\mathbf{I} - \mathbf{A} + \mathbf{L}\mathbf{C}] = s^2 + L_1s + L_2 = s^2 + 8s + 16\): \(\mathbf{L} = [8 \;\; 16]^T\).

    (c)[6]

    \(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C} = \begin{bmatrix} s+8 & -1 \\ 18 & s+2 \end{bmatrix}\), determinant \(s^2 + 10s + 34\), adjugate \(\begin{bmatrix} s+2 & 1 \\ -18 & s+8 \end{bmatrix}\). \(\mathbf{K}\,\mathrm{adj}\,\mathbf{L} = [2s - 32 \;\;\; 2s + 18]\begin{bmatrix} 8 \\ 16 \end{bmatrix} = 48s + 32\).

    \(D_c(s) = \dfrac{48s + 32}{s^2 + 10s + 34} = 48\,\dfrac{s + 0.667}{s^2 + 10s + 34}\)

    (d)[2]

    Zero at −0.67, poles \(-5 \pm 3j\): lead. A double integrator has −180° of phase at every frequency, so without phase lead there is no phase margin at all. Here the loop has PM = 40.8° at 1.50 rad/s.

    S12ZOH equivalent and the gain limit[14]

    The plant \(G(s) = \dfrac{1}{s+2}\) is driven through a zero-order hold, sampled at \(T = 0.1\) s, and controlled by \(u(k) = K e(k)\) in unity feedback.

    (a)

    Find the ZOH equivalent \(G(z)\).

    [5]
    (b)

    Find the closed-loop pole as a function of \(K\) and the range of \(K\) for stability.

    [5]
    (c)

    With \(K = 5\), find the pole and the steady-state output for a unit step. Compare with the continuous loop.

    [4]
    Memo

    (a)[5]

    \(G(z) = (1 - z^{-1})\mathcal{Z}\{G(s)/s\}\) derive. \(\dfrac{1}{s(s+2)} = \dfrac12\left(\dfrac1s - \dfrac{1}{s+2}\right)\), and the formula-sheet pairs give \(\dfrac12\left(\dfrac{z}{z-1} - \dfrac{z}{z - e^{-0.2}}\right)\). Multiplying by \((z-1)/z\):

    \(G(z) = \dfrac{\tfrac12(1 - e^{-0.2})}{z - e^{-0.2}} = \dfrac{0.0906}{z - 0.8187}\)

    (b)[5]

    \(1 + KG(z) = 0\): \(z = 0.8187 - 0.0906K\). Stable when \(|z| \lt 1\): \(-1 \lt 0.8187 - 0.0906K\), so \(K \lt 20.1\) (and \(K \gt -2\)). The continuous loop is stable for every \(K \gt 0\); sampling sets a limit.

    (c)[4]

    \(z = 0.8187 - 0.453 = 0.366\). Discrete FVT: \(y_{ss} = \lim_{z\to1}(1 - z^{-1})\dfrac{KG}{1+KG}\dfrac{z}{z-1} = \dfrac{0.453}{1 - 0.366} = 0.714\), the same as the continuous \(K/(2+K) = 5/7\): the ZOH equivalent keeps the DC gain.

    S13Sample period and aliasing[12]

    A continuous design has crossover 5 rad/s, PM 50° and closed-loop bandwidth 8 rad/s. It is to be implemented digitally with a ZOH.

    (a)

    Find the longest \(T\) for which the hold costs no more than 10° of phase margin.

    [3]
    (b)

    Is that sample period a good choice? Recommend a range of \(T\) from the sample-rate guidelines.

    [4]
    (c)

    The sensor carries 60 Hz mains pickup. Where does it appear if the loop samples at 25 Hz?

    [3]
    (d)

    What hardware prevents this, and where must it go?

    [2]
    Memo

    (a)[3]

    The hold acts as a delay of \(T/2\) derive: lag \(\omega_cT/2 \le 10^\circ = 0.175\) rad gives \(T \le 2(0.175)/5 = 0.070\) s.

    (b)[4]

    \(\omega_s = 2\pi/0.070 = 90\) rad/s, only 11 times the bandwidth: inside the "poor damping" range (below about 20 times). For 20 to 40 times the bandwidth, \(\omega_s = 160\) to 320 rad/s, so \(T \approx 0.02\) to 0.04 s.

    (c)[3]

    Nyquist is 12.5 Hz. The nearest multiple of 25 Hz to 60 Hz is 50 Hz: \(f_a = |60 - 50| = 10\) Hz.

    (d)[2]

    An analogue anti-alias prefilter, before the ADC. After sampling the alias is indistinguishable from a genuine 10 Hz signal.

    C1From specifications to a root-locus lead[22]

    \(G(s) = \dfrac{1}{s(s+4)}\) in unity feedback must have \(M_p \le 16.3\) % and a 2 % settling time of at most 1 s.

    (a)

    Translate the requirements into a design point \(s_0\).

    [4]
    (b)

    Show that proportional control cannot meet the settling time.

    [4]
    (c)

    Design \(D(s) = K\dfrac{s+5}{s+p}\) to place the dominant poles at \(s_0\).

    [10]
    (d)

    Find \(K_v\) and the third closed-loop pole. The simulated overshoot is 19 %; explain.

    [4]
    Memo

    (a)[4]

    16.3 % needs \(\zeta \ge 0.5\); \(t_s = 4/\sigma \le 1\) needs \(\sigma \ge 4\). With \(\zeta = 0.5\) and \(\sigma = 4\): \(\omega_n = 8\), \(\omega_d = 6.93\). \(s_0 = -4 \pm 6.93j\).

    (b)[4]

    \(s^2 + 4s + K = 0\): for \(K \gt 4\) the poles are \(-2 \pm j\sqrt{K-4}\). The real part is stuck at −2, so \(t_s = 2\) s whatever \(K\).

    (c)[10]

    Angles at \(s_0\): from 0, 120°; from −4, 90°; from the zero at −5, \(\tan^{-1}(6.93/1) = 81.8^\circ\). Angle condition: \(81.8^\circ - 120^\circ - 90^\circ - \phi_p = -180^\circ\), so \(\phi_p = 51.8^\circ\) and \(p = 4 + 6.93/\tan51.8^\circ = 9.45\).

    Magnitude: \(K = \dfrac{|s_0||s_0+4||s_0+9.45|}{|s_0+5|} = \dfrac{8 \times 6.93 \times 8.82}{7.00} = 69.8\).

    \(D(s) = 69.8\,\dfrac{s+5}{s+9.45}\)

    (d)[4]

    \(K_v = \dfrac{69.8 \times 5}{4 \times 9.45} = 9.23\) derive. The pole sum is \(-13.45\), so the third pole is \(-13.45 + 8 = -5.45\), close to the zero at −5: they nearly cancel. The closed-loop zero at −5 still adds a little overshoot above the 16.3 % of a pure second-order pair.

    C2PI design and its difference equation[16]

    A motor speed loop has \(G(s) = \dfrac{4}{s+2}\).

    (a)

    With \(D(s) = k_P\dfrac{s+2}{s}\), find the closed-loop transfer function and choose \(k_P\) for a closed-loop time constant of 0.1 s. Give \(k_I\).

    [5]
    (b)

    Find the steady-state error to a unit ramp.

    [3]
    (c)

    Discretise the PI controller with Tustin's method at \(T = 0.01\) s and give the difference equation.

    [6]
    (d)

    Is \(T = 0.01\) s fast enough?

    [2]
    Memo

    (a)[5]

    \(DG = \dfrac{4k_P}{s}\), so \(Y/R = \dfrac{4k_P}{s + 4k_P}\): a first-order loop with time constant \(1/(4k_P) = 0.1\). \(k_P = 2.5\), \(k_I = 2k_P = 5\) s⁻¹. No overshoot; \(t_s = 4 \times 0.1 = 0.4\) s.

    (b)[3]

    Type 1: \(K_v = \lim_{s\to0} sDG = 4k_P = 10\), \(e_{ss} = 1/K_v = 0.1\) derive.

    (c)[6]

    (a)

    Find \(\mathbf{K}\) for poles at \(-2 \pm 2j\).

    (b)

    Find \(\mathbf{L}\) for estimator poles at −10 (twice).

    [4]
    (c)

    Find the compensator \(D_c(s)\) (with \(U = -D_cY\)).

    C6Integral control is PI control[14]

    A first-order plant with an input disturbance: \(\dot y = -2y + 3(u + w)\).

    (a)

    With \(u = -K_0y + \bar Nr\), find \(y_{ss}\) for constant \(r\) and \(w\). Can \(\bar N\) remove the error?

    [4]
    (b)

    Add \(\dot x_I = y - r\) and \(u = -K_Ix_I - K_0y\). Find \(K_I\) and \(K_0\) for \(\zeta = 0.707\) and a 1 s settling time.

    [6]
    (c)

    Show that this controller is a PI controller, and give \(Y/R\).

    [4]
    Memo

    (a)[4]

    \(0 = -2y + 3(-K_0y + \bar Nr + w)\): \(y_{ss} = \dfrac{3\bar Nr + 3w}{2 + 3K_0}\). \(\bar N = (2 + 3K_0)/3\) fixes \(w = 0\) only; any load leaves an error \(3w/(2 + 3K_0)\).

    (b)[6]

    \(t_s = 4/\sigma = 1\): \(\sigma = 4\); with \(\zeta = 0.707\), poles \(-4 \pm 4j\), \(\alpha_c = s^2 + 8s + 32\). \(\mathbf{A}_a = \begin{bmatrix} 0 & 1 \\ 0 & -2 \end{bmatrix}\), \(\mathbf{B}_a = \begin{bmatrix} 0 \\ 3 \end{bmatrix}\): \(\det[s\mathbf{I} - \mathbf{A}_a + \mathbf{B}_a\mathbf{K}_a] = s^2 + (2 + 3K_0)s + 3K_I\).

    \(K_0 = 2\), \(K_I = 32/3 = 10.7\).

    (c)[4]

    \(U = -\dfrac{K_I}{s}(Y - R) - K_0Y = \dfrac{K_I}{s}E - K_0Y\): integral action on the error and proportional action on the output, a PI controller whose proportional part acts on \(y\) only.     C9Discrete design: the gain limit in the z-plane[14]

    \(G(s) = \dfrac{1}{s(s+1)}\) is driven through a ZOH at \(T = 1\) s, with \(u(k) = Ke(k)\) in unity feedback.

    (a)

    Find the ZOH equivalent \(G(z)\).

    [5]
    (b)

    Find the characteristic equation and the largest stable \(K\).

    [5]
    (c)

    With \(K = 1\), find the closed-loop poles and the equivalent \(\zeta\).

    [4]
    Memo

    (a)[5]

    \(\dfrac{1}{s^2(s+1)} = \dfrac1{s^2} - \dfrac1s + \dfrac1{s+1}\). Formula-sheet pairs: \(\dfrac{Tz}{(z-1)^2} - \dfrac{z}{z-1} + \dfrac{z}{z - e^{-1}}\). Multiply by \((z-1)/z\) and combine:

    \(G(z) = \dfrac{0.3679z + 0.2642}{(z-1)(z - 0.3679)}\)

    (b)[5]

    \((z-1)(z - 0.3679) + K(0.3679z + 0.2642) = 0\): \(z^2 + (0.3679K - 1.3679)z + 0.3679 + 0.2642K = 0\). For complex roots \(|z|^2\) equals the constant term, so \(|z| \lt 1\) needs \(0.3679 + 0.2642K \lt 1\): \(K \lt 2.39\). (The real-root limit, a root at \(z = -1\), would be \(K = 26.4\), so it does not apply first.)

    (c)[4]

    \(z^2 - z + 0.632 = 0\): \(z = 0.5 \pm 0.618j\), \(|z| = 0.795\), \(\angle z = 0.891\) rad. \(z = e^{sT}\): \(s = \ln z = -0.229 \pm 0.891j\), so \(\zeta = 0.229/0.920 = 0.25\). The continuous loop with \(K = 1\) has \(\zeta = 0.5\): a slow sample rate costs damping.

    [4]
    Memo

    (a)[4]
