Q1Specifications and PID control[26]

The plant

\[ G(s) = \frac{4}{(s+1)(s+4)} \]

must give a unit-step response that meets all three requirements:

  1. overshoot \(M_p \le 10\) %;
  2. 2 % settling time \(t_s \le 2.5\) s;
  3. zero steady-state error, \(y_{ss} = 1\).
(a)

The plant is driven open loop, with no controller. Find its poles and use the Final Value Theorem to find \(y_{ss}\) for a unit step. State, with reasons, which of the three requirements are met.

[6]
(b)

The plant is placed in a unity negative feedback loop with proportional control \(D(s) = k_P\).

(i)

Find the closed-loop transfer function, and express \(\omega_n\) and \(\zeta\) in terms of \(k_P\).

(4)
(ii)

Find the largest \(k_P\) that meets requirement 1.

(4)
(iii)

With that gain, find \(t_s\) and the steady-state error to a unit step. Which requirements are met?

(4)
[12]
(c)

The controller is changed to the PI controller \(D(s) = k_P\,\dfrac{s+1}{s}\), so that its zero cancels the plant pole at \(-1\).

(i)

Using system type, explain why this controller removes the steady-state error to a step.

(3)
(ii)

Find the range of \(k_P\) that meets requirement 1, choose \(k_P = 2.5\), and estimate \(t_r\), \(t_p\), \(M_p\) and \(t_s\). Do all three requirements hold?

(5)
[8]
Memo for question 1

(a)[6]

Poles at \(s = -1\) and \(s = -4\): real, so the step response has no overshoot and requirement 1 holds. FVT: \(sY(s) = G(s)\) has its poles in the LHP, so \(y_{ss} = \lim_{s\to0} sG(s)\tfrac{1}{s} = G(0) = 4/4 = 1\): requirement 3 holds. The slow pole sets the settling time: \(\sigma = 1\) gives \(t_s \approx 4/\sigma = 4\) s, so requirement 2 fails. (Exactly, \(y = 1 - \tfrac43 e^{-t} + \tfrac13 e^{-4t}\), which settles at 4.2 s.)

(b)[12]

(i) \(T(s) = \dfrac{4k_P}{s^2 + 5s + 4 + 4k_P}\). Matching \(s^2 + 2\zeta\omega_n s + \omega_n^2\): \(\omega_n = \sqrt{4 + 4k_P}\) and \(2\zeta\omega_n = 5\), so \(\zeta = \dfrac{5}{2\sqrt{4+4k_P}}\).

(ii) From \(\ln M_p = -\pi\zeta/\sqrt{1-\zeta^2}\) with \(M_p = 0.1\): \(\zeta = \dfrac{-\ln M_p}{\sqrt{\pi^2 + \ln^2 M_p}} = 0.591\) derive (rearrange the formula-sheet relation). Then \(\sqrt{4+4k_P} \le 5/(2 \times 0.591) = 4.23\), so \(k_P \le 3.47\).

(iii) \(\sigma = \zeta\omega_n = 2.5\) for every \(k_P\), so \(t_s = 4/2.5 = 1.6\) s: requirement 2 holds. The loop is Type 0 with \(K_p = k_P G(0) = 3.47\), so \(e_{ss} = 1/(1 + K_p) = 0.224\) derive: requirement 3 fails. Raising \(k_P\) to cut the error breaks requirement 1.

(c)[8]

(i) The integrator puts a pole at \(s = 0\) in \(DG\), making the loop Type 1. Then \(K_p = \lim_{s\to0} DG = \infty\) and \(e_{ss} = \lim_{s\to0} s\,\dfrac{1}{1+DG}\,\dfrac1s = 0\) for a step.

(ii) \(DG = \dfrac{4k_P}{s(s+4)}\), so \(T = \dfrac{4k_P}{s^2 + 4s + 4k_P}\): \(\omega_n = 2\sqrt{k_P}\), \(\zeta = 1/\sqrt{k_P}\). Requirement 1 needs \(\zeta \ge 0.591\), so \(k_P \le 2.86\) (and \(k_P \gt 1\) for complex poles; below that there is no overshoot at all). With \(k_P = 2.5\): \(\omega_n = 3.16\) rad/s, \(\zeta = 0.632\), \(\omega_d = \sqrt{10 - 4} = 2.45\) rad/s.

\(t_r \approx 1.8/\omega_n = 0.57\) s, \(t_p = \pi/\omega_d = 1.28\) s, \(M_p = e^{-\pi(0.632)/0.775} = 7.7\) %, \(t_s = 4/\sigma = 4/2 = 2.0\) s. All three requirements hold. (Simulation: \(t_r = 0.61\) s, \(t_p = 1.28\) s, \(M_p = 7.7\) %, \(t_s = 1.89\) s.)

\(k_P = 2.5\), \(k_I = 2.5\): \(D(s) = 2.5(s+1)/s\). The cancelled pole at \(-1\) stays in the loop: it is invisible from the reference but still sets a slow 4 s decay for a disturbance entering at the plant input.

Q2Frequency-response lead design[26]

The plant

\[ G(s) = \frac{10}{s(s+2)} \]

is placed in unity feedback with the lead compensator

\[ D(s) = K\,\frac{Ts+1}{\alpha Ts+1}, \qquad 0 \lt \alpha \lt 1. \]

The closed loop must have a steady-state error of at most 0.05 to a unit ramp, and a phase margin of at least 45°.

(a)

Find the gain \(K\) that meets the ramp-error requirement.

[4]
(b)

With this \(K\) and no lead network, find the gain crossover frequency and the phase margin. Is the requirement met?

[6]
(c)

Design the lead network, allowing 10° extra for the shift in crossover. Give \(\alpha\), \(T\), the new crossover frequency and \(D(s)\) with all values substituted.

[12]
(d)

Check the phase margin of the compensated loop, and use the formula sheet's \(M_p\) against phase margin figure to estimate the overshoot. A simulation shows 22 % overshoot. Explain the difference.

[4]
Memo for question 2

(a)[4]

Type 1 loop: \(K_v = \lim_{s\to0} sDG = 10K/2 = 5K\) and \(e_{ss} = 1/K_v\) derive. \(1/K_v \le 0.05\) needs \(K_v \ge 20\), so \(K = 4\).

(b)[6]

\(|KG(j\omega)| = \dfrac{40}{\omega\sqrt{\omega^2 + 4}} = 1\) gives \(\omega^4 + 4\omega^2 - 1600 = 0\), so \(\omega^2 = 38.05\) and \(\omega_c = 6.17\) rad/s. \(\angle KG = -90^\circ - \tan^{-1}(6.17/2) = -162.0^\circ\), so PM \(= 18.0^\circ\). The requirement fails.

(c)[12]

Phase needed: \(\phi_{max} = 45^\circ - 18^\circ + 10^\circ = 37^\circ\). From \(\sin\phi_{max} = \dfrac{1-\alpha}{1+\alpha}\) derive (or read \(1/\alpha \approx 4\) from the formula-sheet figure): \(\alpha = \dfrac{1 - \sin 37^\circ}{1 + \sin 37^\circ} = 0.249\).

The lead adds gain \(1/\sqrt\alpha\) at \(\omega_{max}\), so put \(\omega_{max}\) where \(|KG| = \sqrt\alpha = 0.499\) (−6.0 dB): \(\omega\sqrt{\omega^2+4} = 40/0.499 = 80.2\), giving \(\omega_c = 8.85\) rad/s.

\(\omega_{max} = 1/(T\sqrt\alpha)\) (formula sheet): \(T = \dfrac{1}{8.85 \times 0.499} = 0.227\) s and \(\alpha T = 0.0564\) s.

\(D(s) = 4\,\dfrac{0.227s + 1}{0.0564s + 1}\): zero at −4.41 rad/s, pole at −17.7 rad/s.

(d)[4]

At 8.85 rad/s, \(\angle KG = -90^\circ - \tan^{-1}4.42 = -167.3^\circ\) and the lead adds \(37.0^\circ\), so PM ≈ 49.7°: the requirement holds. The figure gives \(M_p \approx 0.2\) at a 50° margin. The figure assumes a standard second-order loop with no zeros; the lead's zero at −4.41 rad/s also appears in the closed loop, and a zero this close to the dominant poles adds overshoot (week 1, effect of a zero). The closed-loop poles are \(-6.68 \pm 8.15j\) and −6.39.

Q3Root-locus design[28]

The plant

\[ G(s) = \frac{1}{s(s+1)(s+5)} \]

is placed in a unity negative feedback loop. Use the root-locus method throughout.

3.1

With proportional control \(D = K\), sketch the root locus for \(K \gt 0\). Give the real-axis segments, the centroid and angles of the asymptotes, the break-away point, and the gain and frequency at which the locus crosses the imaginary axis.

[10]
3.2

Find the gain \(K\) that gives dominant closed-loop poles with \(\zeta = 0.5\). Find the third closed-loop pole, and estimate the settling time and the velocity error constant \(K_v\).

[8]
3.3

The dominant poles must instead sit at \(s_0 = -2 \pm j2\sqrt3\) (\(\zeta = 0.5\), \(\omega_n = 4\) rad/s). Design the lead compensator \(D(s) = K\,\dfrac{s+1}{s+p}\), whose zero cancels the plant pole at −1. Use the angle condition to find \(p\) and the magnitude condition to find \(K\). Give \(K_v\) and comment on the cancellation.

[10]
Memo for question 3

3.1[10]

\(1 + KL(s) = 0\) with \(L = \dfrac{1}{s(s+1)(s+5)}\): three poles, no zeros, so three branches start at 0, −1 and −5 and all go to infinity.

  • Real axis: \([-1, 0]\) and \((-\infty, -5]\) (left of an odd number of poles and zeros).
  • Asymptotes: centroid \(\alpha = (0 - 1 - 5)/3 = -2\); angles \((180^\circ + 360^\circ(l-1))/3 = 60^\circ, 180^\circ, 300^\circ\).
  • Break-away: \(\dfrac{d}{ds}(s^3 + 6s^2 + 5s) = 3s^2 + 12s + 5 = 0\) gives \(s = -0.473\) or \(-3.53\). Only −0.473 lies on the locus.
  • Imaginary axis: substitute \(s = j\omega\) into \(s^3 + 6s^2 + 5s + K = 0\). Imaginary part: \(-\omega^3 + 5\omega = 0\), so \(\omega = \sqrt5 = 2.24\) rad/s. Real part: \(K = 6\omega^2 = 30\).

3.2[8]

\(\zeta = 0.5\) is the line at 120° from the positive real axis (θ = 30° from the imaginary axis). Searching along it for \(\angle L = -180^\circ\) gives \(s = -0.417 \pm 0.722j\) (\(\omega_n = 0.833\) rad/s). Magnitude condition: \(K = |s||s+1||s+5| = 3.59\).

The closed-loop poles sum to −6 (the \(s^2\) coefficient), so the third pole is at \(-6 + 2(0.417) = -5.17\): far enough left to leave the pair dominant. \(t_s \approx 4/0.417 = 9.6\) s and \(K_v = \lim_{s\to0} sKL = K/5 = 0.72\).

3.3[10]

With the zero cancelling the pole at −1, the loop is \(\dfrac{K}{s(s+5)(s+p)}\). Angles at \(s_0 = -2 + 3.464j\): from 0, \(120.0^\circ\); from −5, \(\tan^{-1}(3.464/3) = 49.1^\circ\). The angle condition needs \(120.0^\circ + 49.1^\circ + \phi_p = 180^\circ\), so \(\phi_p = 10.9^\circ\) and \(p = 2 + 3.464/\tan 10.9^\circ = 20.0\).

Magnitude condition: \(K = |s_0||s_0 + 5||s_0 + 20| = 4 \times 4.583 \times 18.33 = 336\).

\(D(s) = 336\,\dfrac{s+1}{s+20}\), \(K_v = 336/(5 \times 20) = 3.36\): almost five times the proportional design, with \(t_s \approx 4/2 = 2\) s.

The other closed-loop poles are −21.0 and −1. The pole at −1 is cancelled by the compensator zero in \(Y/R\), so it does not show in the step response; it still appears in the response to a disturbance at the plant input, and an imperfect cancellation would leave a slow, small tail.
