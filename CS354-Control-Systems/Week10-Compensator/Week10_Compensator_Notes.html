Compensator design and integral control

Feeding back the state estimate, the separation principle, the compensator transfer function, where the command should enter, and integral control for tracking that survives model errors. Built from the Week 10 folder: the HTML lecture deck, the 2020 Ch 7.8 to 7.10 slides and Tutorial 8.

01Three pieces, one controller

Weeks 8 and 9 produced three pieces, each designed on its own: the control law \(u = -\mathbf{K}\mathbf{x}\) (placing \(\alpha_c\)), the estimator with gain \(\mathbf{L}\) (placing \(\alpha_e\)), and the reference gain \(\bar N\). This week connects them, in three parts:

  1. FPE 7.8: can the control law use \(\hat{\mathbf{x}}\) in place of \(\mathbf{x}\)? (The separation principle and the compensator.)
  2. FPE 7.9: where should the command \(r\) enter the loop?
  3. FPE 7.10: how do we get zero steady-state error when the model is not exact? (Integral control.)

\(\mathbf{K}\)
Control gain from week 8.
\(\mathbf{L}\)

02Feeding back the estimate: the separation principle

The only possible control law when \(\mathbf{x}\) is not measured is \(u = -\mathbf{K}\hat{\mathbf{x}}\). Substitute it into the plant and write \(\hat{\mathbf{x}} = \mathbf{x} - \tilde{\mathbf{x}}\): \(\dot{\mathbf{x}} = (\mathbf{A} - \mathbf{B}\mathbf{K})\mathbf{x} + \mathbf{B}\mathbf{K}\tilde{\mathbf{x}}\). The error still obeys \(\dot{\tilde{\mathbf{x}}} = (\mathbf{A} - \mathbf{L}\mathbf{C})\tilde{\mathbf{x}}\). Stacking:

Closed loop in state and error coordinates (FPE 7.8)\[ \begin{bmatrix} \dot{\mathbf{x}} \\ \dot{\tilde{\mathbf{x}}} \end{bmatrix} = \begin{bmatrix} \mathbf{A} - \mathbf{B}\mathbf{K} & \mathbf{B}\mathbf{K} \\ \mathbf{0} & \mathbf{A} - \mathbf{L}\mathbf{C} \end{bmatrix}\begin{bmatrix} \mathbf{x} \\ \tilde{\mathbf{x}} \end{bmatrix} \]
\(\mathbf{B}\mathbf{K}\tilde{\mathbf{x}}\)
Extra input to the controlled plant caused by the estimate error.
\(\mathbf{0}\)
The state never affects the error: the matrix is block (upper) triangular.

The determinant of a block-triangular matrix is the product of the determinants of its diagonal blocks, so the characteristic equation factors:

Separation principle (FPE 7.170)\[ \det(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K})\cdot\det(s\mathbf{I} - \mathbf{A} + \mathbf{L}\mathbf{C}) = \alpha_c(s)\,\alpha_e(s) = 0 \]
\(\alpha_c(s)\)
The n control poles placed by K.
\(\alpha_e(s)\)
The n estimator poles placed by L.
Key idea

The \(2n\) closed-loop poles are exactly the control poles plus the estimator poles. Neither design moves the other's poles, so \(\mathbf{K}\) and \(\mathbf{L}\) are designed separately, one after the other. Here: \(-3.5 \pm 3.43j\), −12, −15.

Watch out

Two cautions. The zero block appears only because the estimator uses the same \(\mathbf{A}, \mathbf{B}, \mathbf{C}\) as the plant: with a model error it is no longer zero and the poles move, so the separation principle says nothing about how the loop copes with model errors. And only the poles are fixed: the response to a command also depends on the zeros, which depend on where \(r\) enters (section 4).

03The compensator transfer function

Inside the dashed box of Figure 3.1 the estimator, with \(u = -\mathbf{K}\hat{\mathbf{x}}\) substituted, is one dynamic system with input \(y\) and output \(u\):

Compensator (FPE 7.174)\[ \begin{gathered} \dot{\hat{\mathbf{x}}} = (\mathbf{A} - \mathbf{B}\mathbf{K} - \mathbf{L}\mathbf{C})\hat{\mathbf{x}} + \mathbf{L}y, \quad u = -\mathbf{K}\hat{\mathbf{x}} \\ \Rightarrow\;\; D_c(s) = \frac{U(s)}{Y(s)} = -\mathbf{K}(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C})^{-1}\mathbf{L} \end{gathered} \]
\(D_c(s)\)
Compensator transfer function, defined by \(U = D_cY\) (the deck's convention).
\(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C}\)
Its characteristic matrix: the compensator's own poles are never specified, are not closed-loop poles, and need not even be stable.
Watch out

Two sign conventions. The lecture deck defines \(D_c = -\mathbf{K}(\cdots)^{-1}\mathbf{L}\) with \(U = D_cY\), so the loop equation is \(1 - GD_c = 0\). Tutorial 8 (and FPE) define \(D_c = \mathbf{K}(\cdots)^{-1}\mathbf{L}\) with \(U = -D_cY\), so the loop equation is \(1 + GD_c = 0\). They describe the same controller; only the sign of \(D_c\) differs. State which one you use.

Worked example 3.1 Compensator for the running example

Find the compensator, its poles and zero, and check the closed-loop polynomial.

1
\(\mathbf{B}\mathbf{K} = \begin{bmatrix} 3 & - \frac{1}{2} \\ 6 & -1 \end{bmatrix}\), \(\mathbf{L}\mathbf{C} = \begin{bmatrix} 22 & 0 \\ 86 & 0 \end{bmatrix}\), so \(\mathbf{A} - \mathbf{B}\mathbf{K} - \mathbf{L}\mathbf{C} = \begin{bmatrix} -26 & \frac{3}{2} \\ -94 & -3 \end{bmatrix}\).
2
\(\det(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C}) = s^2 + 29s + 219\): compensator poles \(-14.5 \pm 2.96j\).
3
\(\mathrm{adj}\cdot\mathbf{L}\), then \(-\mathbf{K}\) times it, gives the numerator: \(D_c(s) = \dfrac{-(23s + 501)}{s^2 + 29s + 219}\) (deck sign), i.e. \(\dfrac{23s + 501}{s^2 + 29s + 219}\) in the tutorial's sign.
4
Loop check: \[\begin{gathered}(s^2 + 5s + 6)(s^2 + 29s + 219) - (s + 6)\cdot(-(23s + 501)) \\ = s^{4} + 34 s^{3} + 393 s^{2} + 1908 s + 4320\end{gathered}\]
5
\((s^2 + 7s + 24)(s+12)(s+15)\) expands to the same polynomial ✓.
\(D_c\) has DC gain \(501/219 = 2.29\), a zero at \(-21.78\) and poles at \(-14.5 \pm 2.96j\). The zero lies further from the origin than the poles, so in classical terms it is lag-shaped. Nobody drew a root locus to get it, and its poles appear nowhere among the closed-loop poles.

04Where the command enters

The most general linear way to bring in \(r\) adds a term proportional to it to each equation:

General command input (FPE 7.9)\[ \dot{\hat{\mathbf{x}}} = (\mathbf{A} - \mathbf{B}\mathbf{K} - \mathbf{L}\mathbf{C})\hat{\mathbf{x}} + \mathbf{L}y + \mathbf{M}r, \qquad u = -\mathbf{K}\hat{\mathbf{x}} + \bar Nr \]
\(\mathbf{M}\)
n × 1 vector: how the command reaches the estimator.
\(\bar N\)
Scalar reference gain.

\(r\) is external, so \(\mathbf{M}\) and \(\bar N\) never enter the characteristic equation: they set the zeros from \(r\) to \(y\), and so the transient. The estimator's job is to estimate \(\mathbf{x}\), so the command should move the plant without disturbing the estimate. Subtracting the equations gives \(\dot{\tilde{\mathbf{x}}} = (\mathbf{A} - \mathbf{L}\mathbf{C})\tilde{\mathbf{x}} + (\mathbf{B}\bar N - \mathbf{M})r\), and the command drops out when

Autonomous estimator, configuration (a)\[ \begin{gathered} \mathbf{M} = \mathbf{B}\bar N \;\;\Rightarrow\;\; \dot{\hat{\mathbf{x}}} = \mathbf{A}\hat{\mathbf{x}} + \mathbf{B}u + \mathbf{L}(y - \mathbf{C}\hat{\mathbf{x}}), \\ \frac{Y(s)}{R(s)} = \bar N\mathbf{C}(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K})^{-1}\mathbf{B} = \frac{\bar Nb(s)}{\alpha_c(s)} \end{gathered} \]
\(\mathbf{M} = \mathbf{B}\bar N\)
Autonomous estimator: the estimate error has no input.
\(b(s)\)
Plant numerator (state feedback does not move zeros).
\(\alpha_c(s)\)
Control characteristic polynomial only: the estimator poles cancel.

This is the week 9 estimator driven by the actual plant input \(u\), command included: compute \(u = -\mathbf{K}\hat{\mathbf{x}} + \bar Nr\) first and feed the same \(u\) to plant and estimator (configuration (a), Figure 3.1). The full \(2n\)-state transfer function has denominator \(\alpha_c\alpha_e\), so its numerator must contain \(\alpha_e\): the estimator poles are cancelled by zeros, and the command response is exactly the full-state-feedback response of week 9, whatever \(\mathbf{L}\) is. The estimator poles show only when there is an error to correct (a wrong \(\hat{\mathbf{x}}(0)\), a disturbance). A practical bonus: actuator saturation can be copied inside the estimator.

Worked example 4.1 Configurations (a) and (b) compared

For the running example, give \(Y/R\) for configuration (a), and for configuration (b), where the compensator is fed \(y - r\) instead of \(y\) (\(\mathbf{M} = -\mathbf{L}\), \(\bar N = 0\)).

1
(a): \(\bar N\) is the week 9 value, 4: \(\dfrac{Y}{R} = \dfrac{4(s+6)\,\cancel{(s+12)(s+15)}}{(s^2 + 7s + 24)\,\cancel{(s+12)(s+15)}} = \dfrac{4(s+6)}{s^2 + 7s + 24}\), DC gain 1.
2
(b): \(U = D_c(Y - R)\) gives \(\dfrac{Y}{R} = \dfrac{-GD_c}{1 - GD_c} = \frac{\left(s + 6\right) \left(23 s + 501\right)}{\left(s + 12\right) \left(s + 15\right) \left(s^{2} + 7 s + 24\right)}\).
Same four poles in both. In (b) the estimator poles are not cancelled, the compensator zero at −21.8 enters the command response, and the DC gain is \(\frac{167}{240} \approx 0.696\), not 1, because no \(\bar N\) is designed. Configuration (b) is the classical unity-feedback arrangement of weeks 4 to 6, and the only option when the sensor measures only the error.

05Integral control and robust tracking

\(\bar N = \alpha_c(0)/b(0)\) is computed from the model, so it gives zero error only if the model is exact, and it does nothing about a constant disturbance at the plant input. The cure is the one from weeks 2 and 3: integrate the error. A constant non-zero error would integrate into an ever-growing control, so the only possible steady state has zero error, and that argument uses no model at all. In state space the integral of the error becomes one extra state:

Integral control (FPE 7.10.1)\[ \begin{gathered} \dot x_I = \mathbf{C}\mathbf{x} - r = e, \\ \begin{bmatrix} \dot x_I \\ \dot{\mathbf{x}} \end{bmatrix} = \begin{bmatrix} 0 & \mathbf{C} \\ \mathbf{0} & \mathbf{A} \end{bmatrix}\begin{bmatrix} x_I \\ \mathbf{x} \end{bmatrix} + \begin{bmatrix} 0 \\ \mathbf{B} \end{bmatrix}u - \begin{bmatrix} 1 \\ \mathbf{0} \end{bmatrix}r + \begin{bmatrix} 0 \\ \mathbf{B}_1 \end{bmatrix}w, \\ u = -[\,K_1 \;\; \mathbf{K}_0\,]\begin{bmatrix} x_I \\ \mathbf{x} \end{bmatrix} \end{gathered} \]
\(x_I\)
Integral state, \(\int_0^t(y - r)\,d\tau\). Note \(e = y - r\), the opposite of the usual sign; it only flips the sign of \(K_1\).
\(\mathbf{A}_a,\,\mathbf{B}_a\)
Augmented matrices \(\begin{bmatrix} 0 & \mathbf{C} \\ \mathbf{0} & \mathbf{A} \end{bmatrix}\) and \(\begin{bmatrix} 0 \\ \mathbf{B} \end{bmatrix}\).
\(K_1,\,\mathbf{K}_0\)
Gain on the integral state and on the plant state.
\(w\)
Disturbance entering through \(\mathbf{B}_1\).

Recipe: test controllability of \((\mathbf{A}_a, \mathbf{B}_a)\); choose \(n + 1\) poles; find \([K_1\;\;\mathbf{K}_0]\) by comparing coefficients or Ackermann, exactly as in week 8. Augmentation fails if the plant has a zero at the origin, which would cancel the new integrator pole: test \(\mathcal{C}_a\), not \(\mathcal{C}\). When \(\mathbf{x}\) is estimated, only the plant state needs an estimator; \(x_I\) is computed inside the controller and is known exactly, so \(\mathbf{L}\) is the week 9 design.

Worked example 5.1 Integral control of the running example

Replace \(\bar N\) with integral control, keeping the dominant pair of \(s^2 + 7s + 24\) and adding a third pole at −10.

1
\(\mathbf{A}_a = \begin{bmatrix} 0 & 1 & 0 \\ 0 & -1 & 1 \\ 0 & -2 & -4 \end{bmatrix}\), \(\mathbf{B}_a = \begin{bmatrix} 0 \\ 1 \\ 2 \end{bmatrix}\). \(\mathcal{C}_a = [\mathbf{B}_a\;\;\mathbf{A}_a\mathbf{B}_a\;\;\mathbf{A}_a^2\mathbf{B}_a] = \begin{bmatrix} 0 & 1 & 1 \\ 1 & 1 & -11 \\ 2 & -10 & 38 \end{bmatrix}\), \(\det = -72 \ne 0\) ✓.
2
\(\alpha_c(s) = (s + 10)(s^2 + 7s + 24) = s^3 + 17s^2 + 94s + 240\).
3
Expanding \(\det[s\mathbf{I} - (\mathbf{A}_a - \mathbf{B}_a\mathbf{K})]\) with \(\mathbf{K} = [K_1\;\;K_{01}\;\;K_{02}]\) gives \(s^3 + (5 + K_{01} + 2K_{02})s^2 + (6 + K_1 + 6K_{01})s + 6K_1\).
4
Match from the constant up: \(6K_1 = 240 \Rightarrow K_1 = 40\); \(6 + 40 + 6K_{01} = 94 \Rightarrow K_{01} = 8\); \(5 + 8 + 2K_{02} = 17 \Rightarrow K_{02} = 2\).
\(\mathbf{K} = [\,K_1 \;\; \mathbf{K}_0\,] = \begin{bmatrix} 40 & 8 & 2 \end{bmatrix}\). Substituting back gives \(s^3 + 17s^2 + 94s + 240\) ✓. The state gains have grown from \([3\;\;-0.5]\) to \([8\;\;2]\): the loop now also carries an integrator without losing damping.

Why the error is exactly zero. In any steady state every derivative is zero, so \(\dot x_I = y_{ss} - r = 0\). That used none of \(\mathbf{A}\), \(\mathbf{B}\), \(\mathbf{C}\), only the structure of the controller. Change the plant and the poles move (so the transient changes), but while the loop stays stable the steady-state error stays exactly zero, and a constant input disturbance is rejected by the same argument.

Figure 5.1: With the exact model \(\bar N\) reaches 1 (dashed). With the model error it settles at 0.952 before the disturbance and is pushed to 1.07 after it. Integral control reaches 1.000 in both phases, with or without the estimator.

07Practice problems

Problem 1. Tutorial 8: \(\mathbf{A} = \begin{bmatrix} 0 & 1 \\ -5 & -6 \end{bmatrix}\), \(\mathbf{B} = [0\;\;1]^T\), \(\mathbf{C} = [1\;\;0]\). Find \(\mathbf{K}\) for poles \(-4 \pm 4j\) and \(\mathbf{L}\) for estimator poles at −12 (twice).

\(\alpha_c = s^2 + 8s + 32\): \(\mathbf{K} = [27\;\;2]\) (\(\zeta = 0.707\), \(\omega_n = 5.66\), \(t_s = 1.15\) s). \(\alpha_e = s^2 + 24s + 144\): \(\det[s\mathbf{I} - \mathbf{A} + \mathbf{L}\mathbf{C}] = s^2 + (6 + L_1)s + (5 + 6L_1 + L_2)\), so \(\mathbf{L} = [18\;\;31]^T\).

Problem 2. Find the compensator for that design in the tutorial's convention \(D_c = \mathbf{K}(s\mathbf{I} - \mathbf{A} + \mathbf{B}\mathbf{K} + \mathbf{L}\mathbf{C})^{-1}\mathbf{L}\).

\(D_c(s) = \dfrac{548s + 3573}{s^2 + 26s + 207}\): zero −6.52, poles \(-13 \pm 6.16j\), DC gain 17.26. The zero is closer to the origin than the poles: predominantly lead.

Problem 3. Give \(\bar N\) for that design and show that \(\mathbf{M} = \mathbf{B}\bar N\) removes \(r\) from the error equation.

\(\bar N = \alpha_c(0)/b(0) = 32\). \(\dot{\tilde{\mathbf{x}}} = (\mathbf{A} - \mathbf{L}\mathbf{C})\tilde{\mathbf{x}} + (\mathbf{B}\bar N - \mathbf{M})r\), which is \((\mathbf{A} - \mathbf{L}\mathbf{C})\tilde{\mathbf{x}}\) when \(\mathbf{M} = \mathbf{B}\bar N\). With \(\mathbf{M} = \mathbf{0}\) the command would drive the error, exciting the estimator poles on every step.

Problem 4. Integral control for the Tutorial 8 plant with poles \(-4 \pm 4j\) and −8.

\(\mathbf{A}_a = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ 0 & -5 & -6 \end{bmatrix}\), \(\mathbf{B}_a = [0\;\;0\;\;1]^T\), \(\det\mathcal{C}_a = -1\). Companion form: \(s^3 + (6 + K_3)s^2 + (5 + K_2)s + K_1 = s^3 + 16s^2 + 96s + 256\), so \(\mathbf{K}_a = [256\;\;91\;\;10]\). With the stiffness 6 instead of 5, the \(\bar N\) design settles at 0.970 (0.957 with the estimator); integral control at exactly 1.

08Formula sheet

Separation
