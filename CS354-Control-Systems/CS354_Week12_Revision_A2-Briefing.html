01The A2 paper

  • Difficulty is similar to A1.

  • Term 4 adds chapters 7 and 8: state-space theory and design, then digital control.

02How marks are given

Many marks are for the process. A correct final answer on its own will not earn full marks, and this cost marks in A1. The lecturer listed four habits.

  1. Work from first principles. If you use a shortcut such as an error constant, show how it follows from the first-principles route.
  2. Say where every equation comes from, and where every variable you substitute into it comes from.
  3. Work in variable form first, then substitute the numbers as you go.
  4. State what the result means. If the question asks whether a requirement is met, write the comparison with its symbol and say in words whether it passes.

The lecturer's own example was steady-state error. Start from the final value theorem, build \(E(s)\) from \(R\) and \(Y\), replace \(Y\) with the closed-loop transfer function \(T\), and only then link the result to the error constant.

Steady-state error from first principles\[ e_{ss} = \lim_{s\to0} sE(s), \qquad E(s) = R(s) - Y(s) = \bigl(1 - T(s)\bigr)R(s) \]
\(e_{ss}\)
Steady-state error: the error left as \(t \to \infty\) (units of the output).
\(E(s)\)
Laplace transform of the error signal \(e(t) = r(t) - y(t)\).
\(R(s)\)
Laplace transform of the reference input.
\(Y(s)\)
Laplace transform of the output.
\(T(s)\)
Closed-loop transfer function from \(R\) to \(Y\); for unity feedback \(T = G/(1+G)\).
Worked example 2.1 a full-marks layout for a ramp-error check

The plant \(G(s) = \dfrac{10}{s(s+2)}\) is in unity feedback. The specification asks for a steady-state error of at most 0.1 to a unit ramp. Is it met?

1
Closed loop, unity feedback: \(T(s) = \dfrac{G}{1+G} = \dfrac{10}{s^2 + 2s + 10}\).
2
Error: \(E(s) = \bigl(1 - T(s)\bigr)R(s)\) with the unit ramp \(R(s) = 1/s^2\), so \[ E(s) = \frac{s^2 + 2s}{s^2 + 2s + 10}\cdot\frac{1}{s^2} = \frac{s + 2}{s\,(s^2 + 2s + 10)} \]
3
Final value theorem (the closed loop is stable, so it applies): \(e_{ss} = \lim_{s\to0} sE(s) = \dfrac{2}{10} = 0.2\).
4
Link to the error constant: the loop is type 1, so \(e_{ss} = 1/K_v\) with \(K_v = \lim_{s\to0} sG(s) = 10/2 = 5\), giving \(1/5 = 0.2\). Both routes agree.
\(e_{ss} = 0.2 \gt 0.1\), so the ramp-error requirement is not met.
Watch out

Step 4's last line is where marks were lost in A1: a number with no comparison and no conclusion does not answer “is it met?”.

03Term 4: state-space design

The second lecturer summarised term 4 as one design flow, illustrated with an inverted-pendulum example in which only the angle \(\theta\) is measured.

Model

  1. Physics gives a differential equation. Linearise it if it is non-linear; linearisation itself is not tested.
  2. Either arrange it into a state-variable model \((A, B, C, D)\), or Laplace-transform it into a transfer function. You must be able to convert between the two forms.
Key idea

Different choices of state variables give different \((A, B, C, D)\), but converting any of them back gives the same transfer function. If yours differs, there is an error.

Control law, estimator, compensator

  1. Specifications to desired poles. Turn the specs into dominant poles and the desired characteristic equation.
  2. Controllability check. The controllability matrix must have a non-zero determinant. Check observability the same way before designing an estimator.
  3. Control law. Full-state feedback \(u = -\mathbf{K}x\). Expand \(\det(sI - A + B\mathbf{K})\) and match its coefficients with the desired characteristic equation.
  4. Estimator. When not every state is measured, design a full-order estimator. Expand \(\det(sI - A + \mathbf{L}C)\) and match coefficients with the desired estimator equation.
  5. Compensator. Combine the two. By the separation principle the closed-loop poles are the controller poles together with the estimator poles. Be able to recover the transfer function from \(R\) to \(Y\).
Exam

Place the estimator poles 2 to 6 times faster (further left) than the controller poles. The pendulum example used 5 times.

Worked example 3.1 controller and estimator characteristic equations

A second-order plant must have dominant poles with \(\zeta = 0.707\) and \(\omega_n = 2\) rad/s. The estimator poles are to be 5 times faster. Find both desired characteristic equations.

1
Controller poles: \(s = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} = -1.414 \pm j1.414\).
2
Controller equation: \(s^2 + 2\zeta\omega_n s + \omega_n^2 = s^2 + 2.828s + 4\).
3
Estimator poles, 5 times further out on the same \(\zeta\) line: \(\omega_n = 10\) rad/s, so \(s = -7.071 \pm j7.071\).
4
Estimator equation: \(s^2 + 2(0.707)(10)s + 10^2 = s^2 + 14.14s + 100\).
\(\alpha_c(s) = s^2 + 2.828s + 4\) for \(\mathbf{K}\); \(\alpha_e(s) = s^2 + 14.14s + 100\) for \(\mathbf{L}\).

Tracking

A regulator drives every state to zero. To make the output follow a reference instead, there are two ways.

  1. Feedforward gain \(\bar N\). Scale the reference so the output reaches it. It is simple, but it relies on an exact model: an external disturbance or a model error leaves a steady-state error.
  2. Integral control. Add an integrator on the error as an extra state, augment the model, and place the poles of the augmented system.
Exam

Put the extra integrator pole to the left of the dominant poles, but not too far. Too fast and the control effort becomes large and the actuator saturates easily.

04Term 4: digital control

  1. Design by emulation (the main route). Design the controller in continuous time, choose the sample period, then discretise it, for example with Tustin, and simplify to \(D(z)\). The lecturer's example was a PI controller whose zero was placed to cancel the slow plant pole, leaving only the gain to find from the specification.
  2. Implementation. Write \(D(z) = U(z)/E(z)\), divide top and bottom by the highest power of \(z\) so everything is in negative powers, cross-multiply, and inverse z-transform to get the difference equation the computer runs.
  3. ZOH equivalent model. Hold, plant and sampler combine into one z-domain transfer function. You will not derive it from scratch, but you must recognise it and use the formula if it is given.
  4. Discretising a state-space compensator directly is a further route; awareness only.
Tustin (bilinear) substitution\[ s \;\to\; \frac{2}{T}\,\frac{z-1}{z+1} \]
\(s\)
Laplace variable of the continuous controller (1/s).
\(T\)
Sample period (s).
\(z\)
z-transform variable; \(z^{-1}\) is a delay of one sample.
Worked example 4.1 PI controller to difference equation

Implement \(D(s) = 2\,\dfrac{s+1}{s}\) with Tustin at \(T = 0.1\) s.

1
\(2/T = 20\), so \(s \to 20\dfrac{z-1}{z+1}\).
2
Substitute and multiply top and bottom by \(z+1\): \[ D(z) = 2\,\frac{20(z-1) + (z+1)}{20(z-1)} = \frac{2.1z - 1.9}{z - 1} \]
3
Divide by \(z\): \(\dfrac{U(z)}{E(z)} = \dfrac{2.1 - 1.9z^{-1}}{1 - z^{-1}}\). Cross-multiply: \(U(z)(1 - z^{-1}) = E(z)(2.1 - 1.9z^{-1})\).
4
Inverse z-transform (\(z^{-1}\) is one sample of delay).
\(u[k] = u[k-1] + 2.1\,e[k] - 1.9\,e[k-1]\)
Watch out

Direct digital design (designing in the z-domain) was again named as something to be aware of, not something you will be asked to do. This matches the Week 12 notes.

05Practice problems

Problem 5.1 does it meet the spec?

\(G(s) = \dfrac{20}{s(s+4)}\) is in unity feedback. The steady-state error to a unit ramp must be at most 0.25. Lay the answer out for full marks.

1
\(T(s) = \dfrac{20}{s^2 + 4s + 20}\).
2
\(E(s) = (1 - T)\dfrac{1}{s^2} = \dfrac{s + 4}{s\,(s^2 + 4s + 20)}\).
3
\(e_{ss} = \lim_{s\to0} sE(s) = 4/20 = 0.2\). Check: \(K_v = \lim_{s\to0} sG = 5\), \(1/K_v = 0.2\).
\(e_{ss} = 0.2 \lt 0.25\), so the requirement is met.
Problem 5.2 estimator poles

The controller poles are set by \(\zeta = 0.6\) and \(\omega_n = 3\) rad/s. Place the estimator poles 4 times faster and give the desired estimator characteristic equation.

1
Controller poles: \(-1.8 \pm j2.4\).
2
Four times further out: \(-7.2 \pm j9.6\), so \(\omega_n = 12\) rad/s with the same \(\zeta\).
\(\alpha_e(s) = s^2 + 14.4s + 144\)
Problem 5.3 lead compensator to difference equation

Implement \(D(s) = 4\,\dfrac{s+2}{s+8}\) with Tustin at \(T = 0.05\) s, and check the DC gain.

1
\(2/T = 40\): \[ D(z) = 4\,\dfrac{40(z-1) + 2(z+1)}{40(z-1) + 8(z+1)} = \dfrac{168z - 152}{48z - 32} = \dfrac{3.5z - 3.167}{z - 0.6667} \]
2
DC gain at \(z = 1\): \((3.5 - 3.167)/(1 - 0.6667) = 1.0\), equal to \(D(0) = 4 \times 2/8 = 1\).
3
Divide by \(z\), cross-multiply and inverse transform.
\(u[k] = 0.6667\,u[k-1] + 3.5\,e[k] - 3.167\,e[k-1]\)

06Key points

The paper

6 questions, 100 marks, A1 difficulty.

Class-test style, but one question may combine several designs.

Design-focused; chapters 1 to 3 only as tools.

Marking

First principles, then link to shortcuts.

Say where each equation and value comes from.

Variable form first, then numbers.

Compare with the spec and conclude in words.

State space

\(\det(sI - A + B\mathbf{K}) = \alpha_c(s)\)

\(\det(sI - A + \mathbf{L}C) = \alpha_e(s)\), estimator 2 to 6 times faster

Closed-loop poles: controller and estimator poles together

Integrator pole: left of dominant, not too far

Digital

Tustin: \(s \to \tfrac{2}{T}\tfrac{z-1}{z+1}\)

Negative powers of \(z\), cross-multiply, inverse transform

ZOH model: use the formula if given

Direct digital design: awareness only
