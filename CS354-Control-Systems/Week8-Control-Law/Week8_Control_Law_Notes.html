Dynamic response and control law design

How a state model responds in time and in the s-domain, poles and zeros from A, B, C and D, and the full-state feedback law u = −Kx that places the closed-loop poles. Built from the Week 08 folder: the HTML lecture deck, the 2020 Ch 7.4 and 7.5 slides and Tutorial 6.

01From analysis to design

Week 7 built the analysis tools: state models, canonical forms, transformations, and the controllability and observability tests. From this week the state model is used to design. State-space design splits into separate steps that are done one after the other:

StepWhat it doesWeek
Control lawAssign the closed-loop poles using all the states, \(u = -\mathbf{K}\mathbf{x}\)8
EstimatorReconstruct the state vector from the measured output when not every state is measured9
Reference inputIntroduce the command so that the output tracks it9 and 10
CompensatorCombine the control law and the estimator into one controller10
Before any of it

Test before you design: controllability before the control law, observability before the estimator. Design without the test is wasted work if the test fails.

This week has two parts: how a state model responds in time (FPE 7.4), and the control law that places the closed-loop poles (FPE 7.5.1 and 7.6). A running example is used throughout weeks 8 to 10:

Running example, weeks 8 to 10\[ \mathbf{A} = \begin{bmatrix} -1 & 1 \\ -2 & -4 \end{bmatrix}, \quad \mathbf{B} = \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \quad \mathbf{C} = \begin{bmatrix} 1 & 0 \end{bmatrix}, \quad D = 0 \]
\(\mathbf{A}\)
System matrix of the running example.
\(\mathbf{B}\)
Input matrix: the input drives both states.
\(\mathbf{C}\)
Output matrix: the output is \(x_1\).

02Response in the time domain

Start with no input and a known starting state, \(\dot{\mathbf{x}} = \mathbf{A}\mathbf{x}\), \(\mathbf{x}(0) = \mathbf{x}_0\). For a scalar, \(\dot x = ax\) gives \(x = e^{at}x_0\). The same holds for the vector equation once the exponential of a matrix is defined by the same power series:

State transition matrix\[ e^{\mathbf{A}t} = \mathbf{I} + \mathbf{A}t + \frac{\mathbf{A}^2t^2}{2!} + \frac{\mathbf{A}^3t^3}{3!} + \cdots, \qquad \mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}_0 = \mathbf{\Phi}(t)\mathbf{x}_0 \]
\(e^{\mathbf{A}t}\)
Matrix exponential, an \(n \times n\) matrix of time functions.
\(\mathbf{\Phi}(t)\)
State transition matrix: carries the state from time 0 to time \(t\). It depends on \(\mathbf{A}\) alone.
\(\mathbf{x}_0\)
Initial state.

Three facts follow from the series: \(e^{\mathbf{A}\cdot0} = \mathbf{I}\), \(\frac{d}{dt}e^{\mathbf{A}t} = \mathbf{A}e^{\mathbf{A}t}\) and \(e^{\mathbf{A}t}e^{\mathbf{A}\tau} = e^{\mathbf{A}(t+\tau)}\). The first two show that \(\mathbf{x} = e^{\mathbf{A}t}\mathbf{x}_0\) satisfies both the equation and the initial condition. In MATLAB use expm(A*t); exp(A*t) exponentiates entry by entry, which is wrong.

With an input the solution gains a convolution term:

Complete response (FPE 7.4)\[ \mathbf{x}(t) = \underbrace{e^{\mathbf{A}t}\mathbf{x}_0}_{\text{zero-input}} + \underbrace{\int_0^t e^{\mathbf{A}(t-\tau)}\mathbf{B}u(\tau)\,d\tau}_{\text{zero-state}}, \qquad y(t) = \mathbf{C}\mathbf{x}(t) + Du(t) \]
\(\text{zero-input}\)
What the starting state does on its own.
\(\text{zero-state}\)
What the input does from rest: each past input \(u(\tau)\) weighted by \(e^{\mathbf{A}(t-\tau)}\mathbf{B}\), which depends on how long ago it was applied.
\(Du\)
Direct feedthrough to the output.

The two parts simply add because the model is linear. Differentiating with the Leibniz rule confirms the formula: the integrand at \(\tau = t\) gives \(\mathbf{B}u(t)\) and the rest gives \(\mathbf{A}\mathbf{x}\).

Figure 2.1: The zero-input part (teal) decays to zero; the zero-state part (amber) rises to 1.5 × G(0) = 1.5. Their sum is the total. The transient belongs to the initial state; the final value belongs to the input.

03The same response in the s-domain

Laplace-transform \(\dot{\mathbf{x}} = \mathbf{A}\mathbf{x} + \mathbf{B}u\), keeping \(\mathbf{x}_0\): \(s\mathbf{X}(s) - \mathbf{x}_0 = \mathbf{A}\mathbf{X}(s) + \mathbf{B}U(s)\). Solving and comparing with the time-domain result gives the practical way to find \(\mathbf{\Phi}(t)\), and the transfer function:

s-domain response (FPE 7.4)\[ \begin{gathered} \mathbf{X}(s) = (s\mathbf{I} - \mathbf{A})^{-1}\mathbf{x}_0 + (s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B}U(s), \qquad \mathbf{\Phi}(t) = \mathcal{L}^{-1}\{(s\mathbf{I} - \mathbf{A})^{-1}\}, \\ Y(s) = \underbrace{\mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{x}_0}_{\text{free}} + \underbrace{[\mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} + D]U(s)}_{\text{forced}}, \qquad G(s) = \mathbf{C}(s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} + D \end{gathered} \]
\(\mathbf{X}(s)\)
Transform of the state vector.
\((s\mathbf{I} - \mathbf{A})^{-1}\)
Resolvent, \(\mathrm{adj}(s\mathbf{I}-\mathbf{A})/\det(s\mathbf{I}-\mathbf{A})\): every entry shares the denominator \(\det(s\mathbf{I}-\mathbf{A})\).
\(G(s)\)
Transfer function, the forced part with \(\mathbf{x}_0 = \mathbf{0}\). MATLAB: [num,den] = ss2tf(A,B,C,D).
Worked example 3.1 State transition matrix by inverse Laplace

Find \(\mathbf{\Phi}(t)\) for the running example and check \(\mathbf{\Phi}(0)\).

1
\(s\mathbf{I} - \mathbf{A} = \begin{bmatrix} s+1 & -1 \\ 2 & s+4 \end{bmatrix}\), \(\det = s^2 + 5s + 6 = (s+2)(s+3)\), \(\mathrm{adj} = \begin{bmatrix} s+4 & 1 \\ -2 & s+1 \end{bmatrix}\).
2
Partial fractions entry by entry: \(\dfrac{s+4}{(s+2)(s+3)} = \dfrac{2}{s+2} - \dfrac{1}{s+3}\), \(\dfrac{1}{(s+2)(s+3)} = \dfrac{1}{s+2} - \dfrac{1}{s+3}\), \(\dfrac{-2}{(s+2)(s+3)} = \dfrac{-2}{s+2} + \dfrac{2}{s+3}\), \(\dfrac{s+1}{(s+2)(s+3)} = \dfrac{-1}{s+2} + \dfrac{2}{s+3}\).
3
Invert with \(\mathcal{L}^{-1}\{1/(s+a)\} = e^{-at}\).
\(\mathbf{\Phi}(t) = \begin{bmatrix} 2e^{-2t} - e^{-3t} & e^{-2t} - e^{-3t} \\ -2e^{-2t} + 2e^{-3t} & -e^{-2t} + 2e^{-3t} \end{bmatrix}\), and \(\mathbf{\Phi}(0) = \mathbf{I}\) ✓. Only two exponentials appear, \(e^{-2t}\) and \(e^{-3t}\): the roots of the determinant.
Worked example 3.2 Transfer function and step response

Find \(G(s)\), the unit-step response from rest and the steady-state state vector.

1
Work from the right: \((s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} = \dfrac{1}{(s+2)(s+3)}\begin{bmatrix} s+4 & 1 \\ -2 & s+1 \end{bmatrix}\begin{bmatrix} 1 \\ 2 \end{bmatrix} = \dfrac{1}{(s+2)(s+3)}\begin{bmatrix} s+6 \\ 2s \end{bmatrix}\), the transfer functions from \(u\) to each state.
2
\(\mathbf{C}\) picks the first: \(G(s) = \dfrac{s+6}{s^2+5s+6}\), DC gain \(6/6 = 1\).
3
Step: \(Y = \dfrac{s+6}{s(s+2)(s+3)} = \dfrac{1}{s} + \dfrac{k_1}{s+2} + \dfrac{k_2}{s+3}\), \(k_1 = \dfrac{4}{(-2)(1)} = -2\), \(k_2 = \dfrac{3}{(-3)(-1)} = 1\).
4
Steady state from \(\dot{\mathbf{x}} = \mathbf{0}\) with \(u = 1\): \(\mathbf{x}_{ss} = -\mathbf{A}^{-1}\mathbf{B} = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\).
\(y(t) = 1 - 2e^{-2t} + e^{-3t}\); \(y(0) = 0\) ✓ from rest, \(y(\infty) = 1 = G(0)\) ✓, and the first entry of \(\mathbf{x}_{ss}\) agrees. The second state, \(x_2\), returns to zero: its transfer function \(2s/((s+2)(s+3))\) has a zero at the origin.

04Poles and zeros from the state model

Everything above shares the denominator \(\det(s\mathbf{I} - \mathbf{A})\). The poles are its roots, which is the eigenvalue problem of \(\mathbf{A}\); each pole \(p_i\) is a mode \(e^{p_it}\) in \(\mathbf{\Phi}(t)\). The zeros can be found without forming \(G(s)\):

Poles and zeros (FPE 7.4)\[ \begin{gathered} \det(s\mathbf{I} - \mathbf{A}) = 0 \;\;(\text{poles}), \\ \det\begin{bmatrix} z\mathbf{I} - \mathbf{A} & -\mathbf{B} \\ \mathbf{C} & D \end{bmatrix} = 0 \;\;(\text{zeros}), \\ G(s) = \frac{\det\begin{bmatrix} s\mathbf{I} - \mathbf{A} & -\mathbf{B} \\ \mathbf{C} & D \end{bmatrix}}{\det(s\mathbf{I} - \mathbf{A})} \end{gathered} \]
\(p_i\)
Poles: eigenvalues of \(\mathbf{A}\). MATLAB eig(A).
\(z\)
Zeros: values where the block matrix is singular. MATLAB tzero(ss(A,B,C,D)).

Why the zero formula works: add the first \(n\) columns, weighted by \((s\mathbf{I} - \mathbf{A})^{-1}\mathbf{B}\), to the last column; it becomes \([\mathbf{0};\,G(s)]\), so the block determinant equals \(G(s)\det(s\mathbf{I} - \mathbf{A})\), the numerator of \(G\).

Worked example 4.1 Zero from the block determinant

Find the zero of the running example without forming \(G(s)\).

1
\(\det\begin{bmatrix} s+1 & -1 & -1 \\ 2 & s+4 & -2 \\ 1 & 0 & 0 \end{bmatrix}\). Expand along the bottom row: \(1\cdot\begin{vmatrix} -1 & -1 \\ s+4 & -2 \end{vmatrix} = 2 + (s+4) = s + 6\).
A zero at \(s = -6\), matching \(G(s) = (s+6)/(s^2+5s+6)\).
Watch out

If a zero coincides with a pole they cancel in \(G(s)\), and that mode is uncontrollable, unobservable or both. The state model still contains it, and a cancelled unstable mode will still destroy the system.

05The control law

Assume the control is a linear combination of all the states (full-state feedback):

Control law (FPE 7.5.1)\[ \begin{gathered} u = -\mathbf{K}\mathbf{x} = -[\,K_1 \;\; K_2 \;\; \cdots \;\; K_n\,]\,\mathbf{x} \\ \Rightarrow\;\; \dot{\mathbf{x}} = (\mathbf{A} - \mathbf{B}\mathbf{K})\mathbf{x}, \qquad \det[s\mathbf{I} - (\mathbf{A} - \mathbf{B}\mathbf{K})] = 0 \end{gathered} \]
\(\mathbf{K}\)
Gain row vector, \(1 \times n\): one gain per state.
\(\mathbf{A} - \mathbf{B}\mathbf{K}\)
Closed-loop system matrix.
\(\det[s\mathbf{I} - (\mathbf{A}-\mathbf{B}\mathbf{K})]\)
Control characteristic polynomial.

The specification gives the desired pole locations \(s_1, \ldots, s_n\) and so the desired characteristic polynomial \(\alpha_c(s) = (s - s_1)\cdots(s - s_n)\). The only unknown is \(\mathbf{K}\), found by making the two polynomials equal. An \(n\)th-order system has \(n\) gains and \(n\) roots, so any set of poles can be placed: this is pole placement.

Key idea

Condition: the plant must be controllable, \(\det\mathcal{C} \ne 0\). If not, some modes cannot be moved by any \(\mathbf{K}\). For a controllable single-input plant the \(\mathbf{K}\) that places a given set of poles is unique, so every method below gives the same answer.

Root locus compared

Root locus offers one parameter, so the closed-loop poles are restricted to the locus. Full-state feedback places every pole directly, at the cost of needing the whole state vector (which week 9 deals with).

06Three ways to find K

Method 1: compare coefficients

Expand \(\det[s\mathbf{I} - (\mathbf{A} - \mathbf{B}\mathbf{K})]\) with symbolic gains and equate like powers of \(s\). Practical up to \(n = 3\), and the default in this module.

Worked example 6.1 Control law by comparing coefficients

For the running example, place the closed-loop poles to give \(\zeta \approx 0.7\) and a 1 % settling time of about 1.3 s, using \(\alpha_c(s) = s^2 + 7s + 24\). Find \(\mathbf{K}\).

1
Controllability: \(\mathbf{A}\mathbf{B} = [1\;\;-10]^T\), \(\mathcal{C} = \begin{bmatrix} 1 & 1 \\ 2 & -10 \end{bmatrix}\), \(\det\mathcal{C} = -12 \ne 0\) ✓.
2
Roots of \(\alpha_c\): \(-3.5 \pm 3.43j\), so \(\omega_n = \sqrt{24} = 4.90\) rad/s, \(\zeta = 3.5/4.90 = 0.714\), \(t_s = 4.6/3.5 = 1.31\) s, \(M_p = 4.0\) %.
3
\(s\mathbf{I} - (\mathbf{A} - \mathbf{B}\mathbf{K}) = \begin{bmatrix} s+1+K_1 & -1+K_2 \\ 2+2K_1 & s+4+2K_2 \end{bmatrix}\). Its determinant is \(s^2 + (5 + K_1 + 2K_2)s + (6 + 6K_1)\).
4
Compare with \(s^2 + 7s + 24\): \(6 + 6K_1 = 24 \Rightarrow K_1 = 3\); \(5 + 3 + 2K_2 = 7 \Rightarrow K_2 = -0.5\).
\(\mathbf{K} = [\,3 \;\; -0.5\,]\). Check: \(\mathbf{A} - \mathbf{B}\mathbf{K} = \begin{bmatrix} -4 & \frac{3}{2} \\ -8 & -3 \end{bmatrix}\) has trace −7 and determinant 24, the negated \(s\) coefficient and the constant of \(\alpha_c\) ✓. A negative gain is normal: its sign depends on how the states are defined and on the sign pattern of \(\mathbf{B}\), not on stability.

Method 2: Ackermann's formula

Ackermann's formula (FPE 7.88)\[ \mathbf{K} = [\,0 \;\; \cdots \;\; 0 \;\; 1\,]\,\mathcal{C}^{-1}\alpha_c(\mathbf{A}), \qquad \alpha_c(\mathbf{A}) = \mathbf{A}^n + \alpha_1\mathbf{A}^{n-1} + \cdots + \alpha_n\mathbf{I} \]
\(\mathcal{C}\)
Controllability matrix \([\mathbf{B}\;\mathbf{A}\mathbf{B}\cdots\mathbf{A}^{n-1}\mathbf{B}]\).
\(\alpha_c(\mathbf{A})\)
Desired polynomial evaluated at the matrix \(\mathbf{A}\); the constant becomes \(\alpha_n\mathbf{I}\).
\(\alpha_i\)
Coefficients of \(\alpha_c(s) = s^n + \alpha_1s^{n-1} + \cdots + \alpha_n\).
Worked example 6.2 The same K by Ackermann

Confirm \(\mathbf{K}\) for \(\alpha_c(s) = s^2 + 7s + 24\).

1
\(\mathcal{C}^{-1} = \dfrac{1}{-12}\begin{bmatrix} -10 & -1 \\ -2 & 1 \end{bmatrix}\), so \([0\;\;1]\mathcal{C}^{-1} = \begin{bmatrix} \frac{1}{6} & - \frac{1}{12} \end{bmatrix}\).
2
\(\mathbf{A}^2 = \begin{bmatrix} -1 & -5 \\ 10 & 14 \end{bmatrix}\), \(\alpha_c(\mathbf{A}) = \mathbf{A}^2 + 7\mathbf{A} + 24\mathbf{I} = \begin{bmatrix} 16 & 2 \\ -4 & 10 \end{bmatrix}\).
3
\(\mathbf{K} = \begin{bmatrix} \frac{1}{6} & - \frac{1}{12} \end{bmatrix}\begin{bmatrix} 16 & 2 \\ -4 & 10 \end{bmatrix}\).
\(\mathbf{K} = [\,3 \;\; -0.5\,]\) ✓. Do not evaluate \(\alpha_c\) at the eigenvalues of \(\mathbf{A}\): that gives zero.

Method 3: through control canonical form

The 2020 slides (and one of the week's videos) add a third route. In control canonical form \(\mathbf{A}_c - \mathbf{B}_c\mathbf{K}_c\) is still in companion form with top row \(-(a_i + K_i)\), so the gains are read off by inspection, then transformed back:

Pole placement via control canonical form\[ K_{c,i} = \alpha_i - a_i, \qquad \mathbf{K} = \mathbf{K}_c\mathbf{T}^{-1}, \qquad \mathbf{x} = \mathbf{T}\mathbf{z},\;\; \mathbf{T} = \mathcal{C}_x\mathcal{C}_z^{-1} \]
\(a_i\)
Coefficients of the open-loop \(\det(s\mathbf{I}-\mathbf{A})\).
\(\alpha_i\)
Coefficients of the desired \(\alpha_c(s)\).
\(\mathbf{K}_c\)
Gain in canonical coordinates.
\(\mathbf{T}\)
Transformation from week 7.
Worked example 6.3 The same K through canonical form

Repeat example 6.1 by transforming to control canonical form.

1
Open loop \(s^2 + 5s + 6\), desired \(s^2 + 7s + 24\): \(\mathbf{K}_c = [7-5\;\;24-6] = [2\;\;18]\).
2
\(\mathbf{A}_c = \begin{bmatrix} -5 & -6 \\ 1 & 0 \end{bmatrix}\), \(\mathbf{B}_c = [1\;\;0]^T\), \(\mathcal{C}_z = \begin{bmatrix} 1 & -5 \\ 0 & 1 \end{bmatrix}\). \(\mathbf{T} = \mathcal{C}_x\mathcal{C}_z^{-1} = \begin{bmatrix} 1 & 6 \\ 2 & 0 \end{bmatrix}\).
3
\(\mathbf{K} = \mathbf{K}_c\mathbf{T}^{-1} = [2\;\;18]\,\begin{bmatrix} 0 & \frac{1}{2} \\ \frac{1}{6} & - \frac{1}{12} \end{bmatrix}\).
\(\mathbf{K} = [\,3 \;\; -0.5\,]\) ✓ again: the gain is unique.

07Choosing the closed-loop poles

Pole placement answers how, not where. The specification is normally translated through a dominant second-order pair, exactly as in weeks 1 to 6: \(\zeta\) from the overshoot, \(\omega_n\) or \(\sigma\) from the rise and settling times. Any remaining poles go well to the left so that they hardly contribute.

RequirementGuide
Overshoot \(M_p\)\(\zeta \approx 0.6\) gives about 10 %, \(\zeta = 0.7\) about 5 %
Settling time \(t_s\)\(t_s \approx 4.6/(\zeta\omega_n)\) to 1 %
Rise time \(t_r\)\(t_r \approx 1.8/\omega_n\)
Other poles5 to 10 times further left (2026 deck); the 2020 slides say about 4 times the natural frequency

Figure 7.1: Faster poles settle sooner but the initial effort \(u(0) = -K_1\) grows roughly as \(\omega_n^2\): -0.500, -3.17 and -15.7 for \(\omega_n\) = 3, 5 and 10 rad/s.

Watch out

Practical limits. Pole placement assumes \(u\) is unconstrained. Moving poles far from their open-loop positions needs large \(\mathbf{K}\), so large \(u\), so saturation, after which the design is no longer linear. A weakly controllable plant (small \(\det\mathcal{C}\)) also needs large gains: mathematically controllable, practically not. Moving poles that sit close to zeros is expensive too. Ask for the slowest response that meets the specification, and fix only what is undesirable.

Not examined

Optimal pole selection by LQR (FPE 7.6.2) is not for examination.

08MATLAB

[num,den] = ss2tf(A,B,C,D)      % transfer function
p = eig(A); z = tzero(ss(A,B,C,D))
Co = ctrb(A,B); det(Co)          % controllability
K = acker(A,B,pc)                % Ackermann, n <= 10 only (poor numerics)
K = place(A,B,pc)                % reliable, but no repeated poles
eig(A-B*K)                       % must equal pc
initial(ss(A-B*K,B,C,D), x0)     % regulator response
Exam

Show the hand method. Quoting acker output alone earns no marks; use it to check. Always check a finished gain by substituting it back and expanding \(\det[s\mathbf{I} - (\mathbf{A} - \mathbf{B}\mathbf{K})]\), or at least by the trace and determinant: a check that reuses \(\mathcal{C}^{-1}\) or \(\alpha_c(\mathbf{A})\) would only repeat a mistake.

09Practice problems

Problem 1. Tutorial 6 problem 1: \(\mathbf{A} = \begin{bmatrix} 0 & 2 \\ -3 & -5 \end{bmatrix}\), \(\mathbf{B} = [1\;\;1]^T\), \(\mathbf{C} = [1\;\;0]\). Find the poles, \(G(s)\), \(\mathbf{x}_{ss}\) for a unit step, and test controllability and observability.

\(s^2 + 5s + 6\), poles −2, −3. \(\mathrm{adj}\,\mathbf{B} = [s+7\;\;s-3]^T\), so \(G = (s+7)/((s+2)(s+3))\), DC gain 7/6. \(\mathbf{x}_{ss} = -\mathbf{A}^{-1}\mathbf{B} = [7/6\;\;-1/2]^T\). \(\det\mathcal{C} = -10\), \(\det\mathcal{O} = 2\): both hold.

Problem 2. For the same plant, find \(\mathbf{K}\) for \(\zeta = 0.7\), \(\omega_n = 5\) rad/s.

\(\alpha_c = s^2 + 7s + 25\). \(\det[s\mathbf{I} - (\mathbf{A}-\mathbf{B}\mathbf{K})] = s^2 + (5 + K_1 + K_2)s + (6 + 7K_1 - 3K_2)\). So \(K_1 + K_2 = 2\) and \(7K_1 - 3K_2 = 19\), giving \(\mathbf{K} = [2.5\;\;-0.5]\). Trace −7, determinant 25 ✓.

Problem 3. A mass-spring-damper \(\mathbf{A} = \begin{bmatrix} 0 & 1 \\ -2 & -3 \end{bmatrix}\), \(\mathbf{B} = [0\;\;1]^T\). Find \(\mathbf{\Phi}(t)\) and \(\mathbf{K}\) for \(\zeta = 0.7\), \(\omega_n = 5\).

\(\mathbf{\Phi} = \begin{bmatrix} 2e^{-t} - e^{-2t} & e^{-t} - e^{-2t} \\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t} \end{bmatrix}\). Companion form: \(\det = s^2 + (3 + K_2)s + (2 + K_1) = s^2 + 7s + 25\), so \(\mathbf{K} = [23\;\;4]\): 23 N/m of synthetic stiffness and 4 N s/m of synthetic damping.

Problem 4. Why may a design with poles at −40 settle only slightly faster than one at −10 when a dominant pair sits at \(-3 \pm 3j\)? (Tutorial 6 problem 4.)

The dominant pair sets the settling time. Moving the third pole from −10 to −40 grows every entry of \(\mathbf{K}\) by 3.4 to 4.3 times and the initial effort fourfold, while the 1 % settling time improves only from 1.66 s to 1.58 s.

10Formula sheet

Response

\(\mathbf{x} = e^{\mathbf{A}t}\mathbf{x}_0 + \int_0^t e^{\mathbf{A}(t-\tau)}\mathbf{B}u\,d\tau\)

\(\mathbf{\Phi}(t) = \mathcal{L}^{-1}\{(s\mathbf{I}-\mathbf{A})^{-1}\}\)

\(\mathbf{x}_{ss} = -\mathbf{A}^{-1}\mathbf{B}\bar u\)

Poles and zeros

\(\det(s\mathbf{I}-\mathbf{A}) = 0\)

\(\det\begin{bmatrix} z\mathbf{I}-\mathbf{A} & -\mathbf{B} \\ \mathbf{C} & D \end{bmatrix} = 0\)

Control law

\(u = -\mathbf{K}\mathbf{x}\), \(\det[s\mathbf{I} - (\mathbf{A}-\mathbf{B}\mathbf{K})] = \alpha_c(s)\)

\(\mathbf{K} = [0\cdots1]\mathcal{C}^{-1}\alpha_c(\mathbf{A})\)

Canonical: \(K_{c,i} = \alpha_i - a_i\), \(\mathbf{K} = \mathbf{K}_c\mathbf{T}^{-1}\)

Checks

\(\mathrm{tr}(\mathbf{A}-\mathbf{B}\mathbf{K}) = -\alpha_1\)

\(\det(\mathbf{A}-\mathbf{B}\mathbf{K}) = (-1)^n\alpha_n\)
