Formulas, marking and question style

  • Why calculations: the class is large, so questions are chosen to be marked objectively against a marking guide with specific correct answers, leaving little room for debate.
  • Part marks: a formula sheet was requested and refused, because it makes part marks harder to award. Instead the marking guide gives marks for applying the right formula even when the final answer is wrong. So always write the formula down before substituting.
  • Theory: a few marks go to definitions and short theory questions, in the style of the quizzes.
  • Length: answers are short. Long paragraph answers are avoided because they are hard to mark.
  • Extracts: for harder procedures (such as choosing a gradient-boosting split), expect to be given part of the working and asked to continue it.

02Ensembles in one view

An ensemble combines many weak learners: models only slightly better than random guessing. Each makes different mistakes, so combining more of them gives a more reliable prediction.

MethodHow models differTrainingCombination
Bagging (and random forests)Sampling of instances (and of features)ParallelVote or average
AdaBoostSampling biased towards the instances previous models got wrongSequentialVote weighted by confidence \(\alpha\)
Gradient boostingEach model predicts the remaining error itselfSequentialBase model plus the sum of corrections
StackingDifferent model typesParallel base models, then a meta-learnerA meta-learner learns how to combine them
The point to emphasise

Bagging and boosting differ in how the models are trained. Bagging's models are independent, so they can be trained in parallel (good for computational efficiency). Boosting's models are sequential: each depends on the errors of the one before.

AdaBoost and gradient boosting both focus on errors, in different ways. AdaBoost reweights the erroneous instances so they are sampled more. Gradient boosting trains models to predict the error itself.

03Bagging and random forests

Bagging draws a bootstrap sample for each model: the same size as the dataset, sampled with replacement. Some instances repeat and others are left out. The left-out instances form that model's out-of-bag (OOB) set.

The OOB instances were never seen by the model trained on that sample, so they act as a built-in validation set. You do not need a separate train and test split or cross-validation to estimate the error.

Chance an instance is out of bag\[ P(\text{OOB}) = \left(1 - \frac{1}{n}\right)^{n} \approx e^{-1} \approx 0.368 \]
\(P(\text{OOB})\)
Probability that a given instance is never drawn into one bootstrap sample.
\(n\)
Number of instances in the dataset, and the size of the bootstrap sample.

A random forest samples at two levels:

  1. Instances: each tree gets its own bootstrap sample, so each tree emphasises a different part of the problem and their weaknesses compensate for each other.
  2. Features: at each split, a decision tree normally checks every feature for the most information gain. A random forest checks only a random subset, typically \(\sqrt{m}\) of the \(m\) features, and picks the best of those.

Because each tree has an OOB set and sees a different subset of features, a random forest can also rank features: it shows which features help and which do not, so it is useful for feature selection.

Worked example 3.1 OOB size and features per split

A random forest is trained on a dataset of 10 instances with 30 descriptive features. Find the chance that a given instance is out of bag for one tree, the expected number of OOB instances per tree, and the number of features checked at each split.

1
\(P(\text{OOB}) = (1 - 1/10)^{10} = 0.9^{10} = 0.3487\).
2
Expected OOB instances per tree: \(10 \times 0.3487 = 3.49\). The large-\(n\) value \(e^{-1} = 0.368\) is close even at \(n = 10\); at \(n = 1000\) the exact value is 0.3677.
3
Features per split: \(\sqrt{30} = 5.477\), so 5 features (rounded down).
About 35 % of instances (3.49 of 10) are out of bag for each tree, and each split chooses from 5 randomly selected features.

04AdaBoost

AdaBoost builds a sequence of decision stumps (trees with one split). Every instance carries a weight, used as its probability of being sampled for the next model's training set. Weights start equal. After each model, the weights of misclassified instances go up and the weights of correct ones go down, so the next sample is biased towards the problem cases. Over the iterations the models zero in on the hard instances and correct for them.

Finding a stump's split

For a continuous feature, sort the instances by that feature and place candidate thresholds only where the label changes, at the midpoint between the two neighbouring values. Score each candidate and keep the best. This is the same method as for continuous features in information-based learning (Week 7).

Figure 4.1: Teal dots are High demand and amber dots Low. The label changes twice, between 14 and 17 °C and between 29 and 32 °C, so the only candidate thresholds are 15.5 °C and 30.5 °C. Round 1 picks 15.5 °C (solid line); round 2, with the reweighted data, picks 30.5 °C (dashed).

Worked example 4.1 Round 1 stump

Ten days of ambient temperature (°C) and pump demand: 8 L, 11 L, 14 L, 17 H, 20 H, 23 H, 26 H, 29 H, 32 L, 35 L. Each instance starts with weight 0.1. Find the best one-split stump and its weighted error \(\epsilon\).

1
The data are already sorted. Labels change between 14 and 17, and between 29 and 32, so the candidates are 15.5 °C and 30.5 °C.
2
Split at 15.5: below predicts Low, above predicts High (the majority on each side). It misclassifies 32 and 35, so \(\epsilon = 0.1 + 0.1 = 0.2\).
3
Split at 30.5: below predicts High, above predicts Low. It misclassifies 8, 11 and 14, so \(\epsilon = 0.3\).
The round 1 stump is "temperature \(\lt\) 15.5 °C → Low, else High", with \(\epsilon_1 = 0.2\). It gets the two hot days wrong.

The weight formulas

The lecturer called these the formulas you must remember. They are not on any formula sheet. There are three: the error, the weight update (one case for wrong instances and one for correct ones) and the model's confidence.

AdaBoost, textbook form\[ \epsilon = \sum_{i \,\in\, \text{misclassified}} w_i \] \[ w_i \leftarrow w_i \times \frac{1}{2\epsilon} \quad \text{(misclassified)}, \qquad w_i \leftarrow w_i \times \frac{1}{2(1-\epsilon)} \quad \text{(correct)} \] \[ \alpha = \frac{1}{2} \ln\!\left(\frac{1-\epsilon}{\epsilon}\right) \]
\(\epsilon\)
Weighted error of the model: the sum of the weights of the instances it gets wrong (between 0 and 1).
\(w_i\)
Weight of instance \(i\): its probability of being sampled for the next model. The weights sum to 1.
\(\alpha\)
Confidence of the model, used to weight its vote in the ensemble.

After this update the misclassified instances hold exactly half the total weight and the correct ones the other half, so the weights still sum to 1 with no extra step.

Worked example 4.2 Round 1 weight update

Update the weights after the stump of worked example 4.1 (\(\epsilon_1 = 0.2\); 32 and 35 wrong) and find its confidence.

1
Misclassified (32, 35): \(0.1 \times \dfrac{1}{2(0.2)} = 0.25\) each.
2
Correct (the other eight): \(0.1 \times \dfrac{1}{2(0.8)} = 0.0625\) each.
3
Check the sum: \(2(0.25) + 8(0.0625) = 0.5 + 0.5 = 1\).
4
Confidence: \(\alpha_1 = \tfrac12 \ln(0.8/0.2) = \tfrac12 \ln 4 = 0.6931\).
The two hot days now have weight 0.25 each (up from 0.1); the other eight have 0.0625 (down from 0.1). \(\alpha_1 = 0.693\).

Textbook against classical update

The slides show two AdaBoost examples: the textbook one (Kelleher) and a classical one presented later. Both reach the same weights and the same predictions. The classical form multiplies by \(e^{\pm\alpha}\) and then needs an extra normalisation step; the textbook form needs none. In the exam the textbook form is quicker.

AdaBoost, classical form\[ w_i \leftarrow \frac{w_i\, e^{\alpha}}{Z} \;\text{(misclassified)}, \qquad w_i \leftarrow \frac{w_i\, e^{-\alpha}}{Z} \;\text{(correct)} \]
\(w_i\)
Weight of instance \(i\).
\(\alpha\)
Confidence of the model, as above.
\(Z\)
Normalising constant: the sum of the weights after multiplying, so the new weights sum to 1.

Why they agree: with \(e^{\alpha} = \sqrt{(1-\epsilon)/\epsilon}\), the normalising constant is

\[ Z = \epsilon\, e^{\alpha} + (1-\epsilon)\, e^{-\alpha} = 2\sqrt{\epsilon(1-\epsilon)}, \]

so \(e^{\alpha}/Z = 1/(2\epsilon)\) and \(e^{-\alpha}/Z = 1/(2(1-\epsilon))\): exactly the textbook factors.

Worked example 4.3 Same weights by the classical route

Repeat the round 1 update of worked example 4.2 with the classical form.

1
\(e^{\alpha_1} = e^{0.6931} = 2\) and \(e^{-\alpha_1} = 0.5\).
2
Before normalising: wrong \(0.1 \times 2 = 0.2\); correct \(0.1 \times 0.5 = 0.05\).
3
\(Z = 2(0.2) + 8(0.05) = 0.8\), which equals \(2\sqrt{0.2 \times 0.8} = 0.8\).
4
Normalise: wrong \(0.2/0.8 = 0.25\); correct \(0.05/0.8 = 0.0625\).
0.25 and 0.0625, the same as the textbook update, with one extra step.
Worked example 4.4 Round 2 and the ensemble so far

Using the weights from worked example 4.2, find the round 2 stump, its error and confidence, the new weights, and the two-model ensemble's predictions. (Here each candidate is scored by its weighted error directly; on the slides the next training set is drawn by sampling with these weights.)

1
Split at 15.5 (as before): wrong on 32 and 35, \(\epsilon = 0.25 + 0.25 = 0.5\). No better than guessing on the new weights, as expected.
2
Split at 30.5 (High below, Low above): wrong on 8, 11 and 14, \(\epsilon_2 = 3(0.0625) = 0.1875\). This is the round 2 stump.
3
\(\alpha_2 = \tfrac12 \ln(0.8125/0.1875) = 0.7332\).
4
New weights. Wrong (8, 11, 14): \(0.0625/(2 \times 0.1875) = 0.1667\). Correct: 32 and 35 go to \(0.25/(2 \times 0.8125) = 0.1538\); the other five go to \(0.0625/1.625 = 0.0385\). Sum: \(0.5 + 0.3077 + 0.1923 = 1\).
5
Ensemble score with High \(= +1\), Low \(= -1\): \(H = \alpha_1 h_1 + \alpha_2 h_2\). Below 15.5: \(-0.6931 + 0.7332 = +0.040\) (High). Between: \(+1.426\) (High). Above 30.5: \(+0.6931 - 0.7332 = -0.040\) (Low).
Round 2 stump: temperature \(\lt\) 30.5 °C → High, else Low, \(\epsilon_2 = 0.1875\), \(\alpha_2 = 0.733\). The two-model ensemble still gets 8, 11 and 14 wrong, because the more confident second stump outvotes the first there. A third round is needed.

The hot days rise to 0.25 after round 1. In round 2 the cold days are the ones misclassified, so they rise to 0.1667, while the five middle days, right both times, fall to 0.0385.

Watch out

In the recording, the explanation of the slide's updated weights is partly inaudible and at one point sounds as if misclassified weights go down. They go up: \(1/(2\epsilon) \gt 1\) whenever \(\epsilon \lt 0.5\). Correct instances go down, since \(1/(2(1-\epsilon)) \lt 1\).

05Gradient boosting

The slide example is a regression problem: each instance has a numeric target value, not a class. Gradient boosting focuses on the error itself:

  1. Start with a base model \(F_0\) that predicts the average target for every instance.
  2. Compute the residuals \(y - F_0\). These become the new targets.
  3. Train a stump on the input feature to predict the residuals. Choose its split as the one giving the lowest variance of the residuals within the branches. Each branch predicts the mean residual in it.
  4. Add it on: \(F_1 = F_0 + R_1\). Find the new residuals \(y - F_1\), train again, and repeat for the stated number of iterations.
Gradient boosting\[ F_k(x) = F_{k-1}(x) + R_k(x) = F_0 + \sum_{j=1}^{k} R_j(x) \]
\(F_k\)
Ensemble prediction after \(k\) correction models.
\(F_0\)
Base prediction: the mean of the training targets.
\(R_j\)
Correction model \(j\), trained to predict the residuals \(y - F_{j-1}\).

This is the lecture's form, with each correction added in full. The Week 12 notes page adds a learning rate \(\eta\) in front of each \(R_j\); with \(\eta = 1\) the two agree.

Exam

Asked whether students must compute the variance at every candidate split, the lecturer said this is very unlikely; that kind of split search is examined in information-based learning. Expect an extract of the working and be ready to continue it: subtract to get residuals, add the correction, and repeat.

Worked example 5.1 Two rounds of gradient boosting

Five instances: \(x = 1, 2, 3, 4, 5\) with targets \(y = 20, 24, 30, 46, 50\). Run two rounds with one-split stumps and find the training sum of squared errors (SSE) after each.

1
\(F_0 = (20 + 24 + 30 + 46 + 50)/5 = 34\). Residuals \(y - F_0\): \(-14, -10, -4, 12, 16\). SSE \(= 712\).
2
Score each split by the total squared deviation of the residuals from their branch mean (lowest is best): split at 1.5 gives 467.0; at 2.5, 232.0; at 3.5, 58.67; at 4.5, 392.0. Choose 3.5.
3
\(R_1\): left mean \((-14 - 10 - 4)/3 = -9.333\); right mean \((12 + 16)/2 = 14\). So \(F_1 = 24.667\) for \(x \le 3\) and \(48\) for \(x \ge 4\).
4
New residuals \(y - F_1\): \(-4.667, -0.667, 5.333, -2, 2\). SSE \(= 58.67\).
5
Round 2 splits: 1.5 gives 31.44; 2.5, 34.96; 3.5, 58.67; 4.5, 53.67. Choose 1.5: left mean \(-4.667\), right mean \((-0.667 + 5.333 - 2 + 2)/4 = 1.167\).
6
\(F_2 = F_1 + R_2\): \(20, 25.833, 25.833, 49.167, 49.167\). Residuals \(0, -1.833, 4.167, -3.167, 0.833\). SSE \(= 31.44\).
\(F_2\) predicts 20, 25.83, 25.83, 49.17 and 49.17. The SSE falls from 712 to 58.67 to 31.44 over the two rounds.

Figure 5.1: Amber dots are the five targets. The dashed line is \(F_0 = 34\). The light teal steps are \(F_1\), which splits at 3.5, and the dark teal steps are \(F_2\), which adds a second split at 1.5 and fits \(x = 1\) exactly.

06Stacking

Stacking is a heterogeneous ensemble: the base models need not be of the same kind. A neural network, a decision tree and a regression model can be combined. Each base model makes its prediction, and these predictions are treated as intermediate features. A meta-learner is trained on them and learns how much to trust each base model's decision.

Definition

Meta-learner: the model in a stacking ensemble whose inputs are the base models' predictions and whose output is the final prediction.

07Practice problems

Problem 7.1 Textbook update with unequal weights

Six instances have weights 0.3, 0.2, 0.2, 0.1, 0.1 and 0.1. A stump misclassifies instances 2 and 5. Find \(\epsilon\), \(\alpha\) and the new weights.

1
\(\epsilon = 0.2 + 0.1 = 0.3\).
2
\(\alpha = \tfrac12 \ln(0.7/0.3) = 0.4236\).
3
Wrong, factor \(1/(2 \times 0.3) = 1.667\): instance 2 becomes 0.3333, instance 5 becomes 0.1667.
4
Correct, factor \(1/(2 \times 0.7) = 0.7143\): instance 1 becomes 0.2143, instance 3 becomes 0.1429, instances 4 and 6 become 0.0714.
\(\epsilon = 0.3\), \(\alpha = 0.424\). New weights: 0.2143, 0.3333, 0.1429, 0.0714, 0.1667, 0.0714 (sum 1; the two wrong ones hold 0.5).
Problem 7.2 Confidence-weighted vote

Three AdaBoost stumps have weighted errors 0.2, 0.35 and 0.4. For one instance they vote Positive, Negative, Negative. What does the ensemble predict, and what would a plain majority vote predict?

1
\(\alpha_1 = \tfrac12\ln(0.8/0.2) = 0.6931\); \(\alpha_2 = \tfrac12\ln(0.65/0.35) = 0.3095\); \(\alpha_3 = \tfrac12\ln(0.6/0.4) = 0.2027\).
2
Score with Positive \(= +1\): \(0.6931 - 0.3095 - 0.2027 = 0.1809\).
The score is positive, so AdaBoost predicts Positive. The plain majority (two of three) would say Negative: the most accurate stump outweighs the other two together.
Problem 7.3 Bagging numbers

A dataset has 20 instances and 50 descriptive features. For one tree of a random forest, find the probability that a given instance appears in its bootstrap sample at least once, the expected number of OOB instances, and the features checked per split.

1
\(P(\text{OOB}) = 0.95^{20} = 0.3585\), so \(P(\text{in sample}) = 1 - 0.3585 = 0.6415\).
2
Expected OOB instances: \(20 \times 0.3585 = 7.17\).
3
\(\sqrt{50} = 7.07\), so 7 features per split.
0.6415; about 7.17 OOB instances per tree; 7 features per split.
Problem 7.4 Bagging against boosting

In two or three sentences, state how bagging and boosting differ in the way their models are trained, and one consequence.

1
Bagging trains each model independently on its own bootstrap sample. Boosting trains them in sequence, each on data weighted towards the previous model's errors.
Bagging's models can be trained in parallel, which saves time; boosting's cannot, because each model needs the errors of the one before it.

08Formulas to memorise

There is no formula sheet in the A2. These are the ensemble formulas from this lecture; write each down before using it, since the marking guide gives marks for the right formula.

Bagging

\(P(\text{OOB}) = (1 - 1/n)^n \approx 0.368\)

Features per split in a random forest: \(\sqrt{m}\)

AdaBoost (textbook)

\(\epsilon = \sum w_i\) over misclassified instances

Wrong: \(w_i \times 1/(2\epsilon)\)

Correct: \(w_i \times 1/(2(1-\epsilon))\)

\(\alpha = \tfrac12 \ln\big((1-\epsilon)/\epsilon\big)\)

AdaBoost (classical)

\(w_i e^{\pm\alpha}/Z\), with \(Z = 2\sqrt{\epsilon(1-\epsilon)}\)

Ensemble: \(H(x) = \sum \alpha_t h_t(x)\)

Gradient boosting

\(F_0 = \bar{y}\)

Residual: \(y - F_{k-1}\)

\(F_k = F_{k-1} + R_k\)
