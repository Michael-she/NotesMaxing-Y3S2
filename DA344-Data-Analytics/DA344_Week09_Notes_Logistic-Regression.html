Logistic Regression, Basis Functions and Multiclass Models

How the linear models of Week 8 become classifiers. Logistic regression squashes a linear score into a probability with the logistic function, which gradient descent can train. Basis functions let a model that is linear in its weights fit curves. One-versus-all models handle targets with more than two classes.

01From regression to classification

Linear regression predicts an unbounded number. A binary target (Pass/Fail, Fault/OK) needs a class, or better a probability between 0 and 1. Fitting a straight line to 0/1 targets gives predictions below 0 and above 1, which mean nothing as probabilities, and the squared errors from instances far from the boundary pull the line around.

Decision boundaries

The linear score \(z = \mathbf{w}\cdot\mathbf{d}\) still helps: use the line (or plane) \(z = 0\) as a decision boundary. Points on or above it belong to one class and points below to the other. With two features the boundary is

Linear decision boundary\[ \mathbf{w}[0] + \mathbf{w}[1]\,\mathbf{d}[1] + \mathbf{w}[2]\,\mathbf{d}[2] = 0 \quad\Longleftrightarrow\quad \mathbf{d}[2] = -\frac{\mathbf{w}[0]}{\mathbf{w}[2]} - \frac{\mathbf{w}[1]}{\mathbf{w}[2]}\,\mathbf{d}[1] \]
\(\mathbf{w}[0]\)
Intercept weight: shifts the boundary without turning it.
\(\mathbf{w}[1], \mathbf{w}[2]\)
Feature weights: their ratio sets the slope (orientation) of the boundary.
\(\mathbf{d}[1], \mathbf{d}[2]\)
The two descriptive features.

Changing \(\mathbf{w}[0]\) moves the boundary parallel to itself. Changing \(\mathbf{w}[1]\) or \(\mathbf{w}[2]\) changes the slope \(-\mathbf{w}[1]/\mathbf{w}[2]\), rotating it. Scaling all weights by the same positive factor leaves the line where it is but makes the logistic model below more confident.

Why not a step function?

The rule "predict 1 if \(z \ge 0\), else 0" is a step function of the score. Its derivative is 0 everywhere except at \(z = 0\), where it is undefined. Gradient descent needs a slope to follow: on a step function the error surface is flat almost everywhere, so the gradient says nothing about which way to move the weights. A smooth replacement is needed.

Reading Kelleher et al. (2020) Section 7.4.4 (start); slide 5.1

02Logistic regression

The logistic (sigmoid) function is a smooth threshold. It maps any real score to the interval \((0, 1)\): large negative scores give nearly 0, large positive scores nearly 1, and a score of 0 gives exactly 0.5. It is continuous and differentiable everywhere, so gradient descent works.

Logistic function and logistic regression (Kelleher Eqs 7.25, 7.26)\[ \text{logistic}(z) = \frac{1}{1 + e^{-z}}, \qquad \mathbb{M}_\mathbf{w}(\mathbf{d}) = \text{logistic}(\mathbf{w}\cdot\mathbf{d}) = \frac{1}{1 + e^{-\mathbf{w}\cdot\mathbf{d}}} \]
\(z\)
The linear score, any real number.
\(e\)
Euler's number, 2.718….
\(\mathbf{w}\cdot\mathbf{d}\)
Weighted sum \(\sum_j \mathbf{w}[j]\mathbf{d}[j]\) with \(\mathbf{d}[0] = 1\).
\(\mathbb{M}_\mathbf{w}(\mathbf{d})\)
Modelled probability that the target is the positive class.

Why the output lies strictly between 0 and 1: \(e^{-z} \gt 0\) for every \(z\), so the denominator \(1 + e^{-z}\) is greater than 1 and the fraction is less than 1 and positive. Its derivative has a neat form, \(\text{logistic}'(z) = \text{logistic}(z)\,(1 - \text{logistic}(z))\), which the training rule uses.

To classify, apply a threshold, normally 0.5: predict positive if \(\mathbb{M}_\mathbf{w}(\mathbf{d}) \ge 0.5\). Because \(\text{logistic}(z) \ge 0.5\) exactly when \(z \ge 0\), the decision boundary is still the linear one from Section 1. Logistic regression is a linear classifier with a probability attached.

Figure 2.1: It starts at worked example 2.1: \(z = w_0 + w_1\,\text{Hours} - 0.4\,\text{Absences}\) with one absence. The curve is \(P(\text{Pass})\) against study hours, and the dashed line is the 0.5 threshold. Changing \(w_0\) slides the curve sideways, moving the boundary. A larger \(w_1\) makes the curve steeper: the model becomes more certain on either side of the boundary.

Worked example 2.1 A logistic-regression prediction

A model has \(z = -3 + 0.6\,\text{Hours} - 0.4\,\text{Absences}\) and \(P(\text{Pass}) = 1/(1 + e^{-z})\). Predict for a student with 6 study hours a week and 1 absence, using a 0.5 threshold.

1
Score: \(z = -3 + 0.6(6) - 0.4(1) = -3 + 3.6 - 0.4 = 0.2\).
2
Probability: \(e^{-0.2} = 0.8187\), so \(P = 1/1.8187 = 0.550\).
3
\(0.550 \ge 0.5\): predict Pass.
\(P(\text{Pass}) = 0.550\), classified as Pass, only just. With 1 absence the boundary is at \(0.6\,\text{Hours} = 3.4\), so Hours = 5.67.

Reading the output and the weights

  • The output is a modelled probability of the positive class, not a predicted value of any feature. 0.55 does not mean "0.55 study hours" or "55 % of a pass mark"; it means the model estimates a 55 % chance that this student is in the Pass class.
  • A positive weight (StudyHours, +0.6) means increasing that feature raises the score and the probability of the positive class. A negative weight (Absences, −0.4) lowers it. The size of the effect on the probability is not constant: it is largest near \(P = 0.5\) and small where the curve is flat.
  • The intercept sets the probability when all features are zero: here \(\text{logistic}(-3) = 0.047\).

Reading Kelleher et al. (2020) Section 7.4.4; slides 5.1 and 5.2

03Training with gradient descent

Logistic regression is trained with the same batch gradient descent as linear regression: random initial weights, an error delta per weight summed over all instances, an update scaled by \(\alpha\) at the end of each epoch, and repeat until convergence. With the sum of squared errors as the loss, the chain rule adds the derivative of the logistic function to the error delta:

Logistic-regression update (Kelleher Eq 7.32)\[ \mathbf{w}[j] \leftarrow \mathbf{w}[j] + \alpha \sum_{i=1}^{n} \Big( \big(t_i - \mathbb{M}_\mathbf{w}(\mathbf{d}_i)\big) \times \mathbb{M}_\mathbf{w}(\mathbf{d}_i)\big(1 - \mathbb{M}_\mathbf{w}(\mathbf{d}_i)\big) \times \mathbf{d}_i[j] \Big) \]
\(t_i\)
Target of instance \(i\), coded 0 or 1.
\(\mathbb{M}_\mathbf{w}(\mathbf{d}_i)\)
Current predicted probability for instance \(i\).
\(\mathbb{M}(1 - \mathbb{M})\)
Derivative of the logistic function at that instance's score.
\(\mathbf{d}_i[j]\)
Feature \(j\) of instance \(i\) (\(\mathbf{d}_i[0] = 1\)).
\(\alpha\)
Learning rate.

This is the reason for the logistic function: a differentiable threshold gives a usable gradient everywhere. The \(\mathbb{M}(1-\mathbb{M})\) factor is largest near \(P = 0.5\), so instances near the boundary drive most of the learning.

Worked example 3.1 One epoch of logistic regression

Normalised feature \(x\) and target \(t\): (−1, 0), (−0.5, 0), (0.5, 1), (1, 1). Start at \(w_0 = 0\), \(w_1 = 0.5\), with \(\alpha = 0.5\).

1
Scores \(0.5x\): −0.5, −0.25, 0.25, 0.5. Probabilities: 0.3775, 0.4378, 0.5622, 0.6225.
2
Terms \((t - \mathbb{M})\mathbb{M}(1-\mathbb{M})\): \(-0.3775(0.3775)(0.6225) = -0.0887\); \(-0.1078\); \(+0.1078\); \(+0.0887\).
3
Error deltas: \(w_0\): sum of terms \(= 0\). \(w_1\): \((-0.0887)(-1) + (-0.1078)(-0.5) + (0.1078)(0.5) + (0.0887)(1) = 0.2852\).
4
Update: \(w_0 = 0\), \(w_1 = 0.5 + 0.5(0.2852) = 0.6426\).
New weights \(w_0 = 0\), \(w_1 = 0.643\). The probabilities move toward the targets (0.345, 0.420, 0.580, 0.655) and \(L_2\) falls from 0.334 to 0.295. The data are symmetric about 0, so the intercept does not change.

Normalisation and learning curves

Always normalise the descriptive features before training logistic regression. Features on very different scales give error-surface valleys that are long and narrow: the gradient is dominated by the large-valued feature, a learning rate safe for that feature is far too small for the others, and descent zig-zags slowly. Normalised features also keep scores in a range where the logistic function is not saturated (flat), so gradients do not vanish. The cost is interpretability: weights are then per unit of normalised feature.

A learning curve plots the training error against the iteration (epoch). A typical curve drops steeply at first and then flattens: most of the improvement is early and the model is converging. Reasonable stopping criteria: a maximum number of epochs, or stop when the error improves by less than a small tolerance over an epoch. The learning-rate behaviour is as in Week 8: too small is slow, too large oscillates or diverges, and decay combines a fast start with a stable finish.

04Basis functions

A model using the raw features linearly can only fit straight lines (or flat planes and boundaries). When the true relationship is curved, such as crop yield rising with rainfall up to a point and then falling, a raw linear model underfits.

Basis functions \(\phi_k\) transform the raw inputs into new features (squares, products, logs, …). The model is a weighted sum of the basis functions. It is still linear in the weights, so the SSE surface stays convex and the same gradient descent rule applies, with \(\phi_k(\mathbf{d})\) in place of \(\mathbf{d}[k]\). The non-linearity lives entirely in the features.

Model with basis functions (Kelleher Eq 7.33)\[ \mathbb{M}_\mathbf{w}(\mathbf{d}) = \sum_{k=0}^{b} \mathbf{w}[k]\,\phi_k(\mathbf{d}) \]
\(\phi_k(\mathbf{d})\)
The \(k\)-th basis function of the raw features; \(\phi_0(\mathbf{d}) = 1\) for the intercept.
\(\mathbf{w}[k]\)
Weight of basis function \(k\).
\(b\)
Number of basis functions (excluding \(\phi_0\)).

Common choices:

  • Polynomial: \(\phi_0 = 1\), \(\phi_1 = x\), \(\phi_2 = x^2\) (a quadratic), and so on.
  • Interaction: \(\phi = x_1 x_2\), so the effect of one feature can depend on the other, for example income and debt together in a default model.

Basis functions work for classification too: put them inside the logistic function. Then \(z = 0\) is a curve in the raw feature space, so logistic regression can learn curved decision boundaries (a circle, from \(x_1^2\) and \(x_2^2\) terms, for example).

Figure 4.1: Seven fields (dots): yield against seasonal rainfall. The straight line is the least-squares fit of \(w_0 + w_1x\) (SSE 7.10 (t/ha)²). The curve is the least-squares fit of \(w_0 + w_1x + w_2x^2\), with \(x\) in hundreds of mm: \(\hat y = -0.014 + 2.402x - 0.290x^2\), SSE 0.008. Both models are linear in their weights.

Worked example 4.1 Evaluating basis features

Use the quadratic model of Figure 4.1, with \(x\) = rainfall in hundreds of mm: \(\hat y = -0.0143 + 2.4024\,x - 0.2905\,x^2\). (a) Compute the basis features and prediction for 450 mm. (b) At what rainfall is predicted yield highest?

1
\(x = 4.5\): \(\phi_0 = 1\), \(\phi_1 = 4.5\), \(\phi_2 = 20.25\).
2
\(\hat y = -0.0143 + 2.4024(4.5) - 0.2905(20.25) = -0.0143 + 10.811 - 5.882 = 4.91\) t/ha.
3
The peak of a quadratic is at \(x = -w_1/(2w_2) = 2.4024/0.5810 = 4.135\), that is 413.5 mm.
(a) Features (1, 4.5, 20.25) and prediction 4.91 t/ha. (b) Highest predicted yield at about 414 mm of rain.
Watch out

Basis functions must be designed by hand: you have to guess the right shape (quadratic? interaction? log?). Each extra basis function adds a weight, so the gradient-descent search space grows, training gets slower, and the model can overfit. Neural networks (Week 10) learn useful transformations instead of having them designed.

Reading Kelleher et al. (2020) Section 7.4.5; slide 6

05Multinomial logistic regression

Targets can be:

  • Binary: two levels (Pass/Fail).
  • Multiclass: more than two levels, and each instance has exactly one (account type: Family, Single or Business).
  • Multilabel: each instance can have several labels at once (a film tagged Comedy and Romance). This is a different problem.

Multinomial logistic regression handles multiclass targets with a set of one-versus-all models. For a target with \(r\) levels:

  1. One-hot encode the target, so level \(k\) becomes a binary target "is it level \(k\)?" (1 for level \(k\), 0 for all others).
  2. Train \(r\) binary logistic regression models, model \(k\) separating level \(k\) from all the rest.
  3. For a query, run all \(r\) models and normalise their outputs so they sum to 1.
  4. Predict the level whose model gives the highest normalised output.
Normalising one-versus-all outputs (slides; Kelleher Eq 7.38 adapted)\[ \mathbb{M}'_k(\mathbf{q}) = \frac{\mathbb{M}_{\mathbf{w}_k}(\mathbf{q})}{\sum_{l \in \text{levels}(t)} \mathbb{M}_{\mathbf{w}_l}(\mathbf{q})}, \qquad \text{prediction} = \arg\max_k \mathbb{M}'_k(\mathbf{q}) \]
\(\mathbb{M}_{\mathbf{w}_k}(\mathbf{q})\)
Output of the one-versus-all model for level \(k\).
\(\mathbb{M}'_k(\mathbf{q})\)
Normalised output: share of the total, so the \(r\) values sum to 1.

Dividing every output by the same positive sum does not change their order, so the predicted class is the same as picking the largest raw output; normalising just makes the values read as probabilities. Kelleher's textbook version uses the softmax function, \(e^{z_k}/\sum_l e^{z_l}\) applied to the scores, for this step; Week 10 uses softmax in neural networks.

Worked example 5.1 One-versus-all prediction

A vehicle classifier has levels Car, Truck, Bus. The one-hot targets are Car = (1, 0, 0), Truck = (0, 1, 0), Bus = (0, 0, 1). For one query, the three one-versus-all models output 0.60, 0.30 and 0.45. Normalise and predict.

1
Three levels, so three binary models are needed.
2
Sum: \(0.60 + 0.30 + 0.45 = 1.35\).
3
Normalised: Car \(0.60/1.35 = 0.444\), Truck \(0.30/1.35 = 0.222\), Bus \(0.45/1.35 = 0.333\). Check: \(0.444 + 0.222 + 0.333 = 1\).
Predict Car (0.444). The raw outputs summed to 1.35, so they were not probabilities across classes until normalised.

Cross-entropy loss

For multiclass models, the cross-entropy loss is often used instead of squared error. With a one-hot target \(\mathbf{t}\) and predicted probabilities \(\hat{\mathbf{p}}\):

Cross-entropy loss\[ L_{CE}(\mathbf{t}, \hat{\mathbf{p}}) = -\sum_{k} t_k \ln \hat{p}_k = -\ln \hat{p}_{\text{true class}} \]
\(t_k\)
One-hot target: 1 for the true class, 0 otherwise.
\(\hat{p}_k\)
Predicted probability of class \(k\).
\(\ln\)
Natural logarithm.

Only the true class's probability counts. If it is near 1, the loss is near 0; as it approaches 0, \(-\ln\hat p\) grows without limit. Confident wrong answers are punished severely, and the gradient stays large while the model is badly wrong, so it learns faster than with squared error on probabilities. In worked example 5.1, if the true class is Car the loss is \(-\ln 0.444 = 0.811\); if it is Truck, \(-\ln 0.222 = 1.504\).

06Practice problems

Problem 6.1 Probability and decision

Using worked example 2.1's model, \(z = -3 + 0.6\,\text{Hours} - 0.4\,\text{Absences}\), find \(P(\text{Pass})\) for 3 hours and 4 absences, and classify.

1
\(z = -3 + 1.8 - 1.6 = -2.8\).
2
\(P = 1/(1 + e^{2.8}) = 1/(1 + 16.445) = 0.057\).
\(P(\text{Pass}) = 0.057\), well below 0.5: Not Pass.
Problem 6.2 Moving the boundary

A model has \(z = -4 + 2x_1 + x_2\). (a) Write the boundary as \(x_2 = \ldots\). (b) What happens if \(w_0\) becomes −6? (c) If \(w_1\) becomes 1?

1
(a) \(-4 + 2x_1 + x_2 = 0 \Rightarrow x_2 = 4 - 2x_1\): slope −2, intercept 4.
2
(b) \(x_2 = 6 - 2x_1\): same slope, shifted up by 2.
3
(c) \(x_2 = 4 - x_1\): same intercept, slope −1, so the line rotates about the point (0, 4).
(a) \(x_2 = 4 - 2x_1\). (b) Shifted parallel. (c) Rotated.
Problem 6.3 Basis functions

A model uses \(\phi_0 = 1\), \(\phi_1 = x\), \(\phi_2 = x^2\) with weights (1, 3, −0.5). (a) Find the features and prediction at \(x = 2\). (b) Give an interaction basis function for \(x_1, x_2\). (c) Why is the model linear?

1
(a) \(\phi = (1, 2, 4)\); \(\hat y = 1 + 3(2) - 0.5(4) = 5\).
2
(b) \(\phi_3 = x_1 x_2\).
3
(c) The prediction is a weighted sum of fixed features; each weight enters only to the first power.
(a) (1, 2, 4) and 5. (b) \(x_1 x_2\). (c) Linear in the weights, though curved in \(x\).
Problem 6.4 Choosing a representation

Raw features or basis functions? (a) Failure probability rises steadily with load. (b) Reaction yield peaks at a moderate temperature. (c) Default risk depends on the debt-to-income combination.

1
(a) A steady monotonic trend: raw linear features inside the logistic are enough.
2
(b) Rise then fall: add a squared term \(T^2\).
3
(c) A joint effect: add an interaction (or ratio) basis function.
(a) Raw. (b) Polynomial basis. (c) Interaction basis.
Problem 6.5 Multiclass

Four one-versus-all models (Sedan, SUV, Bakkie, Hatch) output 0.20, 0.50, 0.10, 0.40. (a) How many models for 4 levels? (b) Give the one-hot target for SUV. (c) Normalise and predict. (d) Find the cross-entropy loss if the truth is Hatch.

1
(a) 4. (b) (0, 1, 0, 0).
2
(c) Sum 1.2. Normalised: 0.167, 0.417, 0.083, 0.333. Predict SUV.
3
(d) \(-\ln 0.333 = 1.099\).
SUV is predicted (0.417); the loss for a true Hatch is 1.099.

07Formula sheet

Logistic regression

\(\text{logistic}(z) = 1/(1+e^{-z})\), output in \((0,1)\).

\(\mathbb{M}_\mathbf{w}(\mathbf{d}) = \text{logistic}(\mathbf{w}\cdot\mathbf{d})\); positive if \(\ge 0.5 \iff z \ge 0\).

\(\text{logistic}'(z) = \text{logistic}(z)(1 - \text{logistic}(z))\)

Training

\(\mathbf{w}[j] \leftarrow \mathbf{w}[j] + \alpha\sum_i (t_i - \mathbb{M}_i)\mathbb{M}_i(1-\mathbb{M}_i)\mathbf{d}_i[j]\)

Normalise features first. Step function: no usable gradient.

Boundary

\(w_0 + w_1x_1 + w_2x_2 = 0\); slope \(-w_1/w_2\), intercept \(-w_0/w_2\).

Basis functions

\(\mathbb{M}_\mathbf{w}(\mathbf{d}) = \sum_k \mathbf{w}[k]\phi_k(\mathbf{d})\); e.g. \(1, x, x^2, x_1x_2\).

Multiclass

\(r\) one-versus-all models; \(\mathbb{M}'_k = \mathbb{M}_k/\sum_l \mathbb{M}_l\); predict \(\arg\max\).

\(L_{CE} = -\sum_k t_k\ln\hat p_k\)
