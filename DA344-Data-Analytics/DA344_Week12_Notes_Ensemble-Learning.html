Ensemble Learning: Bagging, Boosting, Gradient Boosting and Stacking

An ensemble combines many base models into one prediction, a decision by committee. This page explains why diversity is essential and how the four main methods create and combine it. It also shows how to trace their predictions and score them: majority votes with F1, AdaBoost weights and confidence factors, and gradient-boosting residual corrections.

01Ensemble learning

Ensemble learning trains several models (base learners) from one dataset and aggregates their predictions. It works like a committee: if members make different mistakes, the majority is right more often than any one member.

Key idea

An ensemble only helps if its models differ in their predictive behaviour. Ten identical models trained on identical data make identical mistakes, so averaging them changes nothing.

Ways to make base learners differ:

  1. train the same model type on different subsets of the training instances (bagging, boosting);
  2. train on different subsets of the features (random forests);
  3. use different control-parameter (hyper-parameter) values;
  4. use different training algorithms;
  5. build a heterogeneous ensemble of different model types (stacking).

Aggregation: for a categorical target, vote (majority, or weighted). For a continuous target, take a measure of central tendency: the mean or the median of the predictions.

Decision trees are the usual base learner. Tree induction is sensitive to small changes in the data: a slightly different sample can change the root split and so the whole tree. That instability, usually a weakness, is exactly the diversity an ensemble needs. Trees are also fast to train.

The four methods differ in how they train and combine:

MethodTrainingCombination
BaggingIndependent (parallel) models on bootstrap samplesEqual-weight vote or average
BoostingSequential: each model focuses on what the previous ones got wrongVote weighted by each model's confidence
Gradient boostingSequential: each model predicts the remaining residual errorsBase prediction plus the sum of corrections
StackingDifferent model types on the same dataA meta-model learns how to combine them

02Bagging

Bagging (bootstrap aggregating) trains each model on its own bootstrap sample: a random sample of the dataset, the same size as the dataset, drawn with replacement. Some instances appear several times and others not at all, so every sample, and every model, is different.

The chance that a given instance is never picked in \(n\) draws is \((1 - 1/n)^n\), which tends to \(e^{-1} \approx 0.368\) for large \(n\). Each bootstrap sample therefore leaves out about 37 % of the instances and contains about 63 % of the distinct instances.

Sub-bagging samples without replacement (a smaller subset). It trains faster, but bootstrap sampling tends to give better ensembles.

Figure 2.1: The sample of worked example 2.1. Eight draws with replacement from instances 1 to 8: instance 2 is drawn twice and 5 three times. Instances 1, 4 and 6 are never drawn; they are this tree's out-of-bag instances.

Random forests

A random forest is bagging with decision trees plus a second source of randomness, subspace sampling: at each split, only a random subset of the features may be considered. Induction:

  1. Build \(N\) bootstrap samples \(D_i\) by drawing \(n\) instances with replacement from \(D\).
  2. For each \(D_i\), grow a tree \(T_i\). At every node, choose a random subset of \(m\) features, usually \(m = \sqrt{\text{number of features}}\), and split on the best of those \(m\).
  3. Keep growing each tree until every leaf is pure (no pruning: the averaging over trees controls overfitting).
  4. Predict by majority vote (classification) or the mean (regression) over the trees.

Why restrict the features? Without it, one strong feature would be the root split of almost every tree, and the trees would be highly correlated. Forcing different trees to use different features decorrelates them and increases diversity.

Out-of-bag error and feature importance

  • Out-of-bag error: each tree can be tested on the instances left out of its bootstrap sample, which it never saw. Averaging these gives a validation estimate without a separate hold-out set.
  • Feature importance: keep track of the information gain each feature delivers at every split across the forest. Features with large total gain are the most important.
  • Efficiency: keep one copy of the training data and store each bootstrap sample (and its OOB set) as a list of indexes.

Scoring a voting ensemble

Classification ensembles are scored with the measures from Week 7. With Positive as the positive class:

Precision, recall and F1\[ \text{precision} = \frac{TP}{TP+FP}, \qquad \text{recall} = \frac{TP}{TP+FN}, \qquad F_1 = \frac{2 \times \text{precision} \times \text{recall}}{\text{precision} + \text{recall}} \]
\(TP\)
Positives predicted Positive.
\(FP\)
Negatives predicted Positive.
\(FN\)
Positives predicted Negative.
\(F_1\)
Harmonic mean of precision and recall.

03Boosting

In boosting, base models are trained in sequence, and each one prioritises the instances its predecessors got wrong. Bagging's models are independent and could be trained in parallel; boosting's cannot, because each depends on the previous one's errors.

  • Each instance has a weight \(w_i \ge 0\). Higher-weight instances are more likely to be sampled for (or count more in) training the next model. Initially every \(w_i = 1/n\).
  • Each round trains a model on the weighted data and computes its total error \(\epsilon\): the sum of the weights of the instances it gets wrong.
  • Weights of misclassified instances are increased and weights of correct ones decreased, so the next model concentrates on the hard cases.
  • Each model gets a confidence factor \(\alpha\) that grows as \(\epsilon\) shrinks, and the ensemble's vote is weighted by \(\alpha\).

The base learners are weak learners, presumed only to do better than random guessing (\(\epsilon \lt 0.5\) for two classes). A weak learner with \(\epsilon \gt 0.5\) would get a negative \(\alpha\); one with \(\epsilon = 0.5\) carries no information (\(\alpha = 0\)).

AdaBoost

AdaBoost (adaptive boosting) builds a sequence of weak learners, often decision stumps (one-split trees), but also linear or logistic regression models. With labels \(y_i \in \{-1, +1\}\):

  1. Give every training instance \(x_i\) the weight \(w_1(i) = 1/n\).
  2. Train a weak classifier \(h_t\) and compute its weighted error \(\epsilon_t\).
  3. Compute its voting weight \(\alpha_t\).
  4. Update the weights: multiply by \(e^{\alpha_t}\) if misclassified, by \(e^{-\alpha_t}\) if correct.
  5. Normalise the weights to sum to 1.
  6. Repeat steps 2 to 5 until the desired number of models, or a target performance, is reached.
AdaBoost\[ \epsilon_t = \sum_{i=1}^{n} w_t(i)\, I\big(y_i \ne h_t(x_i)\big), \qquad \alpha_t = \frac12 \ln\!\left(\frac{1 - \epsilon_t}{\epsilon_t}\right) \] \[ w_{t+1}(i) \leftarrow \frac{w_t(i)\, e^{\pm\alpha_t}}{Z_t} \quad (+ \text{ if misclassified}, - \text{ if correct}), \qquad H(x) = \sum_{t} \alpha_t\, h_t(x) \]
\(w_t(i)\)
Weight of instance \(i\) in round \(t\).
\(I(\cdot)\)
Indicator: 1 if the condition holds, else 0.
\(\epsilon_t\)
Weighted error of model \(t\), between 0 and 1.
\(\alpha_t\)
Confidence (voting weight) of model \(t\).
\(Z_t\)
Normalising constant: the sum of the updated weights.
\(H(x)\)
Ensemble score; predict \(+1\) if \(H(x) \ge 0\), else \(-1\).
Worked example 3.1 Two rounds of AdaBoost

Eight instances \(x = 1, \ldots, 8\) with labels \(y = (+,+,+,-,-,+,-,-)\). Round 1 picks the stump \(h_1\): \(+1\) if \(x \le 3.5\), else \(-1\).

1
Initial weights \(1/8 = 0.125\). \(h_1\) misclassifies only \(x = 6\): \(\epsilon_1 = 0.125\).
2
\(\alpha_1 = \tfrac12\ln(0.875/0.125) = \tfrac12\ln 7 = 0.973\).
3
Update: correct instances \(0.125\,e^{-0.973} = 0.0472\); the wrong one \(0.125\,e^{0.973} = 0.3307\). Sum \(Z_1 = 7(0.0472) + 0.3307 = 0.6614\).
4
Normalise: correct instances \(0.0714\) (= 1/14) each; \(x = 6\) gets \(0.5\).
5
Round 2: the best stump on the new weights is \(h_2\): \(+1\) if \(x \le 6.5\). It misclassifies \(x = 4, 5\): \(\epsilon_2 = 2(0.0714) = 0.143\), so \(\alpha_2 = \tfrac12\ln 6 = 0.896\).
After round 1 the misclassified instance holds half of the total weight (0.5). This always happens: AdaBoost reweights so the last model has exactly 50 % weighted error, forcing the next model to do something different. Round 2 fixes \(x = 6\) on its own, but the combined score at \(x = 6\) is \(-0.973 + 0.896 = -0.077\), still negative: a third round is needed.

Confidence-weighted voting

The final AdaBoost prediction weights each model's vote by its \(\alpha_t\). A confident model can therefore outvote two weaker ones, so an AdaBoost ensemble can disagree with a plain majority vote. For an exercise, the slides also turn the confidences into normalised weights with a softmax, \(p_t = e^{\alpha_t}/\sum_j e^{\alpha_j}\). Because \(e^{\alpha}\) compresses the differences between small \(\alpha\) values, softmax weights are more even than the raw \(\alpha\) values.

04Gradient boosting

In gradient boosting, later models are trained to directly correct the errors of earlier ones:

  1. Start with a very simple base model \(M_0\). For a continuous target it usually predicts the overall training mean for everything.
  2. Compute the residuals \(t_i - M_{k-1}(\mathbf{d}_i)\) of the current ensemble.
  3. Train a new model (usually a small tree) to predict those residuals from the descriptive features, not the original target.
  4. Add its predictions, scaled by a learning rate \(\eta\), to the ensemble, and repeat.
Gradient boosting\[ M_k(\mathbf{d}) = M_{k-1}(\mathbf{d}) + \eta\, R_k(\mathbf{d}) = M_0(\mathbf{d}) + \eta \sum_{j=1}^{k} R_j(\mathbf{d}) \]
\(M_0\)
Base prediction, typically the mean target.
\(R_j\)
Model \(j\), trained to predict the residuals left by \(M_{j-1}\).
\(\eta\)
Learning rate, \(0 \lt \eta \le 1\): shrinks each correction.
\(M_k\)
Ensemble prediction after \(k\) corrections.

The name: for squared error, the residual is the negative gradient of the loss with respect to the prediction, so each step moves the predictions downhill, like gradient descent in "function space".

  • A learning rate \(\eta \lt 1\) gives later corrections less impact. One bad correction (say, chasing an outlier) does less damage, so the model is more robust to outliers and less prone to overfit, at the cost of needing more models.
  • Models can predict only the sign of the residual (±1) rather than its magnitude. A huge residual from an outlier then counts the same as a small one, which also reduces sensitivity to outliers.
  • For a categorical target, the initial model predicts a likelihood for each level, and later models predict corrections to those likelihoods.

Figure 4.1: Eight training points (dots). The flat dashed line is \(M_0\), the mean (40.9). Each round fits a least-squares stump to the current residuals and adds \(\eta = 0.5\) times it. The steps show \(M_1\) (thin) and \(M_3\) (thick): the ensemble moves toward the data in halving steps, and the training SSE falls from 1 388.9 to 506.8, 205.7 and 103.8 over the three rounds.

1
Corrections (\(R_1, R_2\)): ID 1 (−10, +4); ID 2 (−10, −6); ID 3 (+8, +4); ID 4 (+8, −6).

05Stacking

Stacking (stacked generalisation) trains a set of different base learners, for example a decision tree, a k-NN classifier and a logistic regression, on the original training data. Their predictions for each instance become new features, the meta-features. A final meta-model is trained on the meta-features (with the original targets) and learns how best to weigh and combine the base learners.

  • Different model types make different kinds of errors (axis-parallel splits, local neighbourhoods, linear boundaries), which gives diversity. The meta-model can learn when to trust which model.
  • To avoid leaking training labels, the meta-features are normally produced on data the base learners were not trained on, for example with cross-validation (out-of-fold) predictions.
  • Compared with bagging, the combination is learned rather than a fixed equal vote. Compared with boosting, the base learners are trained independently: later learners do not prioritise earlier errors.

06Comparing the methods

  • Ensembles of diverse weak learners that beat random guessing perform well: they share a common base level of performance and compensate for each other's weaknesses.
  • Bagging is simpler to implement and parallelise than boosting, so it wins on ease of use and training time. It mainly reduces variance.
  • Boosting's focused training is very effective, mainly reducing bias, but it is prone to overfitting, especially with noisy labels, which keep gaining weight. Learning rates (shrinkage) reduce this.
  • Ensembles work for classification (majority voting) and regression (mean or median).
Exam

Expect to trace votes and compute TP, FP, FN, precision, recall and F1 for bagging; \(\alpha_t\) and confidence-weighted (and softmax-weighted) scores for AdaBoost; and step-by-step predictions, residuals and SSE/MSE for gradient boosting. Code the classes as ±1 and keep three decimals in \(\alpha\).

08Formula sheet

Bagging

Bootstrap: \(n\) draws with replacement; P(left out) \(= (1-1/n)^n \to 0.368\).

Random forest: \(m \approx \sqrt{\#\text{features}}\) per split; grow to pure leaves.

Scoring

Precision \(TP/(TP+FP)\); recall \(TP/(TP+FN)\)

\(F_1 = 2PR/(P+R)\)

AdaBoost

\(w_1(i) = 1/n\); \(\epsilon_t = \sum_i w_t(i) I(y_i \ne h_t(x_i))\)

\(\alpha_t = \tfrac12\ln((1-\epsilon_t)/\epsilon_t)\)

\(w \leftarrow w e^{+\alpha}\) wrong, \(w e^{-\alpha}\) right; normalise.

\(H(x) = \sum_t \alpha_t h_t(x)\); softmax \(p_t = e^{\alpha_t}/\sum_j e^{\alpha_j}\)

Gradient boosting

\(M_0 = \bar t\); \(M_k = M_{k-1} + \eta R_k\)

Residual \(= t - M\). Score with SSE or MSE.

Stacking

Base predictions become meta-features; a meta-model makes the final prediction.
