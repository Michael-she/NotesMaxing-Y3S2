The BJT as a switch, a logic gate and an amplifier

The same common-emitter circuit does three jobs depending on where it operates: between cutoff and saturation it is a switch or a logic gate, and biased in the middle of the active region it is an amplifier. This page shows how to design each.

01The transistor as a switch

Reading Neamen 5.3.1; Lecture 17, slides 3 to 7

The common-emitter circuit with a grounded emitter is an inverter: a low input gives a high output and a high input gives a low output. Used as a switch, the transistor is only ever in one of two states.

StateInputCurrentsLoad\(v_O\)
Off (cutoff)\(v_I \lt V_{BE(on)}\)\(i_B = i_C = 0\)no current, off\(V_{CC}\)
On (saturation)\(v_I\) high, usually \(V_{CC}\)\(i_C = I_{C(sat)}\)full current, on\(V_{CE(sat)}\)

Switching straight from "fully off" to "fully on" keeps the transistor's power low in both states: in cutoff no current flows, and in saturation the voltage across it is only 0.2 V.

Saturated switch\[ I_{C(sat)} = \frac{V_{CC} - V_{load} - V_{CE(sat)}}{R_C} \qquad i_B = \frac{v_I - V_{BE(on)}}{R_B} \]
\(I_{C(sat)}\)
Collector current when saturated, set by the collector loop (A).
\(V_{CC}\)
Supply voltage (V).
\(V_{load}\)
Fixed voltage drop of the load, for example an LED's cut-in voltage \(V_\gamma\) (V); zero for a resistive load.
\(V_{CE(sat)}\)
Saturation voltage, 0.2 V.
\(R_C\)
Resistor in series with the load (\(\Omega\)).
\(i_B\)
Base current (A).
\(v_I\)
Input voltage in the on state (V).
\(V_{BE(on)}\)
0.7 V.
\(R_B\)
Base resistor (\(\Omega\)).

Designing for saturation

The transistor is saturated only if the base current is more than enough to support the collector current: \(\beta i_B \gt I_{C(sat)}\). The lecture designs for \(I_C/I_B = \beta/2\), which gives the base twice the current it would need.

Intuition

Why \(\beta/2\)? \(\beta\) varies widely between transistors of the same type and with temperature. If you designed for exactly \(I_B = I_C/\beta\), a transistor with a lower \(\beta\) would come out of saturation, sit in the active region and dissipate far more power. Overdriving the base by a factor of two keeps every transistor in the batch saturated.

Figure 1.1: When \(v_I\) is high the transistor saturates and \(I_C\) flows through \(R_1\) and the LED. When \(v_I\) is low no current flows and the LED is dark. \(R_1\) sets the LED current.

Worked example 1.1 LED driver

In Figure 1.1 the LED needs 15 mA and has a cut-in voltage \(V_\gamma = 2.0\ \text{V}\). The input is a 3.3 V logic signal. \(\beta = 100\), \(V_{BE(on)} = 0.7\ \text{V}\), \(V_{CE(sat)} = 0.2\ \text{V}\). Find \(R_1\), \(R_B\) and the transistor power when on.

1
Collector loop in saturation: \(R_1 = (5 - 2.0 - 0.2)/15\ \text{mA} = 187\ \Omega\).
2
Design for \(I_C/I_B = \beta/2 = 50\): \(I_B = 15\ \text{mA}/50 = 0.30\ \text{mA}\).
3
Base loop: \(R_B = (3.3 - 0.7)/0.30\ \text{mA} = 8.67\ \text{k}\Omega\).
4
\(P = I_B V_{BE(on)} + I_C V_{CE(sat)} = (0.30)(0.7) + (15)(0.2) = 3.21\ \text{mW}\).
5
With standard values \(R_1 = 180\ \Omega\) and \(R_B = 8.2\ \text{k}\Omega\): \(I_C = 15.6\ \text{mA}\), \(I_B = 0.317\ \text{mA}\), and \(I_C/I_B = 49\), still well below \(\beta\).
\(R_1 = 187\ \Omega\) (use 180 Ω), \(R_B = 8.67\ \text{k}\Omega\) (use 8.2 kΩ), \(P = 3.2\ \text{mW}\).

pnp load switch

A pnp transistor with its emitter at the supply switches a load connected to ground (a "high-side" switch). It is on when the input is pulled low and off when the input is at \(V^+\), because then \(V_{EB} = 0\).

Figure 1.2: With \(v_I = V^+\) the E-B junction has no voltage across it and the transistor is off. With \(v_I = 0\) base current flows out through \(R_B\) and the load sees \(V^+ - V_{EC(sat)}\).

Worked example 1.2 switching a 2 A load

In Figure 1.2, \(V^+ = 24\ \text{V}\) and the load draws 2 A when on. \(\beta = 50\), \(V_{EB(on)} = 0.7\ \text{V}\), \(V_{EC(sat)} = 0.2\ \text{V}\). The input is 0 V for on. Find \(R_B\) and the transistor power.

1
Design for \(I_C/I_B = \beta/2 = 25\): \(I_B = 2\ \text{A}/25 = 80\ \text{mA}\).
2
Base loop from \(V^+\) to \(v_I = 0\): \(R_B = (24 - 0.7 - 0)/80\ \text{mA} = 291\ \Omega\).
3
\(P = (80\ \text{mA})(0.7) + (2\ \text{A})(0.2) = 0.456\ \text{W}\). The load receives \(23.8 \times 2 = 47.6\ \text{W}\).
\(R_B = 291\ \Omega\) and \(P = 0.456\ \text{W}\): the transistor controls about 100 times its own dissipation.
Watch out

A large load current needs a large base current (80 mA here), which an ordinary logic output cannot supply. In practice a second, smaller transistor drives the base. The slide's Example 5.11(b), with a 5 A load, needs 250 mA of base current for the same reason.

02Digital logic: the NOR gate

Reading Neamen 5.3.2; Lecture 17, slide 8

Put two inverters in parallel, sharing one collector resistor, and the output is low whenever either transistor is on. In positive logic (high voltage = 1, low voltage = 0) that is the NOR function.

Figure 2.1: Each input drives one base through its own \(R_B\). The collectors are joined, so if either transistor saturates, \(V_O\) is pulled down to 0.2 V.

\(V_1\)\(V_2\)\(Q_1\)\(Q_2\)\(V_O\)
0 V0 Voffoff5 V (1)
5 V0 Vsaturatedoff0.2 V (0)
0 V5 Voffsaturated0.2 V (0)
5 V5 Vsaturatedsaturated0.2 V (0)
Worked example 2.1 checking that the gate saturates

In Figure 2.1, \(R_C = 1\ \text{k}\Omega\), \(R_B = 20\ \text{k}\Omega\), \(\beta = 50\). Check the output low level with one input at 5 V, then with both, and find the lowest "high" input voltage that still saturates one transistor.

1
The current in \(R_C\) when the output is low: \(I_R = (5 - 0.2)/1\ \text{k}\Omega = 4.8\ \text{mA}\).
2
One input high: \(I_B = (5 - 0.7)/20\ \text{k}\Omega = 0.215\ \text{mA}\). \(\beta I_B = 10.75\ \text{mA} \gt 4.8\ \text{mA}\), so that transistor saturates with \(\beta_{forced} = 4.8/0.215 = 22.3\).
3
Both high: the two transistors share the 4.8 mA, 2.4 mA each, so each is even deeper in saturation (\(\beta_{forced} = 11.2\)).
4
Saturation needs \(I_B \ge I_R/\beta = 96\ \mu\text{A}\), so \(V_{in} \ge (96\ \mu\text{A})(20\ \text{k}\Omega) + 0.7 = 2.62\ \text{V}\).
The output low level is 0.2 V for every input combination with a 1. A "1" input must be at least 2.62 V for one transistor alone to pull the output fully low.

03The transistor as an amplifier

Reading Neamen 5.3.3; Lecture 17, slides 9 to 11

Between cutoff and saturation the transfer curve of the inverter is a sloped straight line. If a DC source \(V_{BB}\) biases the transistor in that region and a small time-varying signal \(\Delta v_I\) is added to the base circuit, the output changes by \(\Delta v_O\), which is larger than \(\Delta v_I\) when the slope is steeper than 1.

Gain from the transfer curve

Voltage gain of the basic CE stage\[ A_v = \frac{\Delta v_O}{\Delta v_I} = -\frac{\beta R_C}{R_B} \]
\(A_v\)
Voltage gain, the slope of the transfer curve in the active region (no unit).
\(\Delta v_O\)
Change in output voltage (V).
\(\Delta v_I\)
Change in input voltage (V).
\(\beta\)
Current gain.
\(R_C\)
Collector resistor (\(\Omega\)).
\(R_B\)
Base resistor (\(\Omega\)).

The negative sign is the inverting action: as \(v_I\) rises, \(v_O\) falls. The formula assumes the Early voltage \(V_A = \infty\), as in the lecture's Example 5.13.

Worked example 3.1 gain and bias of a CE amplifier

A grounded-emitter npn stage has \(V^+ = 9\ \text{V}\), \(R_B = 200\ \text{k}\Omega\), \(R_C = 6\ \text{k}\Omega\) and \(\beta = 100\). Find the active range of \(v_I\), the gain, and the Q-point in the middle of the active range.

1
Cutoff below \(v_I = 0.7\ \text{V}\) (\(v_O = 9\ \text{V}\)).
2
Active: \(v_O = 9 - \frac{(100)(6\ \text{k})}{200\ \text{k}}(v_I - 0.7) = 9 - 3(v_I - 0.7)\), so \(A_v = -3\).
3
Saturation at \(v_O = 0.2\ \text{V}\): \(v_I = 0.7 + 8.8/3 = 3.63\ \text{V}\).
4
Middle of the active range: \(V_{BB} = (0.7 + 3.63)/2 = 2.17\ \text{V}\), where \(v_O = 9 - 3(1.467) = 4.60\ \text{V}\), halfway between 9 V and 0.2 V.
5
A signal of ±0.4 V around the Q-point gives \(v_O = 4.60 \mp 1.2\ \text{V}\), from 3.4 V to 5.8 V. The largest input amplitude before clipping is \((3.63 - 0.7)/2 = 1.47\ \text{V}\).
\(A_v = -3\), active for \(0.7 \lt v_I \lt 3.63\ \text{V}\), Q-point at \(V_{BB} = 2.17\ \text{V}\), \(V_O = 4.60\ \text{V}\); input amplitudes up to 1.47 V are amplified without clipping.

Figure 3.1: The amber dashed lines mark the input swing of ±0.4 V; the grey dashed lines mark the resulting output swing of ±1.2 V. The output moves down when the input moves up.

Where to put the Q-point

The Q-point must leave room for the signal on both sides. Biased too close to saturation, the positive input peaks drive the transistor into saturation and the output flattens at \(V_{CE(sat)}\). Biased too close to cutoff, the negative peaks switch it off and the output flattens at \(V^+\). Either way the output is clipped: it is no longer a scaled copy of the input.

Figure 3.2: Computed from the transfer curve. With the Q-point in the middle (teal), \(v_O\) swings cleanly between 2.8 V and 6.4 V. With \(V_{BB} = 3.30\ \text{V}\) (amber) the input peaks reach 3.9 V, beyond the 3.63 V saturation edge, so the output bottoms out at 0.2 V for part of every cycle.

Exam

"Bias for maximum symmetrical swing" means put the Q-point in the middle of the active part of the transfer curve (or of the load line). State the two limits first, then take their average.

04Practice problems

Problem 4.1 pnp switch with a forced beta

A pnp transistor has its emitter at \(V^+ = 12\ \text{V}\), its base driven from \(V_I\) through \(R_B\), and \(R_C = 1\ \text{k}\Omega\) from collector to ground, with \(V_O\) at the collector. \(V_{EB(on)} = 0.7\ \text{V}\), \(V_{EC(sat)} = 0.2\ \text{V}\). (a) Find \(V_O\) when the transistor is saturated. (b) Find \(R_B\) so that \(I_C/I_B = 20\) when \(V_I = 3\ \text{V}\).

1
(a) \(V_O = V^+ - V_{EC(sat)} = 11.8\ \text{V}\).
2
(b) \(I_{C(sat)} = 11.8\ \text{V}/1\ \text{k}\Omega = 11.8\ \text{mA}\), so \(I_B = 11.8/20 = 0.59\ \text{mA}\).
3
Base loop: \(V^+ = V_{EB(on)} + I_B R_B + V_I\), so \(R_B = (12 - 0.7 - 3)/0.59\ \text{mA} = 14.1\ \text{k}\Omega\).
(a) \(V_O = 11.8\ \text{V}\). (b) \(R_B = 14.1\ \text{k}\Omega\).
Problem 4.2 npn switch output low

An npn transistor with \(\beta = 40\) has \(R_C = 470\ \Omega\) to \(V_{CC} = 12\ \text{V}\) and a grounded emitter. Find \(R_B\) so that \(V_O = 0.2\ \text{V}\) and \(I_C/I_B = 15\) when \(V_I = 5\ \text{V}\).

1
\(V_O = 0.2\ \text{V}\) means saturation, so \(\beta\) does not apply and the forced ratio is used instead.
2
\(I_C = (12 - 0.2)/470 = 25.1\ \text{mA}\); \(I_B = 25.1/15 = 1.67\ \text{mA}\).
3
\(R_B = (5 - 0.7)/1.674\ \text{mA} = 2.57\ \text{k}\Omega\).
\(R_B = 2.57\ \text{k}\Omega\).
Problem 4.3 a NOR gate that does not saturate

The NOR gate of Figure 2.1 is built with \(R_B = 50\ \text{k}\Omega\) instead (\(R_C = 1\ \text{k}\Omega\), \(\beta = 50\)). Find \(V_O\) with one input at 5 V, and with both.

1
One input high: \(I_B = 4.3/50\ \text{k}\Omega = 86\ \mu\text{A}\); \(\beta I_B = 4.3\ \text{mA} \lt 4.8\ \text{mA}\), so the transistor is not saturated.
2
It is forward-active: \(V_O = 5 - (4.3\ \text{mA})(1\ \text{k}\Omega) = 0.70\ \text{V}\).
3
Both high: the transistors can together sink \(2 \times 4.3 = 8.6\ \text{mA} \gt 4.8\ \text{mA}\), so they saturate and \(V_O = 0.2\ \text{V}\).
One input: \(V_O = 0.70\ \text{V}\) (a weak logic 0). Both: \(V_O = 0.2\ \text{V}\). The base resistors are too large for reliable logic.
Problem 4.4 amplifier swing

A grounded-emitter npn stage has \(V^+ = 5\ \text{V}\), \(R_B = 100\ \text{k}\Omega\), \(R_C = 2\ \text{k}\Omega\), \(\beta = 150\). Find \(A_v\), the bias \(V_{BB}\) for maximum symmetrical swing, \(V_{OQ}\), and the largest input amplitude.

1
\(A_v = -(150)(2\ \text{k})/100\ \text{k} = -3\).
2
Saturation edge: \(v_I = 0.7 + 4.8/3 = 2.3\ \text{V}\). Middle: \(V_{BB} = (0.7 + 2.3)/2 = 1.5\ \text{V}\), \(V_{OQ} = 5 - 3(0.8) = 2.6\ \text{V}\).
3
Largest amplitude: \((2.3 - 0.7)/2 = 0.8\ \text{V}\), giving an output swing of ±2.4 V.
\(A_v = -3\), \(V_{BB} = 1.5\ \text{V}\), \(V_{OQ} = 2.6\ \text{V}\), input amplitude up to 0.8 V.
Problem 4.5 relay driver

A relay coil of 120 Ω is switched from 12 V by an npn transistor whose \(\beta\) is at least 60. The input is 5 V for on. Design \(R_B\) for \(I_C/I_B = \beta_{min}/2\) and find the transistor power.

1
\(I_C = (12 - 0.2)/120 = 98.3\ \text{mA}\).
2
\(I_B = 98.3/30 = 3.28\ \text{mA}\); \(R_B = (5 - 0.7)/3.28\ \text{mA} = 1.31\ \text{k}\Omega\).
3
\(P = (3.28)(0.7) + (98.3)(0.2) = 22.0\ \text{mW}\).
\(R_B = 1.31\ \text{k}\Omega\), \(P = 22\ \text{mW}\). Using \(\beta_{min}\) rather than a typical \(\beta\) is what makes the design safe for every transistor.

05Formula sheet

Switch

Off: \(v_I \lt 0.7\ \text{V}\), \(i_C = 0\), \(v_O = V_{CC}\)

On: \(I_{C(sat)} = (V_{CC} - V_{load} - V_{CE(sat)})/R_C\)

Saturated if \(\beta i_B \gt I_{C(sat)}\); design \(I_C/I_B = \beta/2\)

\(P = I_B V_{BE(on)} + I_C V_{CE(sat)}\)

NOR gate

Output low if any input is high

\(I_R = (V_{CC} - 0.2)/R_C\) shared by the on transistors

Minimum high input: \(V_{in} = R_B I_R/\beta + 0.7\)

Amplifier

\(A_v = \Delta v_O/\Delta v_I = -\beta R_C/R_B\)

Active for \(0.7 \lt v_I \lt 0.7 + (V^+ - 0.2)/|A_v|\)

Maximum swing: Q-point in the middle of that range
