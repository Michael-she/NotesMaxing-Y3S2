MOSFET load lines, transistor loads and basic applications

How to locate a MOSFET's operating mode on the load line, bias it with a current source, use another MOSFET as the load, and build switches, logic gates and amplifiers from these pieces.

01Load line and modes of operation

Reading Neamen 3.2.2; Lecture 26, slides 2 to 6

For the common-source circuit of Week 10 the drain loop gives the load line \(V_{DS} = V_{DD} - I_D R_D\), from \(V_{DD}\) on the voltage axis to \(V_{DD}/R_D\) on the current axis. As \(V_{GS}\) rises from zero:

The transition point

The transition point separates saturation from non-saturation. There \(V_{DS} = V_{DS(sat)} = V_{GS} - V_{TN}\), so the saturation equation becomes \(I_D = K_n V_{DS}^2\). Substituting into the load line gives one quadratic in \(V_{DS}\):

Transition point of a common-source stage\[ R_D K_n V_{DS}^2 + V_{DS} - V_{DD} = 0 \qquad V_{GS} = V_{DS} + V_{TN} \]
\(R_D\)
Drain resistor (\(\Omega\)).
\(K_n\)
Conduction parameter (A/V²).
\(V_{DS}\)
Drain-source voltage at the transition point (V).
\(V_{DD}\)
Supply voltage (V).
\(V_{GS}\)
Gate-source voltage that puts the transistor at the transition point (V).
\(V_{TN}\)
Threshold voltage (V).
Worked example 1.1 finding the transition point

A common-source stage has \(V_{DD} = 6\ \text{V}\), \(R_D = 15\ \text{k}\Omega\), \(V_{TN} = 0.8\ \text{V}\) and \(K_n = 0.2\ \text{mA/V}^2\). Find \(V_{DS}\), \(V_{GS}\) and \(I_D\) at the transition point.

1
\((15\ \text{k})(0.2\ \text{mA/V}^2) = 3\ \text{V}^{-1}\), so \(3V_{DS}^2 + V_{DS} - 6 = 0\).
2
The positive root is \(V_{DS} = (-1 + \sqrt{73})/6 = 1.257\ \text{V}\).
3
\(V_{GS} = 1.257 + 0.8 = 2.057\ \text{V}\); \(I_D = 0.2(1.257)^2 = 0.316\ \text{mA}\).
Transition at \(V_{DS} = 1.26\ \text{V}\), \(V_{GS} = 2.06\ \text{V}\), \(I_D = 0.316\ \text{mA}\). Any \(V_{GS}\) between 0.8 V and 2.06 V keeps the transistor saturated.

Figure 1.1: It starts at worked example 1.1, with \(v_{GS} = 2.057\ \text{V}\) on the transition. The teal load line runs from \(V_{DD}/R_D\) to \(V_{DD}\). The dashed amber curve is \(i_D = K_n v_{DS}^2\), the boundary between the two regions, and the amber dot is where the load line crosses it. The faint curves are \(v_{GS}\) = 1.2, 1.6, 2.0, 2.4 and 2.8 V. Slide \(v_{GS}\) and the black operating point runs along the load line: below the amber dot it is saturated, above it non-saturated.

Problem-solving technique

Key idea

1. Assume saturation: \(V_{GS} \gt V_{TN}\), \(I_D \gt 0\), \(V_{DS} \ge V_{DS(sat)}\).
2. Analyse with the saturation equation.
3. Check: if \(V_{GS} \lt V_{TN}\) the transistor is probably cut off; if \(V_{DS} \lt V_{DS(sat)}\) it is probably in non-saturation.
4. If the check fails, change the assumption, reanalyse and check again.

02Biasing with a current source

Reading Neamen 3.2.3; Lecture 26, Design Example 3.8

A constant current source \(I_Q\) in the source lead fixes \(I_D = I_Q\) directly, whatever the transistor's parameters. The gate is held at 0 V through \(R_G\) (no gate current, so no drop across it), and the source settles at whatever \(V_S = -V_{GS}\) the transistor needs to carry \(I_Q\). In an amplifier a capacitor \(C_S\) bypasses the source to ground for signals.

Figure 2.1: The current source sets the drain current. \(R_D\) then sets \(v_D\), and the transistor's own equation sets \(v_S\).

Worked example 2.1 current-source bias and parameter tolerance

In Figure 2.1, \(I_Q = 0.3\ \text{mA}\) and \(V_D\) must be 2 V. The transistor has \(V_{TN} = 1\ \text{V}\), \(k_n' = 100\ \mu\text{A/V}^2\) and \(W/L = 4\). Find \(R_D\), \(V_S\) and \(V_{DS}\), and the spread in \(V_{DS}\) if \(k_n'\) varies by ±10 %.

1
\(K_n = \frac{100}{2}(4) = 0.2\ \text{mA/V}^2\). Saturation: \(0.3 = 0.2(V_{GS} - 1)^2\), so \(V_{GS} = 2.225\ \text{V}\) and \(V_S = -2.225\ \text{V}\).
2
\(R_D = (5 - 2)/0.3\ \text{mA} = 10\ \text{k}\Omega\); \(V_{DS} = 2 - (-2.225) = 4.225\ \text{V} \gt V_{DS(sat)} = 1.225\ \text{V}\).
3
\(k_n' = 90\ \mu\text{A/V}^2\): \(V_{GS} = 2.291\ \text{V}\), \(V_{DS} = 4.291\ \text{V}\). \(k_n' = 110\ \mu\text{A/V}^2\): \(V_{GS} = 2.168\ \text{V}\), \(V_{DS} = 4.168\ \text{V}\).
\(R_D = 10\ \text{k}\Omega\), \(V_S = -2.22\ \text{V}\), \(V_{DS} = 4.22\ \text{V}\). A ±10 % change in \(k_n'\) moves \(V_{DS}\) by only −1.3 % to +1.6 %, because the current, and so \(V_D\), cannot change.

03The enhancement-load device

Reading Neamen 3.2.3; Lecture 26, slides 13 to 17, and Lecture 27, slides 2 to 3

An enhancement NMOS with its gate tied to its drain has \(V_{GS} = V_{DS}\). Then \(V_{DS} = V_{DS(sat)} + V_{TN}\), which is always larger than \(V_{DS(sat)}\) because \(V_{TN} \gt 0\). So the device is always in saturation when it conducts, and behaves as a non-linear resistor:

Enhancement load (gate tied to drain)\[ I_D = K_n(V_{DS} - V_{TN})^2 \]
\(I_D\)
Drain current (A).
\(K_n\)
Conduction parameter (A/V²).
\(V_{DS}\)
Drain-source voltage, equal to \(V_{GS}\) (V).
\(V_{TN}\)
Threshold voltage, positive (V).
Worked example 3.1 sizing an enhancement load

A diode-connected NMOS (\(V_{TN} = 0.6\ \text{V}\), \(k_n' = 80\ \mu\text{A/V}^2\)) is in series with \(R_S = 20\ \text{k}\Omega\) from \(V_{DD} = 5\ \text{V}\) to ground. Find \(W/L\) for \(V_{DS} = 2.0\ \text{V}\).

1
\(I_D = (5 - 2)/20\ \text{k}\Omega = 0.15\ \text{mA}\).
2
Always saturated: \(0.15\ \text{mA} = \frac{80\ \mu\text{A/V}^2}{2}\frac{W}{L}(2.0 - 0.6)^2\), so \(W/L = 1.91\).
\(W/L = 1.91\).

Inverter with an enhancement load

Connecting the load device \(M_L\) above a driver \(M_D\) gives an NMOS inverter that needs no resistor. The load is always saturated; the driver is saturated for small \(v_I\) (large \(v_O\)) and in non-saturation for large \(v_I\) (small \(v_O\)). The two drain currents are equal.

Figure 3.1: \(M_L\)'s gate is tied to \(V_{DD}\) with its drain, so \(V_{GSL} = V_{DSL} = V_{DD} - v_O\). The input drives the gate of \(M_D\).

Driver transition point\[ V_{It} = \frac{V_{DD} - V_{TNL} + V_{TND}\left(1 + \sqrt{K_{nD}/K_{nL}}\right)}{1 + \sqrt{K_{nD}/K_{nL}}} \qquad V_{Ot} = V_{It} - V_{TND} \]
\(V_{It}\)
Input voltage at which the driver moves from saturation into non-saturation (V).
\(V_{DD}\)
Supply voltage (V).
\(V_{TNL}\)
Threshold voltage of the load (V).
\(V_{TND}\)
Threshold voltage of the driver (V).
\(K_{nD}\)
Conduction parameter of the driver (A/V²).
\(K_{nL}\)
Conduction parameter of the load (A/V²).
\(V_{Ot}\)
Output voltage at that point (V).

This comes from equating the two saturation currents, \(\sqrt{K_{nD}/K_{nL}}(V_I - V_{TND}) = V_{DD} - V_O - V_{TNL}\), and setting \(V_O = V_{DS(sat)} = V_I - V_{TND}\).

Worked example 3.2 enhancement-load inverter

In Figure 3.1, \(V_{DD} = 5\ \text{V}\), \(V_{TND} = V_{TNL} = 0.8\ \text{V}\), \(K_{nD} = 80\ \mu\text{A/V}^2\), \(K_{nL} = 20\ \mu\text{A/V}^2\). Find \(v_O\) for \(v_I = 1.5\ \text{V}\) and 4.5 V, and the transition point.

1
\(v_I = 1.5\ \text{V}\), assume the driver saturated: \(80(0.7)^2 = 20(5 - v_O - 0.8)^2\), so \(4.2 - v_O = 2(0.7)\) and \(v_O = 2.80\ \text{V}\). Check: \(V_{DSD} = 2.8 \gt 0.7\ \text{V}\).
2
\(v_I = 4.5\ \text{V}\), assume the driver in non-saturation: \(80[2(3.7)v_O - v_O^2] = 20(4.2 - v_O)^2\), which simplifies to \(100v_O^2 - 760v_O + 352.8 = 0\). The valid root is \(v_O = 0.497\ \text{V} \lt 3.7\ \text{V}\).
3
\(\sqrt{80/20} = 2\): \(V_{It} = (5 - 0.8 + 0.8 \times 3)/3 = 2.2\ \text{V}\), \(V_{Ot} = 1.4\ \text{V}\).
\(v_O = 2.80\ \text{V}\) at \(v_I = 1.5\ \text{V}\); \(v_O = 0.497\ \text{V}\) at 4.5 V; the driver leaves saturation at \(v_I = 2.2\ \text{V}\), \(v_O = 1.4\ \text{V}\).
Watch out

With the driver off, the enhancement load stops conducting when \(V_{GSL}\) falls to \(V_{TNL}\), so the output high level is only \(V_{DD} - V_{TNL}\) (4.2 V here), not \(V_{DD}\).

04The depletion-load device

Reading Neamen 3.2.3; Lecture 27, slides 4 to 9

A depletion NMOS with its gate tied to its source has \(V_{GS} = 0\). Unlike the enhancement load it can be in either region: \(V_{DS(sat)} = 0 - V_{TN} = -V_{TN}\), which is positive because \(V_{TN}\) is negative. Below that it is in non-saturation; above it, it is saturated and passes the constant current \(K_n V_{TN}^2\), acting like a current source.

Figure 4.1: The solid channel line marks the depletion device. Its gate is tied to the output (its source), so \(V_{GSL} = 0\).

Worked example 4.1 depletion-load inverter, input high

In Figure 4.1, \(V_{DD} = 5\ \text{V}\), \(V_{TND} = 0.8\ \text{V}\), \(V_{TNL} = -1.5\ \text{V}\), \(K_{nD} = 60\ \mu\text{A/V}^2\), \(K_{nL} = 15\ \mu\text{A/V}^2\). Find \(v_O\) for \(v_I = 5\ \text{V}\).

1
Assume the driver in non-saturation and the load saturated: \(60[2(4.2)v_O - v_O^2] = 15(1.5)^2 = 33.75\ \mu\text{A}\).
2
\(60v_O^2 - 504v_O + 33.75 = 0\): roots 0.0675 V and 8.33 V. The second is above \(V_{DD}\) and impossible.
3
Check: \(V_{DSD} = 0.0675 \lt 4.2\ \text{V}\) (non-saturation) and \(V_{DSL} = 4.93 \gt 1.5\ \text{V}\) (saturation). Both assumptions hold.
\(v_O = 0.0675\ \text{V}\), with \(I_D = 33.75\ \mu\text{A}\). With \(v_I\) low the driver is off and \(v_O\) rises all the way to \(V_{DD}\), as Figure 4.2 shows.

Figure 4.2: Each curve is solved numerically by equating the driver and load currents at every input voltage, so it depends only on the ratio \(K_{nD}/K_{nL}\) and the thresholds. It starts at worked examples 3.2 and 4.1, which share a ratio of 4. The depletion load (amber) gives a full 5 V high level and a sharper transition; the enhancement load (teal) stops at \(V_{DD} - V_{TNL}\). A larger ratio pulls both low levels closer to 0 V.

Worked example 4.2 sizing a depletion device with a resistor

A depletion NMOS with gate tied to source (\(V_{TN} = -1.5\ \text{V}\), \(k_n' = 100\ \mu\text{A/V}^2\)) is in series with \(R_S = 10\ \text{k}\Omega\) across \(V_{DD} = 5\ \text{V}\). Find \(W/L\) for (a) \(V_{DS} = 2.5\ \text{V}\) and (b) \(V_{DS} = 1.0\ \text{V}\), and state the region.

1
\(V_{DS(sat)} = 0 - (-1.5) = 1.5\ \text{V}\).
2
(a) \(2.5 \gt 1.5\): saturation. \(I_D = 2.5/10\ \text{k} = 0.25\ \text{mA} = 50\frac{W}{L}(1.5)^2\ \mu\text{A}\), so \(W/L = 2.22\).
3
(b) \(1.0 \lt 1.5\): non-saturation. \(I_D = 4/10\ \text{k} = 0.40\ \text{mA} = 50\frac{W}{L}[2(1.5)(1.0) - 1.0^2]\ \mu\text{A}\), so \(W/L = 4.0\).
(a) \(W/L = 2.22\), saturation. (b) \(W/L = 4.0\), non-saturation.
Watch out

On the slide for TYU 3.10(b), the equation is written with \(I_D = 0.1875\ \text{mA}\), the current from part (a), but the answer \(W/L = 6.1\) uses the correct \(I_D = 0.3125\ \text{mA}\) computed one line earlier. With 0.1875 mA the result would be 3.66. The answer 6.1 is right.

05Applications

Reading Neamen 3.3; Lecture 28

Switch

The resistor-load NMOS inverter is a switch. For \(v_I \lt V_{TN}\) it is off: no current, no power, \(v_O = V_{DD}\). When \(v_I\) first exceeds \(V_{TN}\), \(v_{DS}\) is still large, so the transistor starts in saturation. As \(v_I\) rises \(v_{DS}\) falls, and with \(v_I = V_{DD}\) the transistor is in non-saturation with the lowest \(v_O\) and the highest current.

Worked example 5.1 LED driver

An NMOS (\(K_n = 5\ \text{mA/V}^2\), \(V_{TN} = 1\ \text{V}\)) switches an LED (\(V_\gamma = 1.8\ \text{V}\)) in series with \(R\) from 5 V. With \(v_I = 5\ \text{V}\) the LED must carry 15 mA. Find \(R\).

1
Expect non-saturation (switch fully on): \(15 = 5[2(4)V_{DS} - V_{DS}^2]\), so \(V_{DS}^2 - 8V_{DS} + 3 = 0\) and \(V_{DS} = 0.394\ \text{V}\). Check: \(0.394 \lt V_{DS(sat)} = 4\ \text{V}\).
2
\(R = (5 - 1.8 - 0.394)/15\ \text{mA} = 187\ \Omega\).
\(R = 187\ \Omega\); the transistor drops only 0.39 V.

NOR gate

Two NMOS transistors in parallel with a shared drain resistor make a NOR gate, exactly like the BJT version of Week 8: the output is high only when both inputs are low. When one or both inputs are high, the "on" transistors are in non-saturation and pull the output low.

Figure 5.1: With both inputs high the two transistors share the current through \(R_D\), so each carries half of it.

Worked example 5.2 NOR gate output levels

In Figure 5.1, \(R_D = 40\ \text{k}\Omega\), \(V_{TN} = 0.8\ \text{V}\), \(K_n = 60\ \mu\text{A/V}^2\). Find \(V_O\) and the currents for (a) \(V_1 = 5\ \text{V}\), \(V_2 = 0\); (b) \(V_1 = V_2 = 5\ \text{V}\).

1
(a) \(M_2\) is off. \(M_1\) in non-saturation: \((40\ \text{k})(60\ \mu)[2(4.2)V_O - V_O^2] = 5 - V_O\), giving \(2.4V_O^2 - 21.16V_O + 5 = 0\) and \(V_O = 0.243\ \text{V}\). \(I_R = I_{D1} = (5 - 0.243)/40\ \text{k} = 0.119\ \text{mA}\).
2
(b) Both on and identical: \(2 \times 2.4[8.4V_O - V_O^2] = 5 - V_O\), so \(4.8V_O^2 - 41.32V_O + 5 = 0\) and \(V_O = 0.123\ \text{V}\). \(I_R = 0.122\ \text{mA}\), \(I_{D1} = I_{D2} = 0.061\ \text{mA}\).
(a) \(V_O = 0.243\ \text{V}\), \(I_R = 0.119\ \text{mA}\). (b) \(V_O = 0.123\ \text{V}\), \(I_{D1} = I_{D2} = 0.061\ \text{mA}\). Two transistors in parallel pull the output lower than one.

Amplifier

Biased in saturation, a common-source stage is an amplifier. The bias resistors set the Q-point on the DC load line; a sinusoidal signal added to \(V_{GSQ}\) moves the operating point up and down the load line, so \(i_D\) and \(v_{DS}\) vary sinusoidally about \(I_{DQ}\) and \(V_{DSQ}\). The gain depends on the transistor parameters and the circuit resistors, and is the subject of small-signal analysis. As with the BJT (Week 8), the Q-point must leave room on both sides: too close to the transition point and the negative output peaks enter non-saturation; too close to cutoff and the positive peaks clip at \(V_{DD}\).

07Formula sheet

Load line

\(V_{DS} = V_{DD} - I_D R_D\)

Transition: \(R_D K_n V_{DS}^2 + V_{DS} - V_{DD} = 0\), \(V_{GS} = V_{DS} + V_{TN}\)

Current-source bias

\(I_D = I_Q\), \(V_G = 0\), \(V_S = -V_{GS}\)

\(V_{GS} = V_{TN} + \sqrt{I_Q/K_n}\)

Enhancement load
