Tutorial Solutions: MOSFET Questions

Full worked solutions to the MOSFET questions of Tutorials 9 and 10, with the memo discrepancies flagged.

01The common method

Every question below uses the same skeleton, so learn it once.

  1. Work out the gate voltage or the control voltage \(V_{GS}\) (or \(V_{SG}\)) from the circuit.
  2. Assume saturation and use \(I_D = K(\text{overdrive})^2\). Solve for the overdrive with the positive square root.
  3. Check the assumption: output voltage against the edge of saturation. A switch is the one case where the answer is non-saturation by design.
  4. Find the resistors from Ohm's law and the divider formulas.
Divider with specified input resistance\[ R_1 = \frac{R_{in}(V^+ - V^-)}{V_G - V^-} \qquad R_2 = \frac{R_1R_{in}}{R_1 - R_{in}} \]
\(R_1, R_2\)
Upper and lower divider resistors, in \(\Omega\).
\(R_{in}\)
\(R_1 \parallel R_2\), in \(\Omega\).
\(V^+, V^-\)
Supplies across the divider, in V. Use \(V^- = 0\) for a single supply.
\(V_G\)
Required gate voltage, in V.
Divider with a bias-current limit\[ R_1 + R_2 = \frac{V^+ - V^-}{f\,I_D} \qquad \frac{R_2}{R_1+R_2} = \frac{V_G - V^-}{V^+ - V^-} \]
\(f\)
Allowed fraction of \(I_D\), for example 0.1.
\(I_D\)
Drain current, in A.
\(V_G\)
Gate voltage, in V.
Key ideaQuestions 4 and 5 of Tutorial 9 and all of Tutorial 10 are the same two moves: find the gate voltage, then size or solve the divider. Tutorial 10 Q3 and Q4 are the odd ones: a diode-connected stack and a switch.

02Tutorial 9 Q3: width and regions

Question. An NMOS has \(V_{TN} = 0.8\ \text{V}\), \(L = 0.8\ \mu\text{m}\) and \(k_n' = 120\ \mu\text{A/V}^2\). In saturation at \(V_{GS} = 1.4\ \text{V}\) it carries \(I_D = 0.6\ \text{mA}\). (a) Find \(W\). (b) Find \(I_D\) when \(V_{DS} = 0.4\ \text{V}\). (c) Find the \(V_{DS}\) at the edge of saturation.

Worked example T9.3 Width, triode current and edge of saturation

Work in the order of the question, because each part uses the previous one.

1
Saturation at the measured point, so \(K_n = I_D/(V_{GS} - V_{TN})^2 = 0.6\ \text{mA}/(0.6\ \text{V})^2 = 1.6667\ \text{mA/V}^2\).
2
(a) \(W/L = 2K_n/k_n' = 2(1.6667\ \text{mA/V}^2)/(120\ \mu\text{A/V}^2) = 27.78\), so \(W = (27.78)(0.8\ \mu\text{m}) = 22.2\ \mu\text{m}\).
3
(c) first, because (b) needs it: \(V_{DS}(sat) = V_{GS} - V_{TN} = 1.4 - 0.8 = 0.6\ \text{V}\).
4
(b) \(V_{DS} = 0.4\ \text{V}\) is below \(0.6\ \text{V}\), so non-saturation: \(I_D = K_n[2(0.6)(0.4) - 0.4^2] = 1.6667(0.32) = 0.533\ \text{mA}\).
(a) \(W = 22.2\ \mu\text{m}\); (b) \(I_D = 0.533\ \text{mA}\); (c) \(V_{DS}(sat) = 0.6\ \text{V}\).
Memo discrepancyThe memo prints \(V_{DS}(sat) = 0.5\ \text{V}\) for part (c). The definition gives \(V_{GS} - V_{TN} = 1.4 - 0.8 = 0.6\ \text{V}\), and the memo's own part (b) answer of \(0.533\ \text{mA}\) only works with an edge of \(0.6\ \text{V}\). Treat \(0.5\ \text{V}\) as a typing slip.
Watch outThe question prints \(L = 0.8\ \mu\text{A}\). The unit has to be micrometres. Using \(0.8\ \mu\text{m}\) is the only reading that reproduces \(W = 22.2\ \mu\text{m}\).

03Tutorial 9 Q4: NMOS divider design

Question. An NMOS with \(V_{TN} = 0.4\ \text{V}\), \(k_n' = 120\ \mu\text{A/V}^2\) and \(W/L = 80\) sits in a common-source stage: \(V_{DD} = 1.8\ \text{V}\), \(R_D = 0.5\ \text{k}\Omega\), the source is grounded and the divider \(R_1\) (supply to gate), \(R_2\) (gate to ground) feeds the gate. Design for \(I_{DQ} = 0.8\ \text{mA}\) and \(R_{in} = R_1 \parallel R_2 = 200\ \text{k}\Omega\).

Figure 3.1: The source is grounded and the drain joins \(V_{DD}\) through \(R_D = 0.5\ \text{k}\Omega\). \(R_{in}\) is the resistance seen looking into the divider. The gate draws no current, so \(R_{in} = R_1 \parallel R_2\).

Worked example T9.4 NMOS divider with a given input resistance

The gate voltage comes from the current, and the divider is then sized from the input resistance.

1
\(K_n = (k_n'/2)(W/L) = (60\ \mu\text{A/V}^2)(80) = 4.8\ \text{mA/V}^2\).
2
Assume saturation: \(V_{GS} - V_{TN} = \sqrt{I_D/K_n} = \sqrt{0.8/4.8} = 0.4082\ \text{V}\), so \(V_{GS} = V_G = 0.8082\ \text{V}\) (positive root only).
3
Check: \(V_{DS} = V_{DD} - I_DR_D = 1.8 - (0.8\ \text{mA})(0.5\ \text{k}\Omega) = 1.40\ \text{V}\), above \(0.408\ \text{V}\). Saturation holds.
4
\(R_1 = R_{in}V_{DD}/V_G = (200\ \text{k}\Omega)(1.8)/0.8082 = 445.4\ \text{k}\Omega\).
5
\(R_2 = R_1R_{in}/(R_1 - R_{in}) = 363.0\ \text{k}\Omega\).
\(R_1 = 445.4\ \text{k}\Omega\) and \(R_2 = 363\ \text{k}\Omega\), matching the memo (\(445.4\ \text{k}\Omega\), \(363\ \text{k}\Omega\)).
Key ideaMarks follow the chain: \(K_n\), then the overdrive, then \(V_G\), then the saturation check, then the two resistors. The saturation check is easy to forget and is what makes the design valid.

04Tutorial 9 Q5: PMOS with a source resistor

Question. A PMOS with \(K_p = 0.5\ \text{mA/V}^2\) and \(V_{TP} = -0.8\ \text{V}\) has \(+3\ \text{V}\) and \(-3\ \text{V}\) supplies. The divider \(R_1 = 8\ \text{k}\Omega\) (from \(+3\ \text{V}\)) and \(R_2 = 22\ \text{k}\Omega\) (to \(-3\ \text{V}\)) sets the gate. The source connects to \(+3\ \text{V}\) through \(R_S = 0.5\ \text{k}\Omega\), and the drain connects to \(-3\ \text{V}\) through \(R_D = 5\ \text{k}\Omega\). Find \(I_D\), \(V_{SG}\) and \(V_{SD}\).

Figure 4.1: \(R_S\) joins the source to \(+3\ \text{V}\) and \(R_D\) joins the drain to \(-3\ \text{V}\). The divider \(R_1\), \(R_2\) spans both supplies, so the gate voltage is measured from \(-3\ \text{V}\) as in step 1.

Worked example T9.5 PMOS with a source resistor and split supplies

The source resistor couples the current back into \(V_{SG}\), so the loop equation and the device equation have to be solved together.

1
Gate voltage from the divider: \(V_G = -3 + 6 \times 22/30 = 1.40\ \text{V}\).
2
Source voltage: \(V_S = 3 - I_DR_S\), so \(V_{SG} = V_S - V_G = 1.60 - 0.5\,I_D\) (with \(I_D\) in mA).
3
Assume saturation: \(I_D = 0.5(V_{SG} - 0.8)^2 = 0.5(0.80 - 0.5I_D)^2\). Expanding gives \(0.125\,I_D^2 - 1.4\,I_D + 0.32 = 0\).
4
Roots: \(I_D = 0.2334\ \text{mA}\) and \(10.97\ \text{mA}\). The large root would give \(V_{SG} = −3.88\ \text{V}\), below threshold, so reject it.
5
\(V_{SG} = 1.60 - 0.5(0.2334) = 1.483\ \text{V}\).
6
Drain loop: \(V_{SD} = 6 - I_D(R_S + R_D) = 6 - (0.2334\ \text{mA})(5.5\ \text{k}\Omega) = 4.72\ \text{V}\).
7
Check: \(V_{SD}(sat) = V_{SG} + V_{TP} = 0.683\ \text{V}\), and \(4.72 \gt 0.683\). Saturation holds.
\(I_D = 233.4\ \mu\text{A}\), \(V_{SG} = 1.48\ \text{V}\), \(V_{SD} = 4.72\ \text{V}\).
RoundingThe memo's \(231.2\ \mu\text{A}\) and \(4.73\ \text{V}\) come from rounding \(V_{SG}\) to \(1.48\ \text{V}\) first: \(0.5(1.48-0.8)^2 = 231.2\ \mu\text{A}\). The unrounded solution is \(233.4\ \mu\text{A}\) and \(4.72\ \text{V}\). Both round to the same \(V_{SG}\), so state which you used.
Watch outWith a source resistor you cannot read \(V_{SG}\) straight off the divider. Solving \(I_D = K_p(V_{SG}+V_{TP})^2\) alone with \(V_{SG} = V_{DD} - V_G\) ignores the drop across \(R_S\) and gives the wrong current.

05Tutorial 10 Q1: depletion PMOS

Question (P3.41). Depletion PMOS, \(V_{TP} = +1.5\ \text{V}\), \(K_p = 0.5\ \text{mA/V}^2\). \(R_S = 2\ \text{k}\Omega\) connects the source to \(+5\ \text{V}\), the drain is grounded, and the divider \(R_1, R_2\) runs from \(+5\ \text{V}\) to \(-5\ \text{V}\). Design for \(V_{SD} = 2.5\ \text{V}\) with divider current at most 10 % of \(I_D\).

Figure 5.1: The drain is grounded and \(R_S = 2\ \text{k}\Omega\) joins the source to \(+5\ \text{V}\). The divider \(R_1\), \(R_2\) runs from \(+5\ \text{V}\) to \(-5\ \text{V}\). The unbroken channel line is the depletion-mode symbol.

Worked example T10.1 Depletion PMOS, current-limited divider

The drain is at ground, so the source voltage and \(R_S\) fix \(I_D\) immediately.

1
\(I_D = (5 - V_{SD})/R_S = 2.5/2\ \text{k}\Omega = 1.25\ \text{mA}\).
2
\(v_{SG} + V_{TP} = \sqrt{I_D/K_p} = \sqrt{1.25/0.5} = 1.5811\ \text{V}\), so \(V_{SG} = 1.5811 - 1.5 = 0.0811\ \text{V}\).
3
Saturation check: \(V_{SD}(sat) = 1.581\ \text{V} \lt 2.5\ \text{V}\). Holds.
4
\(V_G = 5 - I_DR_S - V_{SG} = 5 - 2.5 - 0.0811 = 2.419\ \text{V}\).
5
\(I_R = 0.1I_D = 125\ \mu\text{A}\), so \(R_1 + R_2 = 10/I_R = 80\ \text{k}\Omega\).
6
\(R_2/(R_1+R_2) = (V_G+5)/10 = 0.7419\), so \(R_2 = 59.35\ \text{k}\Omega\) and \(R_1 = 20.65\ \text{k}\Omega\).
\(R_1 \approx 20.64\ \text{k}\Omega\), \(R_2 \approx 59.36\ \text{k}\Omega\) (memo, with \(R_2/(R_1+R_2)\) rounded to 0.742). Unrounded: \(20.65\ \text{k}\Omega\) and \(59.35\ \text{k}\Omega\).
Watch outFor a depletion PMOS \(V_{TP}\) is positive, so \(V_{SG} = \text{overdrive} - V_{TP}\) can be tiny or negative. The memo's second square-root value \(-3.081\ \text{V}\) is rejected because the overdrive would be negative. Keep the root with \(v_{SG} + V_{TP} \gt 0\).

06Tutorial 10 Q2: PMOS with split supplies

Question (P3.43). PMOS with \(V_{TP} = -1.75\ \text{V}\), \(K_p = 3\ \text{mA/V}^2\). The source is grounded, \(R_D\) joins the drain to \(-10\ \text{V}\), and the divider runs between \(+5\ \text{V}\) and \(-5\ \text{V}\). Design for \(I_D = 5\ \text{mA}\), \(V_{SD} = 6\ \text{V}\) and \(R_{in} = R_1 \parallel R_2 = 80\ \text{k}\Omega\).

Figure 6.1: The source is grounded, \(R_D\) joins the drain to \(-10\ \text{V}\) and the divider runs from \(+5\ \text{V}\) to \(-5\ \text{V}\). \(R_{in}\) is the divider resistance seen from the gate, \(R_1 \parallel R_2\).

Worked example T10.2 Enhancement PMOS, split supplies, given Rin

Here the source sits at 0 V, so the gate voltage is simply \(-V_{SG}\).

1
Drain voltage \(= -6\ \text{V}\), so \(V_{R_D} = -6 - (-10) = 4\ \text{V}\) and \(R_D = 4/5\ \text{mA} = 800\ \Omega\).
2
\(v_{SG} + V_{TP} = \sqrt{5/3} = 1.2910\ \text{V}\), so \(V_{SG} = 3.041\ \text{V}\) (the other root, \(0.459\ \text{V}\), is below threshold).
3
Check: \(V_{SD}(sat) = 1.291\ \text{V} \lt 6\ \text{V}\). Saturation holds.
4
\(V_G = -V_{SG} = −3.041\ \text{V}\), so \(R_2/(R_1+R_2) = (V_G + 5)/10 = 0.1959\).
5
\(R_{in} = R_1R_2/(R_1+R_2) = R_1 \times 0.1959 = 80\ \text{k}\Omega\), so \(R_1 = 408.4\ \text{k}\Omega\) and \(R_2 = 99.5\ \text{k}\Omega\).
\(R_D = 800\ \Omega\), \(R_1 = 408.4\ \text{k}\Omega\), \(R_2 = 99.5\ \text{k}\Omega\), matching the memo.
Key ideaThe shortcut \(R_{in} = R_1 \times R_2/(R_1+R_2)\) turns the two simultaneous equations into one division. Equivalent general form: \(R_1 = R_{in}(V^+ - V^-)/(V_G - V^-)\).

07Tutorial 10 Q3: diode-connected stack

Question (P3.46c). Two NMOS transistors in series from \(V_{DD} = 5\ \text{V}\) to ground. Both have gate tied to drain: \(M_1\) at \(V_{DD}\), \(M_2\) at \(V_o\). \(V_{TN} = 0.4\ \text{V}\), \(k_n' = 120\ \mu\text{A/V}^2\), \((W/L)_1 = 15\), \((W/L)_2 = 30\). Find \(V_{GS1}\), \(V_{GS2}\), \(V_o\), \(I_D\), and show both are always saturated.

Figure 7.1: The gate of each transistor is tied to its own drain, so \(v_{DS} = v_{GS}\) for both. \(M_1\) has its drain at \(V_{DD}\), \(M_2\) has its source at ground, and \(V_o\) is the node between them.

Worked example T10.3 Diode-connected stack

Two unknown voltages, one shared current: use the loop and the equal-current condition.

1
\(K_1 = 60 \times 15 = 0.9\ \text{mA/V}^2\) and \(K_2 = 60 \times 30 = 1.8\ \text{mA/V}^2\).
2
Loop: \(V_{GS1} + V_{GS2} = 5\). Equal current: \(K_1(V_{GS1}-0.4)^2 = K_2(V_{GS2}-0.4)^2\).
3
Square roots (overdrives positive): \(V_{GS1} - 0.4 = \sqrt{K_2/K_1}\,(V_{GS2} - 0.4) = 1.4142(V_{GS2}-0.4)\). With \(V_{GS1}-0.4 + V_{GS2}-0.4 = 4.2\): \(V_{GS2} - 0.4 = 1.7397\ \text{V}\).
4
\(V_{GS1} = 2.860\ \text{V}\), \(V_{GS2} = V_o = 2.140\ \text{V}\).
5
\(I_D = K_1(V_{GS1}-0.4)^2 = 0.9(2.4603)^2 = 5.448\ \text{mA}\).
6
Region: \(V_{DS} = V_{GS}\) for each, so \(V_{DS} - V_{DS}(sat) = V_{GS} - (V_{GS} - V_{TN}) = V_{TN} = 0.4\ \text{V} \gt 0\). Always saturated, for any supply or \(W/L\).
\(V_{GS1} = 2.86\ \text{V}\), \(V_{GS2} = V_o = 2.14\ \text{V}\), \(I_D = 5.45\ \text{mA}\).

The memo's route. Substitute \(V_{GS2} = V_{DD} - V_{GS1}\) and square out: \(V_{GS1}^2 - 17.6\,V_{GS1} + 42.16 = 0\), with roots \(2.86\ \text{V}\) and \(14.74\ \text{V}\). Keep the one between \(V_{TN}\) and \(V_{DD}\). It gives the same answer as the square-root route, which avoids the quadratic.

08Tutorial 10 Q4: PMOS LED switch

Question (P3.52). A PMOS switches an LED (\(V_\gamma = 1.6\ \text{V}\)) from \(+5\ \text{V}\). The source is at the supply, the gate is \(V_I\), and \(R_D\) in series with the LED goes to ground. \(V_{TP} = -0.6\ \text{V}\), \(k_p' = 40\ \mu\text{A/V}^2\), \(\lambda = 0\). Design \(R_D\) and \(W/L\) for \(I_D = 15\ \text{mA}\) at \(V_I = 0\) with \(V_{SD} = 0.2\ \text{V}\), and verify the state.

Figure 8.1: The source is at \(+5\ \text{V}\) and the gate is driven by \(V_I\). With \(V_I = 0\) the transistor conducts, and \(I_D\) flows through \(R_D\) and the LED to ground.

Worked example T10.4 PMOS LED switch

The transistor is deliberately in non-saturation, so the triode equation is the one to use.

1
Output loop: \(5 = V_{SD} + I_DR_D + V_\gamma\), so \(R_D = (5 - 0.2 - 1.6)/15\ \text{mA} = 213.3\ \Omega\).
2
\(V_I = 0\) gives \(V_{SG} = 5\ \text{V}\) and \(V_{SD}(sat) = 5 - 0.6 = 4.4\ \text{V}\). The design value \(0.2\ \text{V}\) is far below, so non-saturation, as assumed.
3
\(K_p = I_D/[2(V_{SG}+V_{TP})V_{SD} - V_{SD}^2] = 15/[2(4.4)(0.2) - 0.04] = 8.721\ \text{mA/V}^2\).
4
\(W/L = 2K_p/k_p' = 2(8.721)/0.04 = 436.0\).
\(R_D = 213.3\ \Omega\) and \(W/L \approx 436\). Verified: \(V_{SD} = 0.2\ \text{V} \lt V_{SD}(sat) = 4.4\ \text{V}\).
Watch outUsing the saturation formula here gives \(K_p = 15/4.4^2 = 0.775\ \text{mA/V}^2\), a transistor about eleven times too small. The question asks to verify the assumed state; the check \(V_{SD} \lt V_{SD}(sat)\) is the verification.
