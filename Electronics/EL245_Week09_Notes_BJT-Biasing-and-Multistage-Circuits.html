Biasing, bias stability and multistage circuits

Why a single base resistor gives a Q-point that depends on \(\beta\), how a voltage divider and an emitter resistor fix that, how to design bias-stable circuits with one or two supplies or a current mirror, how to analyse and design circuits with two transistors, and how to design the LED switch of the practical test.

01Single-resistor biasing

Reading Neamen 5.4.1; Lecture 18, slides 2 to 5

The Q-point and the load line

A transistor amplifier only works while its DC operating point sits in the forward-active region and stays there. Biasing means choosing resistors and supplies so that the quiescent values \(I_{CQ}\), \(I_{BQ}\) and \(V_{CEQ}\) land where you want them, whichever transistor of that type is fitted.

Definition

Q-point (quiescent point): the DC currents and voltages in the transistor with no signal applied. On the output characteristic it is the point \((V_{CEQ}, I_{CQ})\) where the DC load line meets the transistor curve for the base current that flows.

Every calculation this week uses the same ground rules for a forward-active transistor: \(V_{BE(on)} = 0.7\ \text{V}\) (a pnp uses \(V_{EB(on)} = 0.7\ \text{V}\)), the collector current is \(\beta\) times the base current, and the emitter current is the sum of the two. A coupling capacitor is an open circuit for DC, so the signal source drops out of every bias calculation.

Forward-active current relations\[ I_{CQ} = \beta\, I_{BQ} \qquad I_{EQ} = (1+\beta)\, I_{BQ} \]
\(I_{CQ}\)
Quiescent collector current, in A.
\(\beta\)
Current gain of the transistor. It is a ratio, so it has no unit.
\(I_{BQ}\)
Quiescent base current, in A.
\(I_{EQ}\)
Quiescent emitter current. It is slightly larger than \(I_{CQ}\) because it also carries the base current.

The collector loop gives the DC load line. With an emitter resistor, \(I_{EQ} \approx I_{CQ}\) when \(\beta\) is large, so \(R_C\) and \(R_E\) act together.

DC load line\[ V_{CEQ} = V_{CC} - I_{CQ}R_C - I_{EQ}R_E \;\approx\; V_{CC} - I_{CQ}(R_C + R_E) \]
\(V_{CEQ}\)
Quiescent collector-emitter voltage, in V.
\(V_{CC}\)
Positive supply voltage, in V.
\(I_{CQ}\)
Quiescent collector current, in A.
\(R_C\)
Collector resistor, in \(\Omega\).
\(I_{EQ}\)
Quiescent emitter current, in A.
\(R_E\)
Emitter resistor, in \(\Omega\). It is zero for the single-resistor circuit.
Key idea

The load line is fixed by the circuit, but the Q-point also depends on \(\beta\), and the same part number can have a \(\beta\) anywhere from 50 to 150 (the range the lecture uses). A good bias circuit is one whose Q-point hardly moves when \(\beta\) changes. The next three sections compare how well each circuit does that.

One base resistor

The simplest bias circuit needs one supply and one base resistor \(R_B\) from \(V_{CC}\) to the base. A coupling capacitor \(C_C\) passes the signal from the source but blocks DC, so the source does not disturb the bias.

\(R_B\)

\(I_{CQ}\)

\(\beta\)

\(V_{CEQ}\)
Quiescent collector-emitter voltage, in V.
\(R_C\)
Collector resistor, in \(\Omega\).

Watch out

Exam

Intuition

The term \((1+\beta)R_E\) is the emitter resistor as the base sees it: any base current is multiplied by \((1+\beta)\) on its way through \(R_E\). A large \((1+\beta)R_E\) makes the base current depend more on \(R_E\) and less on \(\beta\), which is what a stable circuit needs.

03Bias stability

Reading Neamen 5.4.2; Lecture 18, slides 12 to 17

From the divider equations,

\[ I_{CQ} = \frac{\beta(V_{TH} - V_{BE(on)})}{R_{TH} + (1+\beta)R_E} \]

If \(R_{TH} \ll (1+\beta)R_E\), the \(R_{TH}\) term can be dropped, and with \(\beta/(1+\beta) \approx 1\) the result no longer contains \(\beta\) at all:

Bias-stable collector current\[ I_{CQ} \approx \frac{V_{TH} - V_{BE(on)}}{R_E} \qquad \text{when } R_{TH} \ll (1+\beta)R_E \]
\(I_{CQ}\)
Quiescent collector current (A).
\(V_{TH}\)
Thevenin voltage of the divider (V).
\(V_{BE(on)}\)
0.7 V.
\(R_E\)
Emitter resistor (\(\Omega\)).
\(R_{TH}\)
Thevenin resistance of the divider (\(\Omega\)).
\(\beta\)
Current gain.

"Much smaller" is made concrete by the general rule for bias stability:

Design rule for bias stability\[ R_{TH} = 0.1(1+\beta)R_E \]
\(R_{TH}\)
Thevenin resistance to design the divider for (\(\Omega\)).
\(\beta\)
Nominal current gain.
\(R_E\)
Emitter resistor (\(\Omega\)).

Making \(R_{TH}\) smaller still would improve stability further, but a small \(R_{TH}\) means small divider resistors, which waste supply current and load the signal source. The factor 0.1 is the compromise.

Figure 3.1: Computed from \(i_C = \beta(V_{TH} - V_{BE(on)})/(R_{TH} + (1+\beta)R_E)\) with a nominal \(\beta = 100\), so the horizontal axis is \(R_{TH}/(101R_E)\). The ratio does not depend on \(V_{TH}\) or \(R_E\). At the 0.1 rule the current changes by about 14 % across a threefold change in \(\beta\); with a single base resistor it would change threefold.

Watch out

The Tutorial 8 memo applies the rule as \(R_{TH} = 0.1\beta R_E\) (for example \(0.1 \times 125 \times 200 = 2.5\ \text{k}\Omega\) in Question 4), while the lecture slides use \(0.1(1+\beta)R_E\). For \(\beta \ge 100\) the two differ by 1 % or less, so the final resistor values hardly change. This page follows the slides; state which form you use in a test.

Design for the centre of the load line

A design method that works every time:

Key idea

1. Find \(I_{CQ}\) and \(V_{CEQ}\) from the specification (for "centre of the load line", \(V_{CEQ}\) is half the total supply).
2. Set \(R_{TH} = 0.1(1+\beta)R_E\).
3. Write the base loop to get \(V_{TH} = I_{BQ}R_{TH} + V_{BE(on)} + I_{EQ}R_E\).
4. Use \(V_{TH} = \frac{R_2}{R_1+R_2}V_{CC} = \frac{R_{TH}}{R_1}V_{CC}\) to get \(R_1 = R_{TH}V_{CC}/V_{TH}\), then \(R_2 = R_{TH}V_{CC}/(V_{CC} - V_{TH})\).

2
\(R_{TH} = 0.1(121)(300) = 3.63\ \text{k}\Omega\).

What it costs

A smaller \(R_{TH}\) means smaller \(R_1\) and \(R_2\). They draw more current from the supply, and the input resistance of the bias network, \(R_1 \parallel R_2\), is lower. That is why some problems give \(R_{in}\) as a design target as well.

Exam

The lecture designs use two shortcuts: \(I_{EQ} \approx I_{CQ}\) when finding \(I_{CQ}\) from the load line, and \(R_{TH} = 0.1(1+\beta)R_E\). They then use the exact \(I_{EQ} = (1+\beta)I_{BQ}\) when computing \(V_{TH}\). Follow the same order.

05Integrated circuit biasing

Reading Neamen 5.4.4; Lecture 19, slides 6 to 11

Resistors take up a lot of space on a chip, so integrated circuits bias transistors with a constant current source made from other transistors. The basic version is the current mirror: \(Q_1\) has its base and collector joined ("diode connected"), \(Q_2\) shares its base-emitter voltage, and so \(Q_2\) carries the same collector current as \(Q_1\).

Figure 5.1: \(R_1\) from ground to \(V^-\) through \(Q_1\) sets the reference current \(I_1\). \(Q_2\) has the same \(V_{BE}\) as \(Q_1\), so it copies the current as \(I_Q\), which then flows through \(Q_O\) whatever \(R_C\) is.

\(I_1\)
Reference current through \(R_1\) (A).
\(V_{BE(on)}\)
0.7 V.
\(V^-\)
Negative supply (V).
\(R_1\)
Reference resistor, from ground (0 V) to the joined base-collector of \(Q_1\) (\(\Omega\)).
\(I_Q\)
Mirrored current, the collector current of \(Q_2\) (A).
\(\beta\)
Current gain of \(Q_1\) and \(Q_2\).

The second equation is KCL at the joined node: \(I_1 = I_{C1} + I_{B1} + I_{B2}\). Identical transistors at the same temperature with the same \(V_{BE}\) have \(I_{C1} = I_{C2}\) and \(I_{B1} = I_{B2}\), so \(I_1 = I_{C2} + 2I_{C2}/\beta\). Both mirror transistors must stay forward-active for this to hold.

Intuition

\(Q_2\) cannot tell that its base-emitter voltage came from somewhere else. Whatever collector current the diode-connected \(Q_1\) carries at that voltage, \(Q_2\) carries as well. The load \(R_C\) can change and \(I_Q\) does not, as long as \(Q_2\) stays forward-active.

The mirrored current \(I_Q\) is the emitter current of \(Q_O\), since the collector of \(Q_2\) connects to the emitter of \(Q_O\). The collector current of \(Q_O\) is therefore slightly smaller than \(I_Q\).

06Multistage circuits

Most amplifiers use more than one transistor. When stages are connected directly (no coupling capacitor), the DC bias of one stage depends on the next: the base current of the second transistor is drawn from the collector node of the first.

Analysing a two-stage circuit

Figure 6.1: The collector of \(Q_1\) drives the base of \(Q_2\). The current in \(R_{C1}\) plus the base current flowing out of \(Q_2\) equals \(I_{C1}\).

Key idea

Work from the input stage outwards. Solve \(Q_1\)'s base loop first (its base current does not depend on \(Q_2\)), then write KCL at the node joining the two stages, using \(Q_2\)'s base-emitter loop to express \(I_{B2}\) in terms of that node voltage.

The cascode

A cascode stacks a second transistor on top of a common-emitter stage. In the full amplifier \(Q_1\) receives the signal at its base, and \(Q_2\)'s base is held at AC ground by a bypass capacitor \(C_B\) (left out of Figure 6.2, which shows only the DC circuit). Both transistors carry essentially the same current. A three-resistor divider sets both base voltages.

10Formula sheet

Ground rules

\(I_C = \beta I_B\), \(I_E = (1+\beta)I_B\)

\(V_{CEQ} \approx V_{CC} - I_{CQ}(R_C + R_E)\)

\(V_{BE(on)} = V_{EB(on)} = 0.7\ \text{V}\)

Single resistor

\(R_C = (V_{CC} - V_{CEQ})/I_{CQ}\)

\(R_B = (V_{CC} - 0.7)/I_{BQ}\)

\(I_{BQ} = (V_{CC} - 0.7)/R_B\), \(I_{CQ} = \beta I_{BQ}\)

\(I_{CQ} \propto \beta\): not stable

Divider

\(V_{TH} = \frac{R_2}{R_1+R_2}(V^+ - V^-) + V^-\), \(R_{TH} = R_1 \parallel R_2\)

\(I_{BQ} = \dfrac{V_{TH} - 0.7 - V^-_E}{R_{TH} + (1+\beta)R_E}\)

Bias stability

\(R_{TH} = 0.1(1+\beta)R_E\)

\(I_{CQ} \approx (V_{TH} - 0.7)/R_E\)

\(R_1 = R_{TH}V/V_{TH}\), \(R_2 = R_{TH}V/(V - V_{TH})\) (single supply \(V\))

Current mirror

\(I_1 = (-0.7 - V^-)/R_1\)

\(I_1 = I_Q(1 + 2/\beta)\)

\(I_Q = \frac{1+\beta}{\beta}I_C(Q_O)\)

Two supplies

\(V_{TH} = I_{BQ}R_{TH} + 0.7 + I_{EQ}R_E + V^-\)

\(V_{CEQ} = (V^+ - V^-) - I_{CQ}R_C - I_{EQ}R_E\)

Multistage

Solve stage 1 base loop first

KCL at the joining node includes \(I_{B2}\)

npn-npn: \(I_{BQ2} = \dfrac{V^+ - I_{CQ1}R_{C1} - 0.7 - V^-}{R_{C1} + (1+\beta)R_{E2}}\)

Cascode: \(V_{B1} = V_{R_E} + 0.7\), \(V_{B2} = V_{B1} + V_{CE1}\)

LED switch

\(R_C = (V_{CC} - V_\gamma - V_{CE(sat)})/I_C\)

\(\dfrac{V_{BB} - 0.7}{I_{B(max)}} \le R_B \le \dfrac{\beta(V_{BB} - 0.7)}{I_C}\)

\(\eta = \dfrac{V_\gamma I_C}{V_{CC}I_C + V_{BB}I_B}\)

In the divider entry, \(V^-_E\) is the voltage at the bottom of \(R_E\) (0 V for a single supply).
