01Digital Signal Specifications & Thresholds

A GPIO pin can be configured for input (floating/high-impedance, pull-down, pull-up, analog, or alternate function) or output (open-drain or push-pull, with optional pull-up/pull-down, or alternate function).

For the STM32F407 (VDD = 3.3 V):

  • Input High (VIH): minimum ≈ 0.7 × VDD ≈ 2.31 V.
  • Input Low (VIL): maximum ≈ 0.3 × VDD ≈ 0.99 V.
  • Output High (VOH): ≥ VDD − 0.4 V ≈ 2.9 V at 8 mA.
  • Output Low (VOL): ≤ 0.4 V at 8 mA.
  • 5 V-tolerant pins (FT): specific GPIO pins can safely accept a 5 V input without damaging the internal 3.3 V protection diodes.
  • Current capability: GPIO pins can sink/source ±8 mA under standard conditions, or up to ±20 mA absolute maximum with relaxed VOL/VOH. This is enough to switch an LED or drive a transistor, but not enough for higher-current loads (motors, relays) — those need an external switch (e.g. a MOSFET) driven from the GPIO.

02Output Configurations

ConfigurationHow it drives the pin
Push-pullComplementary P-MOS (pulls up to VDD) and N-MOS (pulls down to VSS) — the output is always actively driven, either high or low. Writing "0" activates the N-MOS; writing "1" activates the P-MOS.
Open-drainThe P-MOS is permanently disabled; only the N-MOS is active. Writing "0" pulls the pin to ground; writing "1" leaves the pin in high-impedance (Hi-Z) — it does not actively drive high. An internal or external pull-up resistor is needed to get a logic-high level. Behaves like a switch to ground, or disconnected. Essential for shared bidirectional buses (e.g. I²C), where multiple devices need to share one line without ever fighting each other.

On input, a pin is configured high-impedance (with the option of an internal pull-up or pull-down resistor); the voltage present on the pin is sampled into the input data register on every AHB clock cycle.

03Schmitt Triggers & Switch Debouncing

Schmitt trigger

A gate's input has an "uncertain" voltage range where the interpretation as HIGH or LOW is not clearly defined; a single threshold point at that boundary means AC noise superimposed on a slowly-changing signal can cause erratic, rapid toggling of the gate's output.

A Schmitt trigger is a comparator circuit that uses positive feedback to implement hysteresis — two distinct threshold voltages instead of one: a positive-going threshold VT+ (for rising edges) and a negative-going threshold VT− (for falling edges). The output holds its value until the input crosses far enough to trigger a change, which removes noise-induced oscillation and produces a clean, "square" digital transition from a noisy or slowly-varying analog input.

Switch bounce

A mechanical switch does not transition cleanly between open and closed — its contacts physically bounce for roughly 5–50 ms after being pressed or released, producing several unwanted extra edges. This matters most when the number of presses is significant (not just whether a press occurred), and especially when using interrupts, since each bounce can trigger its own interrupt.

Debouncing

ApproachTechnique
HardwareEstablish a definite logic level with the GPIO's pull-down resistor when the button is not pressed, then smooth the transition with an external RC low-pass filter (τ = R×C ≈ 10–50 ms) chosen to match the desired debounce time, followed by a Schmitt-trigger input to produce a clean edge. Pressing the button charges the capacitor; after release, the capacitor holds the pin high briefly before decaying.

04Memory-Mapped I/O

A portion of the address space is dedicated to I/O devices rather than memory — on this microcontroller, the range 0x4000 0000 to 0x5FFF FFFF is used for I/O. Each I/O device is assigned one or more addresses within this range: a store to that address sends data to the device, and a load receives data from it. This technique — using ordinary load/store instructions to talk to peripherals rather than dedicated I/O instructions — is called memory-mapped I/O.

Internally, an address decoder examines the address and the write-enable signal to determine which device the CPU is addressing, and generates the appropriate control/select signals; a multiplexer then selects between memory and the various I/O devices for reads, while write-enabled registers latch the values written to each device.
