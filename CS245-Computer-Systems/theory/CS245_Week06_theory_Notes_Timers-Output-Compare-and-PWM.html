Timers, output compare and PWM

How an STM32 timer turns a clock into a counter, how the prescaler and auto-reload register set the interrupt period, and how output compare and PWM drive a pin from the timer without the processor. After this page you can choose PSC, ARR and CCR values for a required period or duty cycle.

01Timer/counters

Reading Practical 5 lecture, slides 2 to 4, 6 and 9

A timer/counter is a register that counts clock edges. Fed with a fixed-frequency clock it measures time; fed with an external signal it counts events. The STM32F407 has several, each set up through memory-mapped registers.

Figure 1.1: A multiplexer picks the clock: the internal clock \(f_{clk}\) or an external source. The prescaler divides it by \(N\) to give the counter clock \(f_{timer}\) (CK_CNT). The counter TIMx_CNT counts up to the auto-reload value in TIMx_ARR, then restarts and raises an update event. The comparator checks TIMx_CNT against TIMx_CCRx and drives the channel output.

Definitions

TIMx_CNT: the count register, 16 or 32 bits wide. More bits give a longer counting range. TIMx_PSC: the 16-bit prescaler, dividing the clock by any factor from 1 to 65 536. TIMx_ARR: the auto-reload register, the same width as the count register. Update event (UEV): the counter overflowing (up-counting) or underflowing (down-counting); it can raise an interrupt.

In up-counting mode the counter runs 0, 1, …, ARR, then resets to 0. In down-counting mode it runs ARR, ARR−1, …, 0, then reloads ARR. Either way, one update event happens per pass.

Counter frequency and update period

Timer clock and update period\[ f_{timer} = \frac{f_{clk}}{N}, \quad N = \text{TIMx\_PSC} + 1 \qquad T = \frac{R + 1}{f_{timer}} \]
\(f_{timer}\)
Counter clock frequency, CK_CNT (Hz).
\(f_{clk}\)
Clock into the prescaler, CK_PSC (Hz).
\(N\)
Division factor. The register holds \(N - 1\), so a value of 0 divides by 1 and a divide by zero is impossible.
\(T\)
Time between update events, the interrupt interval (s).
\(R\)
Auto-reload value in TIMx_ARR. The count includes both 0 and \(R\), so one pass is \(R + 1\) ticks.
Watch out

Both registers are "minus one" values. To divide by 84 write PSC = 83; to count 1000 ticks write ARR = 999. Forgetting the +1 in either gives a period that is slightly off, which shows up as drift in anything timed over many periods.

Worked example 1.1 a 1 ms interrupt

The timer clock is \(f_{clk} = 84\) MHz. Choose PSC and ARR for an update interrupt every 1 ms.

1
Pick a convenient counter clock. Dividing by 84 gives \(f_{timer} = 84\text{ MHz}/84 = 1\) MHz, so PSC = 83.
2
At 1 MHz one tick is 1 µs, so 1 ms needs \(R + 1 = 1000\) ticks: ARR = 999.
3
Check: \(T = 1000 / 10^6 = 0.001\) s.
PSC = 83, ARR = 999 gives an update interrupt every 1 ms. Many other pairs work; any with \((\text{PSC}+1)(\text{ARR}+1) = 84\,000\) gives the same period.
Worked example 1.2 longest period of a 16-bit timer

With \(f_{clk} = 84\) MHz, a 16-bit counter and a 16-bit prescaler, what is the longest possible update period?

1
The largest division is \(N = 65\,536\) (PSC = 65 535), and the longest count is \(R + 1 = 65\,536\) (ARR = 65 535).
2
\(T_{max} = \dfrac{65\,536 \times 65\,536}{84 \times 10^{6}} = 51.13\) s.
About 51.13 s. A 32-bit counter with no prescaling reaches the same \(2^{32}/84\text{ MHz} = 51.13\) s, but with 12 ns resolution instead of 780 µs.

Set-up registers and channels

A timer is configured through its registers (in STM32CubeIDE, on the device configuration's Configuration tab, which also holds the NVIC interrupt and GPIO settings; the Pinout view shows which pins the timer uses):

  • clock source selection and up/down direction;
  • prescale value and auto-reload value;
  • interrupt enable, and whether it runs once (one-shot) or repeats (periodic).

Most timers have 4 independent channels, each usable for output compare, input capture, PWM generation or one-pulse output. Interrupts can come from an update (overflow, underflow or initialisation), a trigger (counter start, stop or count by trigger), an output compare, an input capture, or the break input.

Timers also clock other peripherals: they set the conversion rate of the ADC (Week 9) and the bit rate of serial links (Week 7). The clock reaching each timer is set in the Clock Configuration tab, so read \(f_{clk}\) from there before calculating PSC and ARR.

02Output compare

Reading Practical 5 lecture, slides 5, 7 and 10; reference manual p. 517

Output compare changes an output pin from the timer itself, without interrupting the processor. The counter is compared continuously with the capture/compare register TIMx_CCRx. On a match the output is set high, cleared low or toggled, and an interrupt can also be raised. It is used to make an output waveform or to mark that a time has passed.

Figure 2.1: The counter (teal) ramps from 0 to ARR and restarts. Every time it passes the CCR level (amber dashed) the output toggles. Two toggles make one output cycle, so a toggled output has half the update frequency and a 50 % duty cycle. CCR only shifts where in the period the edge falls.

Worked example 2.1 a 1 Hz square wave by toggling

A timer with \(f_{clk} = 16\) MHz has PSC = 1599, ARR = 4999, and channel 1 in toggle mode. Find the output frequency.

1
\(f_{timer} = 16\text{ MHz} / 1600 = 10\) kHz.
2
\(T = 5000 / 10\,000 = 0.5\) s between matches.
3
The pin toggles every 0.5 s, so one full cycle takes 1 s.
A 1 Hz square wave with 50 % duty cycle, produced with no processor time at all.

Advanced timers (TIM1 and TIM8) add dead-time generation between complementary outputs, shown in the reference manual block diagram. This stops both switches of a half bridge being on at once.

Starting the timer in HAL

STM32CubeIDE generates the timer's set-up code and a handle for it. The output compare must still be started once, before the while(1) loop:

HAL_TIM_OC_Start(&htim4, TIM_CHANNEL_1);

htim4 is the handle generated for timer 4 and must match the timer the output pin belongs to. The channel must match the channel that pin was set up to use. The PWM equivalent is HAL_TIM_PWM_Start, and the update interrupt version is HAL_TIM_Base_Start_IT.

Watch out

A timer that is configured but never started does nothing, and no error is reported. If the pin stays still, check the start call, the handle and the channel first.

03Pulse-width modulation

Reading Practical 5 lecture, slides 11 and 12

Pulse-width modulation (PWM) is a square wave whose pulse width, and so duty cycle, is programmable. Averaged by a slow load (a motor, an LED seen by the eye, or an RC filter) it behaves like a DC voltage set by the duty cycle.

Duty cycle and average voltage\[ D = \frac{t}{T} \qquad V_{avg} = D\, V_{high} \]
\(D\)
Duty cycle, the fraction of each period the output is high (no unit, often given in %).
\(t\)
Pulse width (s).
\(T\)
Pulse period (s).
\(V_{avg}\)
Average output voltage (V).
\(V_{high}\)
Voltage of the high level (V).

Figure 3.1: From a 3.3 V output, duty cycles of 25 %, 50 % and 75 % average to 0.825 V, 1.65 V and 2.475 V. The frequency does not change, only the pulse width. (The slide shows the same idea from 5 V: 1.25 V, 2.5 V and 3.75 V.)

PWM mode 1

PWM is output compare with a level rule instead of a toggle. In PWM mode 1, up-counting, the reference output OCxREF is high while the counter is below CCR and low from CCR up to ARR.

PWM mode 1, up-counting\[ \text{OCxREF} = \begin{cases} 1 & \text{CNT} \lt \text{CCR} \\ 0 & \text{CNT} \ge \text{CCR} \end{cases} \qquad D = \frac{\text{CCR}}{\text{ARR} + 1} \qquad T_{PWM} = \frac{\text{ARR} + 1}{f_{timer}} \]
\(\text{OCxREF}\)
Channel reference output (logic level).
\(\text{CNT}\)
Counter value.
\(\text{CCR}\)
Value in the capture/compare register: the number of high ticks per period.
\(D\)
Duty cycle.
\(\text{ARR}\)
Auto-reload value; one PWM period is ARR + 1 ticks.
\(T_{PWM}\)
PWM period (s).
\(f_{timer}\)
Counter clock frequency (Hz).

Figure 3.2: The counter (teal) steps 0 to 4, five ticks per period. The output (amber) is high for counts 0, 1 and 2 (below CCR = 3) and low for 3 and 4, so \(D = 3/5 = 60\) %. The slide's example (ARR = 6, CCR = 3) gives \(3/7\) and a period of 7 clock periods in the same way.

Watch out

The slide titles this "PWM Mode 1 (Low-True)" while its rule and waveform are high while CNT < CCR. Go by the rule: in mode 1 the output is active (high with default polarity) while the counter is below CCR. PWM mode 2 is the inverse. CCR = 0 gives 0 % and CCR ≥ ARR + 1 gives 100 %.

Worked example 3.1 a 20 kHz motor PWM

\(f_{clk} = 84\) MHz. Set up a 20 kHz PWM in mode 1 with 70 % duty cycle from a 3.3 V pin, and find the pulse width and average voltage.

1
PSC = 83 gives \(f_{timer} = 1\) MHz.
2
\(T_{PWM} = 1/20\text{ kHz} = 50\) µs = 50 ticks, so ARR = 49.
3
\(\text{CCR} = D(\text{ARR}+1) = 0.7 \times 50 = 35\).
4
Pulse width \(= 35\) ticks \(= 35\) µs; \(V_{avg} = 0.7 \times 3.3 = 2.31\) V.
PSC = 83, ARR = 49, CCR = 35: a 35 µs pulse every 50 µs, averaging 2.31 V. With ARR + 1 = 50 the duty cycle can only change in 2 % steps; a smaller PSC and larger ARR give finer steps at the same frequency.
Exam

Expect to be given \(f_{clk}\) and a required period or duty cycle and asked for PSC, ARR and CCR, or the reverse. Write \(N = \text{PSC} + 1\) and \(R + 1\) explicitly before substituting.

04Practice problems

Problem 4.1 a 250 ms tick

Choose PSC and ARR for an update interrupt every 250 ms from an 84 MHz timer clock, with a 10 kHz counter clock.

1
\(N = 84\text{ MHz}/10\text{ kHz} = 8400\), so PSC = 8399.
2
\(R + 1 = 0.25 \times 10\,000 = 2500\), so ARR = 2499.
PSC = 8399, ARR = 2499.
Problem 4.2 reading a PWM set-up

A timer runs at \(f_{timer} = 2\) MHz with ARR = 399 and CCR = 100 in PWM mode 1, output high 3.3 V. Find the frequency, duty cycle, pulse width and average voltage.

1
\(f_{PWM} = 2\text{ MHz}/400 = 5\) kHz.
2
\(D = 100/400 = 25\) %; pulse width \(= 100/2\text{ MHz} = 50\) µs.
3
\(V_{avg} = 0.25 \times 3.3 = 0.825\) V.
5 kHz, 25 %, 50 µs, 0.825 V.
Problem 4.3 toggle frequency

A channel in output compare toggle mode runs with \(f_{timer} = 1\) MHz and ARR = 499. What frequency appears on the pin?

1
\(T = 500/10^6 = 0.5\) ms between matches.
2
Two toggles per output cycle: period 1 ms.
1 kHz, 50 % duty cycle.
Problem 4.4 a servo signal

A hobby servo needs a 50 Hz signal with a 1 ms to 2 ms pulse (1.5 ms centred). Set up TIM4 from 84 MHz, PWM mode 1.

1
PSC = 83 gives 1 µs ticks.
2
20 ms period = 20 000 ticks: ARR = 19 999.
3
CCR equals the pulse width in µs: 1000 to 2000, centre 1500 (\(D = 7.5\) %).
PSC = 83, ARR = 19 999, CCR from 1000 to 2000 (1500 centred). Start it with HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_x).
