L1Embedded Systems & Computing History

Embedded systems & microcontrollers

  • Embedded system: a combination of a computer processor, computer memory, and dedicated input/output (I/O) peripheral devices, designed to perform a dedicated function within a larger mechanical or electrical system.
  • Microprocessor (CPU): a multi-purpose, clock-driven, register-based digital integrated circuit. It accepts binary data as input, processes it according to instructions stored in memory, and provides results as output. It fetches machine instructions from external memory, decodes them, and executes arithmetic/logic operations.
  • Microcontroller (MCU): integrates the CPU core, memory (Flash/ROM and SRAM), and hardware peripherals (GPIO, timers, ADCs, serial interfaces) onto a single silicon die. A CPU by itself has little use — it needs memory, timers, and peripherals around it.
  • Traditional PC architecture mounts the CPU on a mainboard with separate memory daughter-boards and peripherals soldered on or plugged in. A microcontroller integrates all of this into one device.

A microcontroller is similar to, but less sophisticated than, a System on a Chip (SoC) — an SoC (e.g. a smartphone chip) may include a microcontroller-like core plus a GPU and other specialised units as just some of its components. Microcontrollers range from tiny devices with a single dedicated function (a remote control) up to devices with desktop-class compute capability (e.g. multi-core boards with an integrated GPU). Choosing a microcontroller for a project means trading off requirements against constraints (cost, power, performance, peripherals, whether an OS is needed).

Chronological milestones in computing

  • ≈2400 BC: Abacus — earliest mechanical aid for arithmetic.
  • 1640s: Blaise Pascal invents the Pascaline, a mechanical calculator capable of adding six-digit numbers.
  • Early 1800s: Charles Babbage invents the Difference Engine to tabulate polynomial functions.
  • 1833: Babbage's Analytical Engine — both program and data supplied via punched cards; incorporated an arithmetic logic unit and control flow (conditional branching, loops) with integrated memory, making it the first design for a general-purpose computer.
  • 1890: Herman Hollerith's punch-card tabulating machines process the US census in three years, saving the government $5 million; the company later becomes IBM.
  • 1937: Atanasoff–Berry Computer (ABC) — first automatic electronic digital computer concept; not programmable.
  • 1941: Konrad Zuse's Z3 — first working programmable, fully automatic digital computer. Electromechanical (2600 relays), 22-bit word length, ≈4–5 Hz clock, program stored on punched film, used the binary number system.
  • 1943: Colossus (Britain) — first electronic programmable vacuum-tube computer, built to crack German ciphers.
  • 1946: ENIAC (USA) — first general-purpose electronic computer; had to be physically rewired to reprogram (often taking weeks per problem). Could execute 5000 additions, 357 multiplications, and 38 divisions per second.
  • 1971: Intel 4004 — first commercial single-chip microprocessor: 740 kHz, 4-bit word length, 2250 transistors.
Why this mattersComputers began as mechanical devices and only became general-purpose, programmable, electronic machines in the mid-20th century. Everything since — including the STM32F407 used in this module — is a direct descendant of the ENIAC/Z3 lineage: a clocked digital circuit executing stored instructions.

L2–3Number Systems & Representation

Number systems

Digital logic only has two states — HIGH and LOW — so binary is the native representation. Hexadecimal exists purely as a convenient, human-readable shorthand for binary.

  • Binary (base-2): bits ∈ {0, 1}. An N-bit number represents the value Σ bᵢ·2ⁱ for i = 0 … N−1. An N-bit unsigned number has 2N distinct values, in the range [0, 2N−1].
  • Hexadecimal (base-16): digits 0–9, A–F (10–15 in decimal). Each hex digit maps exactly to a 4-bit nibble, which is why it is convenient shorthand for binary. In C, hex literals use the 0x prefix, e.g. 0xA5 = 1010 01012 = 16510.

Two's-complement signed integers

The processor performs all arithmetic as if the number were unsigned — the only difference is how the bit pattern is interpreted. In two's complement, the most significant bit (MSB) carries a negative weight instead of a positive one:

Value = −bN−1·2N−1 + Σ bᵢ·2i (i = 0 … N−2) Most positive value: 011…1₂ = +2ᴺ⁻¹ − 1 · Most negative value: 100…0₂ = −2ᴺ⁻¹
N
Number of bits in the word.
bᵢ
Bit i, either 0 or 1.
bN−1
The sign bit; it carries a negative weight of 2N−1.
2i
Weight of bit i.

Negation algorithm: invert every bit and add 1 — Two's-Comp(x) = ~x + 1.

Worked cautionA satellite telemetry channel used a 16-bit signed integer with ×1000 fixed-point scaling to represent an angular spin rate (range −32.768 to +32.767 deg/s). When the true rate exceeded the representable range, the value overflowed and appeared to "jump" between +32 and −32 — a classic symptom of exceeding a signed integer's range.

Characters & the ASCII table

  • A bit pattern in memory has no inherent meaning — the computer does not know whether it represents a signed number, an unsigned number, a floating-point value, a character, or a machine instruction. Interpretation depends entirely on the CPU state and the instruction about to execute.
  • ASCII: characters mapped to 7/8-bit codes. '0' = 48, '1' = 49 …; 'A' = 65, 'B' = 66 …; 'a' = 97, 'b' = 98 …
  • Special escape characters: \0 (null terminator, 0x00), \n (newline, 0x0A), \r (carriage return, 0x0D), \t (tab, 0x09).
