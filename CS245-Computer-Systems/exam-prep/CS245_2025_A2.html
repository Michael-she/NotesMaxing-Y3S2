Q1Discovery board facts

True, False or Pass for each statement about the STM32F407VG Discovery board.

(a)
The STM32F407VG features an ARM 16-bit Cortex-M4 CPU.
(b)
The board's microcontroller supports floating-point operations in hardware.
(c)
The board only has one timer that can generate PWM signals.
(d)
The Discovery board includes an ST-LINK/V2 debugger integrated on the PCB.
(e)
The STM32F407VG uses 12-bit registers for all peripheral control.
Memo for question 1

Approach. Each item tests one fact from the board and chip documentation.

Answers

  1. (a) False. The Cortex-M4 is a 32-bit core (32-bit registers, 32-bit address bus).

  2. (b) True. The Cortex-M4F core in the STM32F407 has a single-precision floating-point unit.

  3. (c) False. Most of its 14 timers (TIM1 to TIM5, TIM8 to TIM14) have capture/compare channels that can output PWM.

  4. (d) True. The ST-LINK/V2 programmer and debugger is the top part of the Discovery PCB.

  5. (e) False. Peripheral registers are 32 bits wide and memory-mapped; 12 bits is only the ADC/DAC resolution.

F, T, F, T, F

Q2Bit pattern in C

Write unsigned char CheckByte(unsigned char input) that returns a byte according to this table. X is a don't-care bit.

Input (binary)Output
XXXX 010116
XXXX 001X17
XXXX 0X0018
XXXX 011X19

Tests given: 1110 0010 → 17, 0010 0100 → 18, 1010 0101 → 16.

Memo for question 2

Approach. Mask and match (revision lecture): AND the input with a mask that has 1s only where the pattern has fixed bits, then compare the result with the fixed bits. The high nibble is all don't-care, so only the low nibble is tested.

Mask and pattern for each row

  1. XXXX 0101: mask 0x0F, match 0x05.

  2. XXXX 001X: mask 0x0E, match 0x02.

  3. XXXX 0X00: mask 0x0B, match 0x00.

  4. XXXX 011X: mask 0x0E, match 0x06.

  5. Code:

    unsigned char CheckByte(unsigned char input)
{
    if ((input & 0x0F) == 0x05) return 16;   /* XXXX 0101 */
    if ((input & 0x0E) == 0x02) return 17;   /* XXXX 001X */
    if ((input & 0x0B) == 0x00) return 18;   /* XXXX 0X00 */
    if ((input & 0x0E) == 0x06) return 19;   /* XXXX 011X */
    return 0;                                /* not in the table */
}
Tests: 0xE2 → 17, 0x24 → 18, 0xA5 → 16 (run with gcc)
Watch out

The table does not cover XXXX 0001 or any input with bit 3 set. The paper does not say what to return; returning 0 is a reasonable choice, but read the CodeRunner tests if they show one.

Q4Timer auto-reload

The timer input clock is 90 MHz and TIMx_PSC = 999. What must TIMx_ARR be for an interrupt every 0.2 s?

179999 · 17999 · 18000 · 180000

Timer period (revision lecture)\[ f_{timer} = \frac{f_{clk}}{PSC + 1}, \qquad T = \frac{ARR + 1}{f_{timer}} \]
\(f_{timer}\)
Counter clock after the prescaler (Hz).
\(f_{clk}\)
Timer input clock (Hz).
\(PSC\)
Value in TIMx_PSC; the clock is divided by PSC + 1.
\(T\)
Interrupt interval, counting up from 0 to ARR (s).
\(ARR\)
Value in TIMx_ARR.
Memo for question 4

Approach. Find the counter clock, then the number of counts in 0.2 s, then subtract one.

ARR

  1. \(f_{timer} = 90\ \text{MHz} / 1000 = 90\ \text{kHz}\).

  2. Counts in 0.2 s: \(0.2 \times 90\,000 = 18\,000\).

  3. Both 0 and ARR are counted, so \(ARR = 18\,000 - 1\).

TIMx_ARR = 17999

Approach. Divide by PSC + 1, not by PSC.

Timer frequency

  1. \(f_{timer} = 64 \times 10^6 / (2047 + 1) = 64 \times 10^6 / 2048 = 31\,250\) Hz.

Q7Serial communication

True, False or Pass (negative marking).

(a)
All serial communication must be bi-directional.
(b)
SPI is a full-duplex, point-to-point communication standard.
(c)
UART can be used to communicate between a microcontroller and a user using a terminal emulator like Termite.
(d)
In I2C, each byte must be followed by an Acknowledge bit.
(e)
The USB Virtual COM port device can be used as a USB-connected UART to your PC when using the STM32F407VG Discovery board.
Memo for question 7

Approach. Use the comparison table in the revision lecture: UART is full-duplex point-to-point, I2C is a half-duplex bus, SPI is a full-duplex bus.

Answers

  1. (a) False. A link can be one-way (simplex), for example a sensor that only transmits, or the I2S audio output.

  2. (b) False. SPI is full-duplex, but it is a bus: one master selects one of several slaves with separate chip-select lines.

  3. (c) True. A terminal emulator on a PC sends and shows the UART characters (through a USB-UART bridge or virtual COM port).

  4. (d) True. Every 8-bit byte is followed by a ninth clock in which the receiver sends ACK (or NACK after the last byte of a read).

  5. (e) True. The USB device peripheral with the CDC class appears on the PC as a COM port, so it behaves like a UART link.

F, F, T, T, T

Q8Speed ranking

Arrange from fastest to slowest: UART, SPI, I2C.

Memo for question 8

Approach. Compare typical maximum rates.

Ranking

  1. SPI has no addressing or acknowledge overhead and push-pull lines: tens of Mbit/s.

  2. I2C: 100 kbit/s, 400 kbit/s, 1 Mbit/s and 3.4 Mbit/s modes, limited by the open-drain pull-ups.

  3. UART: standard rates up to 115 200 bit/s in this module, with start and stop bits on every byte.

SPI → I2C → UART

Q9UART throughput

A UART runs at 115 200 bit/s with 8N1 framing. What is the data rate in bytes per second?

Memo for question 9

Approach. Count every bit in a frame, not only the data bits.

Bytes per second

  1. 8N1: 1 start + 8 data + 0 parity + 1 stop = 10 bits per byte.

  2. \(115\,200 / 10 = 11\,520\) bytes/s.

11 520 bytes/s

Q11SPI facts

(a)
SPI supports multiple masters? (negative marking)
(b)
SPI only supports 8-bit transfers? (negative marking)
(c)
SPI hardware controllers can also be used for transmitting [A] data. Options: I²S · I²C · UART
Memo for question 11

Approach. These items follow the SPI feature list in the STM32F4 reference manual (RM0090).

Answers

  1. (a) True. RM0090 lists "multimaster mode capability": the NSS pin and mode-fault (MODF) detection let a master hand over the bus. Only one master drives the bus at a time.

  2. (b) False. The frame format is selectable as 8 or 16 bits.

  3. (c) I²S. SPI2 and SPI3 double as I²S audio interfaces: SCK is the bit clock, MOSI the serial data, NSS the word select.

True, False, I²S
Watch out

Q13LIS3DSH driver

A junior engineer wrote these functions to set up and read the LIS3DSH accelerometer over SPI. It does not work. Correct both so that the accelerometer runs in normal mode at an output data rate of 50 Hz and LIS3DSH_ReadXYZ returns the X, Y and Z accelerations. GPIO and SPI are already configured. The chip select is PE3.

void LIS3DSH_Init(void)
{
  HAL_StatusTypeDef res;
  uint8_t TxBuf[10] = {0};
  TxBuf[0] = 0x20 | 0x80;
  TxBuf[1] = 0x13;
  res = HAL_SPI_Transmit(&hspi1, TxBuf, 2, 100);
}

void LIS3DSH_ReadXYZ(int16_t *pData)
{
  HAL_StatusTypeDef res;
  uint8_t TxBuf[10] = {0};
  uint8_t RxBuf[10] = {0};
  TxBuf[0] = 0x18;
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_SET);
  res = HAL_SPI_Transmit(&hspi1, RxBuf, 1, 100);
  res = HAL_SPI_Receive(&hspi1, TxBuf, 3, 100);
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_RESET);
  pData[0] = RxBuf[0];
  pData[1] = RxBuf[2];
  pData[2] = RxBuf[4];
}
Memo for question 13

Approach. On the LIS3DSH, the first SPI byte is the register address with bit 7 = 1 to read and 0 to write. CS (PE3) is active low and must stay low for the whole transfer. CTRL_REG4 (0x20) holds ODR[3:0], BDU, Zen, Yen, Xen. The outputs are OUT_X_L at 0x28 to OUT_Z_H at 0x2D, low byte first.

Errors

  1. Init writes to 0x20 | 0x80: bit 7 set means read. A write uses 0x20.

  2. 0x13 = 0001 0011: ODR 3.125 Hz and Z disabled. 50 Hz is ODR = 0101; enable all axes with 111: 0101 0111 = 0x57.

  3. Init never drives CS low, so the sensor ignores the bytes.

  4. ReadXYZ addresses 0x18 instead of OUT_X_L (0x28) and does not set the read bit: use 0x28 | 0x80 = 0xA8.

  5. CS is driven high during the transfer and low after it: the levels are swapped.

  6. It transmits from RxBuf and receives into TxBuf: the buffers are swapped.

  7. It reads 3 bytes, but three 16-bit values need 6.

  8. Each axis is a 16-bit two's complement value, low byte first, so combine two bytes per axis.

Corrected code

  1. void LIS3DSH_Init(void)
{
  HAL_StatusTypeDef res;
  uint8_t TxBuf[10] = {0};
  TxBuf[0] = 0x20;                  /* CTRL_REG4, write (bit 7 = 0) */
  TxBuf[1] = 0x57;                  /* ODR 50 Hz, Z, Y and X enabled */
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_RESET);   /* CS low */
  res = HAL_SPI_Transmit(&hspi1, TxBuf, 2, 100);
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_SET);     /* CS high */
}

void LIS3DSH_ReadXYZ(int16_t *pData)
{
  HAL_StatusTypeDef res;
  uint8_t TxBuf[10] = {0};
  uint8_t RxBuf[10] = {0};
  TxBuf[0] = 0x28 | 0x80;           /* OUT_X_L, read */
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_RESET);
  res = HAL_SPI_Transmit(&hspi1, TxBuf, 1, 100);
  res = HAL_SPI_Receive(&hspi1, RxBuf, 6, 100);
  HAL_GPIO_WritePin(GPIOE, GPIO_PIN_3, GPIO_PIN_SET);
  pData[0] = (int16_t)((RxBuf[1] << 8) | RxBuf[0]);   /* X */
  pData[1] = (int16_t)((RxBuf[3] << 8) | RxBuf[2]);   /* Y */
  pData[2] = (int16_t)((RxBuf[5] << 8) | RxBuf[4]);   /* Z */
}
Reading six bytes in one go

The register address steps from 0x28 to 0x2D during the burst because the ADD_INC bit in CTRL_REG6 enables address auto-increment. If your sensor set-up clears ADD_INC, read the six registers one at a time instead.

Q15I2C pull-up resistor

For an I/O drive strength of 6 mA and \(V_{DD}\) = 3.3 V, calculate the minimum pull-up resistor in ohms for an I2C bus signal, using the values from table 54 of the datasheet. Round to 2 significant figures.

Minimum pull-up\[ R_{P(min)} = \frac{V_{DD} - V_{OL(max)}}{I_{OL}} \]
\(R_{P(min)}\)
Smallest pull-up resistance that still lets the pin pull the line low (Ω).
\(V_{DD}\)
Bus supply voltage (V).
\(V_{OL(max)}\)
Highest low-level output voltage the pin guarantees at that current (V).
\(I_{OL}\)
Sink current the pin can take (A).
Memo for question 15

Approach. When the pin pulls the line low it sinks the pull-up current. That current may not exceed the drive strength, so the resistor has a minimum.

Rp(min)

  1. The STM32F407 datasheet I/O output table gives \(V_{OL(max)}\) = 0.4 V for the CMOS output at this current.

  2. \(R_{P(min)} = (3.3 - 0.4) / 0.006 = 483.3\ \Omega\).

  3. To 2 significant figures: 480 Ω.

480 Ω
Watch out

The 2024 handwritten answers took \(V_{OL} = 0\) and got 550 Ω. That ignores the datasheet value the question tells you to use.

Q16ADC resolution

For a 0 to 3.3 V ADC, choose the minimum resolution for a quantisation error of less than 5 mV.

4 · 6 · 8 · 10 · 12 · 14 · 16 · 24 bit

Memo for question 16

Approach. The quantisation error of a rounding ADC is at most half an LSB. Find N, then pick the next option up.

Resolution

  1. \(\tfrac{1}{2}\,\text{LSB} = \dfrac{3.3}{2 \cdot 2^N} \lt 0.005\) gives \(2^N \gt 330\), so \(N \ge 9\).

  2. If the error is taken as a full LSB, \(2^N \gt 660\) and \(N \ge 10\).

  3. 9 bits is not an option, so either way the smallest choice is 10 bits.

10-bit

Q21Motors and relays

(a)
In a design with small discrete movements, use a [A] motor. Options: DC · Servo · Stepper
(b)
When switching relays, include a [B] in parallel with the [C]. Options: resistor, transistor, capacitor, flyback diode, relay, coil
(c)
For efficient DC motor speed control, use a [E] to drive a [F]. Options: DMA, GPIO, PWM signal, H-Bridge, relay
Memo for question 21

Approach. Match each actuator to its driver.

Answers

  1. [A] Stepper: it moves in fixed steps per pulse, which gives precise discrete positions.

  2. [B] flyback diode across [C] the coil of the relay: it gives the coil current a path when the transistor turns off, so the inductive voltage spike does not destroy the transistor.

  3. [E] a PWM signal drives [F] an H-Bridge: the bridge switches the motor current fully on or off (little loss) and can reverse it; the duty cycle sets the average voltage and so the speed.

Stepper; flyback diode, coil; PWM signal, H-Bridge

Q22Signals and cables

(a)
Wires or traces carrying differential signals must have equal length, otherwise one signal will arrive before the other.
(b)
Characteristic impedance is the resistance of the wire.
(c)
Coaxial cables typically have characteristic impedances of 50 Ω or 75 Ω.
Memo for question 22

Approach. Transmission-line basics from the impedance lecture.

Answers

Q23Memory types

(a)
In general, [A] flash is used for program code. NAND · NOR
(b)
[B] flash memory is used for mass storage. NAND · NOR
(c)
A [C] interface has separate strobe signals for column and row addresses. SDRAM · NOR · NAND
(d)
[D] information is stored as charge in a capacitor. SDRAM · NOR · NAND
Memo for question 23

Approach. Revision lecture, flash memory comparison.

Answers

  1. [A] NOR: random access, the CPU can execute directly from it.

  2. [B] NAND: denser and cheaper per bit, read in pages.

Q25Assembly: read PA0

Write the assembly function readUserPin that returns the state of PA0 (the user button) on the STM32F4DISCOVERY. The ports are initialised. Use only the input data register. C prototype: uint32_t readUserPin();

Memo for question 25

Approach. GPIOA starts at 0x4002 0000 and IDR is at offset 0x10. Return the value in R0 (AAPCS) and mask off everything except bit 0.

Code

  1. .syntax unified
readUserPin:
    ldr  r1, =0x40020010    @ GPIOA_IDR
    ldr  r0, [r1]           @ read all 16 input bits
    and  r0, r0, #1         @ keep PA0 only
    bx   lr                 @ return value in r0
Returns 1 when the button is pressed, 0 otherwise
