Timer Frequency & Period Formulas

f_timer = f_clk / N  where N = TIMx_PSC + 1 (never 0, avoiding a divide-by-zero)
T = (R + 1) / f_timer  where R = TIMx_ARR R + 1 because both 0 and R are included in the count — counting 0..3 is 4 steps, not 3.

Worked example

The input clock to the timer module (CK_PSC) is 10 MHz, with a prescaler value TIMx_PSC = 1024, counting up from 0. What auto-reload value gives a ≈1 s interrupt period?

TIMx_ARR = 10⁷ / (1024 + 1) − 1 ≈ 9746

Because 9746 is rounded down to an integer, the resulting period is not exactly 1 s — it works out to ≈0.9990675 s. Some timer hardware compensates for this rounding automatically; check the specific device's datasheet.

HAL: Output Compare

// Start outside the while(1) loop:
HAL_TIM_OC_Start(&htim4, TIM_CHANNEL_1);

htim4 is auto-generated by STM32CubeIDE from the timer's device-configuration settings — use the handle matching the timer, and the channel matching the output pin you configured.

HAL: Input Capture

// Start (with interrupt) outside the while(1) loop:
HAL_TIM_IC_Start_IT(&htim5, TIM_CHANNEL_1);

// Callback — copy the template from stm32f4xx_hal_tim.c into main.c
// (without the __weak qualifier), then fill in your own logic.
// Callbacks are shared across all timers, so check which one fired:
void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim) {
    if (htim->Instance == TIM5) {
        volatile uint32_t captured_val = __HAL_TIM_GetCounter(htim);
        __HAL_TIM_SetCounter(htim, 0);   // reset the timer
    }
}
NoteThe captured value is written from inside an interrupt callback — if you store it into a variable read elsewhere (e.g. the main loop), that variable must be volatile.

Kicking the Watchdog

The Independent Watchdog (IWDG) resets the MCU when its counter reaches 0x000. Writing the key value 0xAAAA into IWDG_KR reloads the counter from IWDG_RLR and prevents the reset — this is the "kick".

#define IWDG_KR (*((volatile uint32_t *)0x40003000))
IWDG_KR = 0xAAAA;   // reload the watchdog counter — call periodically

HAL: Real-Time Clock

RTC_TimeTypeDef sTime = {0};
RTC_DateTypeDef sDate = {0};

// Set:
HAL_RTC_SetTime(&hrtc, &sTime, RTC_FORMAT_BIN);
HAL_RTC_SetDate(&hrtc, &sDate, RTC_FORMAT_BIN);

// Read:
HAL_RTC_GetTime(&hrtc, &sTime, RTC_FORMAT_BIN);
HAL_RTC_GetDate(&hrtc, &sDate, RTC_FORMAT_BIN);

Like the timer input-capture callback, the alarm has its own weak callback template (in stm32f4xx_hal_rtc.c) to copy into main.c and override:

void HAL_RTC_AlarmAEventCallback(RTC_HandleTypeDef *hrtc) {
    HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_12);   // e.g. turn an LED on when the alarm fires
}
